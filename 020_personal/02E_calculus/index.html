微分積分の教科書

CALCULUS

2次関数から指数・対数・三角関数を経て数学Ⅱと数学Ⅲの微分積分まで学習指導要領の順に積み上げる。目標は共通テスト数学Ⅱ・B・Cの満点と数学Ⅲの基礎である。

各章に例題と確認問題を置いた。野球・男女・スタートアップの比喩とトリビアは理解の補助として短く添えてある。

教科書

序章

序章検証済み
微分積分の地図
微分は変化の速さを求める操作で積分は変化を積み重ねる操作である。2つは互いに逆の操作である。この本は数学Ⅰの2次関数から数学Ⅲの積分法の応用まで学習指導要領の順序で積み上げる。

数学Ⅰ

第1章検証済み
関数と2次関数
関数は入力 x に出力 y を1つ対応させる規則である。2次関数は平方完成で頂点の形に直すとグラフの位置と最大最小と x 軸との交わり方がすべて分かる。微分を学ぶ前に関数とグラフの言葉をここで整える。

数学Ⅱ

第2章検証済み
指数関数
指数は同じ数を掛ける回数として始まり指数法則が成り立つように0・負の数・分数へ広げられる。広げた結果として得る指数関数 y＝aˣ は底が1より大きければ増加し1より小さければ減少する。方程式と不等式はこの増減の性質で解く。
第3章検証済み
対数関数
対数は指数の逆である。aを何乗するとMになるかを答える数が log_a M である。指数法則を裏返すと積が和になる対数の性質が得られ常用対数を使うと巨大な数の桁数が足し算と掛け算で求まる。
第4章検証済み
三角関数
数学Ⅰの三角比は0°から180°までの図形の計量の道具であった。角を回転の量として一般角に広げ単位円上の点の座標で定義し直すと三角関数になる。加法定理を1本導けば2倍角・半角・合成はすべてそこから導ける。
第5章検証済み
微分係数と導関数
2点を結ぶ直線の傾きが平均変化率である。2点の間隔を限りなく0に近づけた極限が微分係数で接線の傾きと瞬間の速度を表す。x の値ごとに微分係数を対応させた関数が導関数で xⁿ の導関数は nxⁿ⁻¹ になる。
第6章検証済み
導関数の応用
導関数は接線の傾きを与えるので接線の方程式が書ける。導関数の符号は関数の増減を決め符号が変わる点で極大や極小になる。増減表を作れば3次関数のグラフ・最大最小・方程式の実数解の個数・不等式の証明を同じ手順で扱える。
第7章検証済み
積分と面積
微分すると f(x) になる関数を f(x) の原始関数と呼び原始関数を求める計算が不定積分である。原始関数の値の差が定積分で x=a から x=t までの面積を t で微分すると f(t) に戻ることから定積分は面積を表す。放物線と直線で囲まれた面積は 1/6 公式で一度に求まる。

数学B

第8章検証済み
数列と数学的帰納法
数列は自然数 n を入力として値を返す関数である。等差は足し算の繰り返しで等比は掛け算の繰り返しである。和の公式も漸化式の解法も同じ数列を2通りに並べて差をとる操作から導ける。

数学Ⅲ

第9章検証済み
極限
極限は「限りなく近づく先の値」を定める操作である。不定形は式を変形してから値を決める。r の n 乗の振る舞い・sin x / x → 1・e の定義の3つが数学Ⅲの微分の出発点になる。
第10章検証済み
微分法
積・商・合成・逆関数の4つの規則と sin x と log x の2つの導関数があれば高校で扱う関数はすべて微分できる。e は点 (0, 1) での傾きがちょうど1になる指数関数の底である。
第11章検証済み
微分法の応用
第10章で求めた導関数を使ってグラフの形を調べる。1回微分すると増減が分かり2回微分すると曲がり方が分かる。平均値の定理がこの2つを結び付け接線は近似式と速度の計算の基礎にもなる。
第12章検証済み
積分法
積分の公式はすべて微分の公式を逆に読んだものである。合成関数の微分法を逆に読むと置換積分法になり積の微分法を逆に読むと部分積分法になる。式の形を見て変形を選ぶ力がこの章の目標である。
終章検証済み
積分法の応用
面積も体積も曲線の長さも道のりも細かく分けた小さな量の和の極限であり定積分で表される。分け方を決めれば小さな1片の量を式にするだけで公式が導ける。
