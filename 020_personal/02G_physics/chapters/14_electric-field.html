電場と電位・コンデンサー

電荷のまわりの空間には電場があり電荷はその場から力を受ける。電場を位置エネルギーの言葉で書き直したものが電位である。コンデンサーは一様な電場に電荷とエネルギーを蓄える装置でありその容量は極板の形と間の物質だけで定まる。

第7章では電流と電気抵抗を扱いオームの法則と電力を確認した。そこでは電圧を電流を流す原因として扱いその中身には立ち入らなかった。この章では電荷が電荷に及ぼす力から出発し電場と電位を定義して電圧の意味を力学のエネルギーと同じ言葉で書き直す。後半ではその知識を使ってコンデンサーと直流回路を扱う。

共通テストの物理でこの範囲から出るのは主に5種類である。クーロンの法則による力の合成・点電荷の電場と電位・一様な電場の中での仕事・コンデンサーの容量と接続・静電エネルギーと誘電体の挿入である。第4章の仕事とエネルギーの考え方がそのまま使える。

クーロンの法則

物体がもつ電気の量を電気量または電荷と呼び単位はクーロン C である。電気量は正と負があり同符号の電荷は反発し異符号の電荷は引き合う。物体間で電荷が移動しても全体の電気量の和は変わらない。これを電気量保存の法則と呼ぶ。

距離 rr 離れた2つの点電荷 q1q_1 と q2q_2 の間に働く力の大きさは次のとおりである。これをクーロンの法則と呼ぶ。

F=kq1q2r2k=14πε0≒9.0×109 N⋅m2/C2F=k\frac{q_1q_2}{r^2}\qquad k=\frac{1}{4\pi\varepsilon_0}\fallingdotseq 9.0\times 10^{9}\ \mathrm{N\cdot m^2/C^2}

ε0≒8.85×10−12 F/m\varepsilon_0\fallingdotseq 8.85\times 10^{-12}\ \mathrm{F/m} を真空の誘電率と呼ぶ。力の向きは2つの電荷を結ぶ直線の方向である。力が距離の2乗に反比例するのは点から出る作用が半径 rr の球面全体に広がり球の表面積 4πr24\pi r^2 で薄まるからと考えると納得しやすい。万有引力も同じ形である。

3つ以上の電荷がある場合は 1組ずつ求めたクーロン力をベクトルとして合成する。これを重ね合わせの原理と呼ぶ。

例題 1

真空中で +1.0 μC+1.0\ \mathrm{\mu C} の点電荷2個を 0.30 m 離して置く。互いに及ぼす力の大きさと向きを求めよ。

解き方
F=9.0×109×(1.0×10−6)20.302F=9.0\times 10^{9}\times\dfrac{(1.0\times 10^{-6})^2}{0.30^2} である。
=9.0×109×1.0×10−120.090=0.10 N=9.0\times 10^{9}\times\dfrac{1.0\times 10^{-12}}{0.090}=0.10\ \mathrm{N} である。
答え 0.10 N の斥力である。同符号なので互いに遠ざかる向きに働く。

典型的な誤りは2つある。1つ目は距離を2乗し忘れる誤りである。距離が2倍になれば力は2分の1ではなく4分の1になる。2つ目は μC を C に直し忘れる誤りである。1 μC=10−6 C1\ \mathrm{\mu C}=10^{-6}\ \mathrm{C} である。

電場と電気力線

電荷のまわりの空間には他の電荷に力を及ぼす性質がある。この性質をもつ空間を電場と呼ぶ。電場は向きと大きさをもつベクトルで次のように定義する。+1 C の試験電荷を置いたときに受ける力がその点の電場 E⃗\vec{E} である。電荷 qq が受ける力は F⃗=qE⃗\vec{F}=q\vec{E} であり単位は N/C である。

点電荷 QQ から距離 rr の点の電場はクーロンの法則で q2=1q_2=1 とおけば得られる。

E=kQr2E=k\frac{Q}{r^2}

向きは Q>0Q\gt 0 なら QQ から離れる向きで Q<0Q\lt 0 なら QQ に向かう向きである。複数の電荷がつくる電場はベクトルの和になる。

電気力線

電場の向きをつないだ曲線を電気力線と呼ぶ。電気力線には次の性質がある。正の電荷から出て負の電荷に入る。途中で交わらず枝分かれもしない。電場の強さが EE の所では電場に垂直な面 1 m² あたり EE 本の電気力線が通ると約束する。この約束で点電荷 QQ から出る電気力線の総数を数えると半径 rr の球面で E×4πr2=4πkQE\times 4\pi r^2=4\pi kQ 本である。半径によらない一定値 Qε0\dfrac{Q}{\varepsilon_0} になる。これをガウスの法則と呼ぶ。コンデンサーの容量はこの数え方から導かれる。

例題 2

x 軸上の原点に +2.0×10−9 C+2.0\times 10^{-9}\ \mathrm{C} を置き x=0.60 mx=0.60\ \mathrm{m} に −2.0×10−9 C-2.0\times 10^{-9}\ \mathrm{C} を置く。中点 x=0.30 mx=0.30\ \mathrm{m} の電場を求めよ。

解き方
正電荷による電場は 9.0×109×2.0×10−90.302=200 N/C9.0\times 10^{9}\times\dfrac{2.0\times 10^{-9}}{0.30^2}=200\ \mathrm{N/C} で x 軸の正の向きである。
負電荷による電場も大きさ 200 N/C で負電荷に向かう x 軸の正の向きである。
同じ向きなので和は 400 N/C である。
答え x 軸の正の向きに 400 N/C である。

電位と電位差

重力の場で物体を持ち上げると位置エネルギーが増える。電場でも同じで電場に逆らって電荷を運ぶと静電気力による位置エネルギーが増える。電位は +1 C あたりの静電気力による位置エネルギーである。単位はボルト V で 1 V=1 J/C1\ \mathrm{V}=1\ \mathrm{J/C} である。2点の電位の差を電位差または電圧と呼ぶ。

U=qVWA→B=q(VA−VB)U=qV\qquad W_{\mathrm{A\to B}}=q(V_{\mathrm{A}}-V_{\mathrm{B}})

2つ目の式は電荷 qq が A から B へ移る間に静電気力がする仕事である。仕事は経路によらず両端の電位差だけで決まる。静電気力が重力と同じ保存力だからである。電位の基準はどこに置いてもよい。実用上は地面を 0 V としこれを接地またはアースと呼ぶ。

一様な電場と点電荷の電位

強さ EE の一様な電場の中を電場の向きに距離 dd 進むと電位は EdEd 下がる。+1 C を運ぶ力 EE と距離 dd の積が仕事だからである。

V=EdV=Ed

この式から電場の単位は V/m とも書ける。N/C と V/m は同じ単位である。点電荷 QQ のまわりでは無限遠を基準として距離 rr の点の電位は次のとおりである。電場が 1r2\dfrac{1}{r^2} に比例するのに対し電位は 1r\dfrac{1}{r} に比例する。

V=kQrV=k\frac{Q}{r}

電位が等しい点を連ねた面を等電位面と呼ぶ。等電位面の上で電荷を動かしても仕事は 0 なので電場は等電位面に垂直である。等電位面が密な所ほど電場は強い。地図の等高線が密な所ほど斜面が急なのと同じである。

例題 3

静止した電子を電位差 100 V で加速する。電子が得る運動エネルギーと速さを求めよ。電気素量 e=1.6×10−19 Ce=1.6\times 10^{-19}\ \mathrm{C} と電子の質量 9.1×10−31 kg9.1\times 10^{-31}\ \mathrm{kg} を使う。

=3.5×1013≒5.9×106 m/s=\sqrt{3.5\times 10^{13}}\fallingdotseq 5.9\times 10^{6}\ \mathrm{m/s} である。
答え運動エネルギーは 1.6×10−17 J で速さは約 5.9×106 m/s である。

電子1個を 1 V で加速したときのエネルギー 1.6×10−19 J1.6\times 10^{-19}\ \mathrm{J} を 1 電子ボルト 1 eV と呼ぶ。第16章で原子のエネルギーを表す単位として使う。

投資で言えば

電位は株価であり仕事は売買の損益である

損益は買値と売値の差だけで決まり途中の値動きの経路によらない。基準となる価格の水準をどこに置いても差は同じである。

導体と誘電体

金属のように自由に動ける電子をもつ物質を導体と呼ぶ。導体を電場の中に置くと自由電子が電場と逆向きに移動し導体の表面に正と負の電荷が現れる。これを静電誘導と呼ぶ。電子の移動は表面の電荷がつくる電場が外の電場を打ち消すまで続く。その結果として次の性質が成り立つ。

  • 導体の内部の電場は 0 である
  • 導体全体が等電位である
  • 電荷は導体の表面だけに分布する

中が空洞の導体では外部の電場が空洞の中に入らない。これを静電遮蔽と呼ぶ。電子機器を金属のケースで囲むのは外部の電場の影響を防ぐためである。

野球で言えば

金属の箱はドーム球場である

外でどれだけ風が吹いてもドームの中の風は 0 である。導体の壁は外の電場を表面の電荷で打ち消し内部の電場を 0 にする。

ガラスやゴムのように自由電子をもたない物質を不導体または誘電体と呼ぶ。誘電体を電場の中に置くと各分子の中で電子の分布がわずかに偏り分子が正負の向きをそろえる。その結果として表面に電荷が現れる。これを誘電分極と呼ぶ。現れた電荷は分子に束縛されていて取り出せない。誘電分極の電荷がつくる電場は外の電場と逆向きなので誘電体の内部の電場は弱まる。

恋愛で言えば

静電誘導は引っ越しであり誘電分極は向き直るだけである

導体の電子は導体の中を端まで実際に移り住む。誘電体の電子は自分の分子に留まったまま向きを変えるだけである。

箔検電器はこの性質を使って帯電を調べる器具である。負に帯電した棒を金属板に近づけると静電誘導で電子が箔へ移動し 2枚の箔が同符号に帯電して開く。

コンデンサーの電気容量と接続

2枚の導体板を向かい合わせて電荷を蓄える装置をコンデンサーまたはキャパシターと呼ぶ。極板に電圧 VV をかけると一方に +Q+Q で他方に −Q-Q が蓄えられ QQ は VV に比例する。比例定数 CC を電気容量と呼び単位はファラド F である。

Q=CVQ=CV

平行板コンデンサーの容量

面積 SS の極板を間隔 dd で平行に置く。極板の電荷 QQ から出る電気力線は Qε0\dfrac{Q}{\varepsilon_0} 本で極板間の面積 SS を一様に通る。1 m² あたりの本数が電場の強さなので E=Qε0SE=\dfrac{Q}{\varepsilon_0S} である。極板間の電位差は V=Ed=Qdε0SV=Ed=\dfrac{Qd}{\varepsilon_0S} である。Q=CVQ=CV と比べると次の式が得られる。

C=ε0SdC=\varepsilon_0\frac{S}{d}

容量は極板の面積に比例し間隔に反比例する。電圧や電荷の量にはよらない。極板間を比誘電率 εr\varepsilon_r の誘電体で満たすと誘電分極で内部の電場が 1εr\dfrac{1}{\varepsilon_r} に弱まり同じ電荷での電位差も 1εr\dfrac{1}{\varepsilon_r} になる。したがって容量は εr\varepsilon_r 倍になる。ε=εrε0\varepsilon=\varepsilon_r\varepsilon_0 を誘電率と呼ぶと C=εSdC=\varepsilon\dfrac{S}{d} である。平行板の式は極板の端で電場が広がる効果を無視した近似であり、間隔が面積に比べて小さいほど正確になる。誘電体が極板間の一部だけを占める場合は、並列や直列の合成として容量を計算する。

例題 4

面積 0.010 m² の極板を 1.0 mm の間隔で置いた空気コンデンサーの容量を求めよ。空気の誘電率は真空と同じ 8.85×10−12 F/m8.85\times 10^{-12}\ \mathrm{F/m} とする。

解き方
C=8.85×10−12×0.0101.0×10−3C=8.85\times 10^{-12}\times\dfrac{0.010}{1.0\times 10^{-3}} である。
=8.85×10−11 F=8.85\times 10^{-11}\ \mathrm{F} である。
答え約 89 pF である。1 F がいかに大きな単位かが分かる。

並列接続と直列接続

並列接続では各コンデンサーの電圧が等しく電荷の合計が全体の電荷になる。直列接続では各コンデンサーの電荷が等しく電圧の合計が全体の電圧になる。直列の各極板の電荷が等しいのは中間の極板どうしをつなぐ導線の部分が外から孤立していて電気量の和が 0 に保たれるからである。

並列 C=C1+C2直列 1C=1C1+1C2\text{並列}\ C=C_1+C_2\qquad \text{直列}\ \frac{1}{C}=\frac{1}{C_1}+\frac{1}{C_2}

抵抗の合成と式の形が逆になる。並列は極板の面積を足すことにあたり直列は間隔を足すことにあたると考えると式の形が説明できる。

例題 5

2.0 μF と 3.0 μF のコンデンサーを直列につなぎ 10 V の電池に接続する。合成容量と各コンデンサーの電荷と電圧を求めよ。

解き方
1C=12.0+13.0=56.0\dfrac{1}{C}=\dfrac{1}{2.0}+\dfrac{1}{3.0}=\dfrac{5}{6.0} で C=1.2 μFC=1.2\ \mathrm{\mu F} である。
電荷は共通で Q=1.2×10=12 μCQ=1.2\times 10=12\ \mathrm{\mu C} である。
電圧は 122.0=6.0 V\dfrac{12}{2.0}=6.0\ \mathrm{V} と 123.0=4.0 V\dfrac{12}{3.0}=4.0\ \mathrm{V} である。
答え合成容量 1.2 μF ／ 電荷はどちらも 12 μC ／ 電圧は 6.0 V と 4.0 V である。容量が小さい方に大きな電圧がかかる。

静電エネルギー

コンデンサーを充電するには電荷を一方の極板から他方の極板へ電場に逆らって運ぶ仕事が要る。電荷が qq まで蓄えられたときの電圧は v=qCv=\dfrac{q}{C} で少量 Δq\Delta q を運ぶ仕事は vΔqv\Delta q である。電荷 0 から QQ までの仕事の合計は Q-V グラフの三角形の面積に等しい。

U=12QV=12CV2=Q22CU=\frac{1}{2}QV=\frac{1}{2}CV^2=\frac{Q^2}{2C}

電池がした仕事は QVQV であるが蓄えられるのはその半分の 12QV\dfrac{1}{2}QV である。電池は電荷 QQ を常に一定の電圧 VV で送り出すからである。差の 12QV\dfrac{1}{2}QV は導線の抵抗でジュール熱になる。抵抗の大きさによらず半分が熱になる。

会計で言えば

充電は支出 QV に対し資産計上が半分の取引である

電池からの支出 QV のうち貸借対照表に残るのは ½QV で残りはジュール熱として費用になる。

誘電体の挿入と2つの条件

コンデンサーの問題では何が一定に保たれるかを最初に確認する。電池につないだまま操作すると電圧 VV が一定である。電池から切り離して操作すると電荷 QQ が一定である。比誘電率 εr\varepsilon_r の誘電体を極板間に満たすと次のように変わる。

条件容量電荷電圧静電エネルギー
電池につないだままεr 倍εr 倍変わらないεr 倍
電池から切り離すεr 倍変わらない1/εr 倍1/εr 倍
例題 6

2.0 μF のコンデンサーを 100 V で充電する。蓄えられる静電エネルギーと充電の間に電池がした仕事を求めよ。

解き方
U=12×2.0×10−6×1002=1.0×10−2 JU=\dfrac{1}{2}\times 2.0\times 10^{-6}\times 100^2=1.0\times 10^{-2}\ \mathrm{J} である。

答え静電エネルギー 0.010 J ／ 電池の仕事 0.020 J である。差の 0.010 J はジュール熱である。

直流回路とキルヒホッフの法則

学習指導要領は電場とコンデンサーと同じ項目で電気回路を扱うと定めている。複数の電池と抵抗を含む回路ではオームの法則だけでは電流が求まらない。次の2つの法則を使う。

  • 第1法則 回路の分岐点に流れ込む電流の和と流れ出る電流の和は等しい。電気量保存の法則を表す
  • 第2法則 回路の任意の閉じた道筋に沿って一周すると起電力の和は電圧降下 RIRI の和に等しい。一周すると電位は元に戻ることを表す

実際の電池には内部抵抗 rr がある。起電力 EE の電池から電流 II を取り出すと端子間の電圧は V=E−rIV=E-rI に下がる。

例題 7

起電力 6.0 V の電池 E1 と 2.0 Ω の抵抗 R1 の枝 ／ 起電力 4.0 V の電池 E2 と 1.0 Ω の抵抗 R2 の枝 ／ 2.0 Ω の抵抗 R3 だけの枝の3本が 2つの分岐点の間に並列につながっている。2つの電池はどちらも同じ分岐点側に正極を向けている。電池の内部抵抗は無視する。各枝の電流を求めよ。

解き方
E1 と E2 の枝を正極の向きに流れる電流を I1I_1 と I2I_2 とし R3 の電流を I3I_3 とする。
第1法則より I3=I1+I2I_3=I_1+I_2 である。
E1 と R3 を通る道筋で 6.0=2.0I1+2.0I36.0=2.0I_1+2.0I_3 である。
E2 と R3 を通る道筋で 4.0=1.0I2+2.0I34.0=1.0I_2+2.0I_3 である。
I1=3.0−I3I_1=3.0-I_3 と I2=4.0−2.0I3I_2=4.0-2.0I_3 を第1法則に代入して I3=7.0−3.0I3I_3=7.0-3.0I_3 より I3=1.75 AI_3=1.75\ \mathrm{A} である。
答え I1=1.25 AI_1=1.25\ \mathrm{A} ／ I2=0.50 AI_2=0.50\ \mathrm{A} ／ I3=1.75 AI_3=1.75\ \mathrm{A} である。

コンデンサーを含む直流回路では十分に時間がたつとコンデンサーに電流は流れない。その枝の抵抗の電圧降下は 0 になりコンデンサーの電圧は並列につながる部分の電圧に等しい。スイッチを入れた直後はコンデンサーの電荷が 0 なので電圧も 0 で導線と同じに扱う。

半導体の pn 接合をもつダイオードは一方の向きにだけ電流をよく通す。この性質は交流を直流に変える整流に使われる。第15章の交流と組み合わせて用いられる素子である。

スマートフォンの画面の多くは静電容量方式のタッチパネルである。画面の下に透明な電極が格子状に並び電極どうしの間にコンデンサーが形成されている。

現実世界

指は水分を多く含む導体である。指が画面に近づくと電極の電場の一部が指へ向かい電極間の容量が変化する。回路はこの変化を格子の各点で測り触れた位置を算出する。手袋をした指や乾いたペン先で反応しないのは容量を変えるほどの導体が近づかないからである。

確認問題

問1 ・ クーロンの法則

2つの点電荷の間に大きさ FF の力が働いている。一方の電荷を3倍にし距離を2倍にすると力の大きさはいくらか。

  1. 34F\dfrac{3}{4}F
  2. 32F\dfrac{3}{2}F
  3. 6F6F
  4. 12F12F
解答と解説
正解は 1 である。力は電荷の積に比例し距離の2乗に反比例する。3×122=343\times\dfrac{1}{2^2}=\dfrac{3}{4} 倍である。
問2 ・ 電場の合成

原点に +2.0×10−9 C+2.0\times 10^{-9}\ \mathrm{C} を置き x=0.60 mx=0.60\ \mathrm{m} に +2.0×10−9 C+2.0\times 10^{-9}\ \mathrm{C} を置く。中点の電場の強さは何 N/C か。k=9.0×109 N⋅m2/C2k=9.0\times 10^{9}\ \mathrm{N\cdot m^2/C^2} とする。

  1. 0
  2. 200
  3. 400
  4. 800
解答と解説
正解は 1 である。各電荷による電場の大きさは 200 N/C で等しいがどちらも中点から見て電荷と反対の向きを向くので逆向きで打ち消し合う。例題2のように片方が負なら 400 N/C になる。
問3 ・ 電位差と仕事

電位 30 V の点 A から電位 80 V の点 B まで +2.0 μC+2.0\ \mathrm{\mu C} の電荷をゆっくり運ぶ。外力がする仕事は何 J か。

  1. 6.0×10−56.0\times 10^{-5}
  2. 1.0×10−41.0\times 10^{-4}
  3. 1.6×10−41.6\times 10^{-4}
  4. 2.2×10−42.2\times 10^{-4}
解答と解説
正解は 2 である。ゆっくり運ぶので外力の仕事は位置エネルギーの増加に等しい。q(VB−VA)=2.0×10−6×50=1.0×10−4 Jq(V_{\mathrm{B}}-V_{\mathrm{A}})=2.0\times 10^{-6}\times 50=1.0\times 10^{-4}\ \mathrm{J} である。経路によらない。
問4 ・ 電気容量

平行板コンデンサーの極板の面積を2倍にし間隔を半分にし極板間を比誘電率2の誘電体で満たす。容量は元の何倍か。

  1. 2
  2. 4
  3. 8
  4. 16
解答と解説
正解は 3 である。C=εrε0SdC=\varepsilon_r\varepsilon_0\dfrac{S}{d} より 2×2×2=82\times 2\times 2=8 倍である。
問5 ・ 直列接続

3.0 μF と 6.0 μF のコンデンサーを直列につなぎ 12 V の電圧をかける。3.0 μF のコンデンサーにかかる電圧は何 V か。

  1. 4.0
  2. 6.0
  3. 8.0
  4. 12
解答と解説
正解は 3 である。合成容量は 1C=13.0+16.0\dfrac{1}{C}=\dfrac{1}{3.0}+\dfrac{1}{6.0} で 2.0 μF である。共通の電荷は 24 μC で 3.0 μF の電圧は 243.0=8.0 V\dfrac{24}{3.0}=8.0\ \mathrm{V} である。
問6 ・ 静電エネルギー

4.0 μF のコンデンサーを 50 V で充電した。蓄えられた静電エネルギーは何 J か。

  1. 1.0×10−41.0\times 10^{-4}
  2. 2.0×10−42.0\times 10^{-4}
  3. 5.0×10−35.0\times 10^{-3}
  4. 1.0×10−21.0\times 10^{-2}
解答と解説
正解は 3 である。12CV2=12×4.0×10−6×2500=5.0×10−3 J\dfrac{1}{2}CV^2=\dfrac{1}{2}\times 4.0\times 10^{-6}\times 2500=5.0\times 10^{-3}\ \mathrm{J} である。4 は電池の仕事 QVQV にあたる。
問7 ・ 誘電体の挿入

充電したコンデンサーを電池から切り離し極板間を比誘電率2の誘電体で満たした。正しい記述を1つ選べ。

  1. 極板の電荷は2倍になる
  2. 極板間の電圧は2倍になる
  3. 静電エネルギーは半分になる
  4. 極板間の電場は変わらない
解答と解説
正解は 3 である。切り離したので電荷 QQ は一定である。容量が2倍なので電圧は半分で電場も半分になる。U=Q22CU=\dfrac{Q^2}{2C} より静電エネルギーは半分になる。減った分は誘電体を引き込む静電気力の仕事に使われる。
問8 ・ 内部抵抗

起電力 3.0 V で内部抵抗 1.0 Ω の電池に 5.0 Ω の抵抗をつなぐ。電池の端子電圧は何 V か。

  1. 2.0
  2. 2.5
  3. 3.0
  4. 3.6
解答と解説
正解は 2 である。電流は 3.01.0+5.0=0.50 A\dfrac{3.0}{1.0+5.0}=0.50\ \mathrm{A} である。端子電圧は 3.0−1.0×0.50=2.5 V3.0-1.0\times 0.50=2.5\ \mathrm{V} である。

この章の要点

要点 クーロンの法則 F = kq₁q₂/r² で k ≒ 9.0×10⁹ N·m²/C² である。力はベクトルとして合成する。
電場は +1 C が受ける力である。点電荷の電場は E = kQ/r² で電気力線は1 m²あたり E 本と約束する。
電位は +1 C あたりの位置エネルギーである。仕事は W = q(VA − VB) で経路によらない。一様な電場では V = Ed である。
導体の内部は電場 0 で全体が等電位である。誘電体は分極して内部の電場を弱める。
Q = CV ／ C = εS/d ／ 並列は和 ／ 直列は逆数の和である。
静電エネルギーは ½CV² で電池の仕事 QV の半分である。電池につないだままなら V 一定 ／ 切り離せば Q 一定である。
キルヒホッフの第1法則は電気量保存 ／ 第2法則は一周して電位が戻ることを表す。

考えるための問い

答えが一つに定まらない問いを挙げた。手がかりは本文の内容から示した。

  • 電場は実在するものか、力を計算するための道具か。 本文は電場を電荷のまわりの空間がもつ性質とし、その大きさを+1 C の試験電荷が受ける力で定義した。一方で電気力線の本数は約束として定めたものであり、本文はその数え方からコンデンサーの容量を導いた。
  • 電位の基準をどこに置いてもよいなら、電位の値そのものに意味はあるか。 本文は電位の基準をどこに置いてもよいとし、仕事は両端の電位差だけで決まるとした。実用上は地面を0 V とし、点電荷では無限遠を基準とする。
