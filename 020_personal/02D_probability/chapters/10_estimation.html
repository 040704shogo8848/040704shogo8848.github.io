標本調査と推定

母集団から無作為に n 個を取り出すと標本平均の期待値は母平均 m で標準偏差は σ/√n になる。n が大きいと標本平均は正規分布に近い分布に従う。この2つの事実から標本平均の前後に 1.96σ/√n の幅をとった区間が母平均の95%信頼区間になる。

この章は2026-10-15に出典照合を通した。 検証した事実は37件である。出典と一致したものは35件である。食い違ったものは1件で本文を修正済みである。出典で確認できなかったものは1件である。これらは末尾の「残っている問い」に列挙した。

第8章と第9章では分布がわかっている確率変数について確率を計算した。この章では向きを逆にする。分布の中心がわからない集団から一部を取り出しその一部から集団全体の平均や比率を見積もる。これが推定である。

共通テストの「統計的な推測」の大問は母集団分布の設定から始まり標本平均の期待値と標準偏差を求め正規分布で近似して信頼区間を作る流れが多い。この章の公式 E(X‾\overline{X})＝m と σ(X‾\overline{X})＝σ/√n と信頼区間の式がその中心である。第11章の仮説検定も同じ公式を使う。

全数調査と標本調査

調査の対象となる集団全体を母集団と呼ぶ。母集団のすべてを調べる調査を全数調査と呼び母集団の一部を取り出して調べる調査を標本調査と呼ぶ。取り出した一部を標本と呼び標本を取り出すことを抽出と呼ぶ。母集団の要素の個数を母集団の大きさと呼び標本の要素の個数を標本の大きさと呼ぶ。

全数調査を行う例
  • 国勢調査
  • 学校の健康診断
  • 漏れが許されず全員を調べられる場合
標本調査を行う例
  • 内閣支持率の世論調査 ／ テレビの視聴率
  • 缶詰や電球の品質検査 調べると製品が使えなくなる
  • 費用と時間の制約で全員を調べられない場合

標本調査で母集団の性質を正しく推測するには標本が母集団の縮図でなければならない。そのために母集団のどの要素も等しい確率で選ばれるように抽出する。この方法を無作為抽出と呼び無作為抽出で得た標本を無作為標本と呼ぶ。無作為抽出には乱数さい・乱数表・コンピュータで発生させた乱数を使う。

1個取り出すたびに元に戻してから次を取り出す抽出を復元抽出と呼ぶ。戻さずに続ける抽出を非復元抽出と呼ぶ。復元抽出では各回の結果が独立である。非復元抽出でも母集団の大きさが標本の大きさに比べて十分大きければ取り出すたびの変化は無視できるので復元抽出と同じように扱う。

典型的な誤りは標本を大きくすれば偏った抽出でも正しく推定できると考える誤りである。標本の大きさは偶然の誤差を小さくするだけで抽出方法の偏りは除けない。第7節の実例がその例である。

母集団分布

母集団の各要素がもつ数値を変量と呼ぶ。母集団から1個を無作為に取り出したときの変量の値を X とすると X は確率変数である。X の確率分布を母集団分布と呼ぶ。母集団分布の期待値を母平均と呼び m で表す。分散と標準偏差をそれぞれ母分散と母標準偏差と呼び σ² と σ で表す。

母集団分布は母集団の度数分布の相対度数をそのまま確率としたものである。したがって母平均は母集団全体の平均に等しく母分散は母集団全体の分散に等しい。

例題 1

1 と書かれたカードが2枚・2 と書かれたカードが3枚・3 と書かれたカードが5枚ある。この10枚を母集団とし数字を変量とする。母集団分布と母平均と母標準偏差を求めよ。

解き方
手順1 1枚取り出したときの数字 X の分布は P(X＝1)＝0.2・P(X＝2)＝0.3・P(X＝3)＝0.5 である。
手順2 m=1×0.2+2×0.3+3×0.5=2.3m=1\times 0.2+2\times 0.3+3\times 0.5=2.3
手順3 E(X2)=0.2+1.2+4.5=5.9E(X^2)=0.2+1.2+4.5=5.9 なので σ2=5.9−2.32=0.61\sigma^2=5.9-2.3^2=0.61
手順4 σ=0.61≒0.78\sigma=\sqrt{0.61}\fallingdotseq 0.78。答え 母平均 2.3・母標準偏差 約0.78

標本平均の期待値と標準偏差

母平均 m・母標準偏差 σ の母集団から大きさ n の無作為標本を復元抽出する。k 番目に取り出した値を XkX_k とする。X1,X2,…,XnX_1, X_2, \ldots, X_n はどれも母集団分布に従い互いに独立である。これらの平均を標本平均と呼び X‾\overline{X} で表す。

X‾=X1+X2+⋯+Xnn\overline{X}=\frac{X_1+X_2+\cdots+X_n}{n}

標本平均は抽出のたびに値が変わる確率変数である。第8章の公式から期待値と分散が求まる。

  • 和の期待値は和なので E(X1+⋯+Xn)=nmE(X_1+\cdots+X_n)=nm である。これを n で割り E(X‾)=mE(\overline{X})=m
  • 独立なので和の分散は和で V(X1+⋯+Xn)=nσ2V(X_1+\cdots+X_n)=n\sigma^2 である。1/n 倍すると分散は 1/n² 倍になり V(X‾)=nσ2n2=σ2nV(\overline{X})=\frac{n\sigma^2}{n^2}=\frac{\sigma^2}{n}
E(X‾)=m,V(X‾)=σ2n,σ(X‾)=σnE(\overline{X})=m ,\qquad V(\overline{X})=\frac{\sigma^2}{n} ,\qquad \sigma(\overline{X})=\frac{\sigma}{\sqrt{n}}

標本平均は平均すると母平均に一致しその散らばりは標本の大きさの平方根に反比例して小さくなる。n を4倍にすると標準偏差は半分になる。n を100倍にすると10分の1になる。

例題 2

例題1の母集団から大きさ25の標本を復元抽出する。標本平均の期待値と標準偏差を求めよ。

解き方
手順1 E(X‾)=m=2.3E(\overline{X})=m=2.3
手順2 σ(X‾)=0.6125=0.615≒0.156\sigma(\overline{X})=\frac{\sqrt{0.61}}{\sqrt{25}}=\frac{\sqrt{0.61}}{5}\fallingdotseq 0.156。答え 期待値 2.3・標準偏差 約0.16

典型的な誤りは2つある。1つ目は σ(X‾\overline{X}) を σ/n とする誤りである。n で割るのは分散のほうで標準偏差は √n で割る。2つ目は σ(X‾\overline{X}) と母標準偏差 σ を取り違える誤りである。問題文の「標本平均の標準偏差」と「母標準偏差」を区別して読む。

恋愛で言えば

相手の印象の精度は会った回数の平方根でしか上がらない

1回のデートの印象は大きさ1の標本である。4回会えば印象の平均の誤差は半分になり16回で4分の1になる。

大数の法則と中心極限定理

大数の法則

σ(X‾\overline{X})＝σ/√n は n を大きくすると0に近づく。標本平均の散らばりがなくなり標本平均は母平均の近くに集まる。この事実を大数の法則と呼ぶ。

大数の法則 母平均 m の母集団から大きさ n の無作為標本を抽出する。n を大きくすると標本平均 X‾\overline{X} が m に近い値をとる確率は1に近づく。

硬貨の表を1・裏を0とする母集団では母平均は 0.5 で標本平均は表の相対度数である。投げる回数を増やすと相対度数は 0.5 に近づく。確率を多数回の試行での相対度数と結びつける根拠がこの法則である。

中心極限定理

大数の法則は標本平均が母平均に近づくことを示す。中心極限定理はその近づき方の分布の形を示す。高校では次の形で扱う。

標本平均の分布 母平均 m・母標準偏差 σ の母集団から大きさ n の無作為標本を抽出する。n が大きいとき標本平均 X‾\overline{X} は近似的に正規分布 N(m, σ²/n) に従う。母集団分布が正規分布でなくても成り立つ。

第9章で二項分布が正規分布で近似できたのはこの定理の特別な場合である。二項分布は 0 か 1 をとる母集団からの標本の和だからである。母集団分布が正規分布なら n の大きさによらず X‾\overline{X} は正確に N(m, σ²/n) に従う。

例題 3

母平均60・母標準偏差12の母集団から大きさ36の無作為標本を抽出する。標本平均が63以上になる確率を求めよ。

解き方
手順1 σ(X‾)=12/36=2\sigma(\overline{X})=12/\sqrt{36}=2 で X‾\overline{X} は近似的に N(60, 2²) に従う。
手順2 標準化すると Z=(63−60)/2=1.5Z=(63-60)/2=1.5 である。
手順3 P(X‾≥63)=P(Z≥1.5)=0.5−0.4332=0.0668P(\overline{X}\ge 63)=P(Z\ge 1.5)=0.5-0.4332=0.0668。答え 約0.0668

典型的な誤りは標本平均の標準化に母標準偏差 σ をそのまま使う誤りである。例題3で12で割ると Z＝0.25 になる。標本平均の標準化の分母は σ/√n である。

野球で言えば

開幕10打席の打率4割は大数の法則の手前である

真の打率 .270 の打者でも10打数なら標準偏差は約 .140 ある。500打数で約 .020 まで縮みシーズン打率は実力に近づく。

母平均の推定

母平均 m がわからないときに標本平均から m を含む範囲を求める。n が大きいとき X‾\overline{X} は近似的に N(m, σ²/n) に従うので次の式が成り立つ。

P(−1.96≤X‾−mσ/n≤1.96)=2×0.4750=0.95P\left(-1.96\le\frac{\overline{X}-m}{\sigma/\sqrt{n}}\le 1.96\right)=2\times 0.4750=0.95

かっこの中の不等式を m について解くと次の形になる。

P(X‾−1.96σn≤m≤X‾+1.96σn)=0.95P\left(\overline{X}-1.96\frac{\sigma}{\sqrt{n}}\le m\le\overline{X}+1.96\frac{\sigma}{\sqrt{n}}\right)=0.95

標本から得た X‾\overline{X} の値を代入した区間を母平均 m に対する信頼度95%の信頼区間と呼ぶ。区間の端の値を求めて母平均を幅で示すことを区間推定と呼ぶ。

母平均の信頼区間 信頼度95% ・ X‾\overline{X}−1.96 σ/√n ≤ m ≤ X‾\overline{X}＋1.96 σ/√n
信頼度99% ・ X‾\overline{X}−2.58 σ/√n ≤ m ≤ X‾\overline{X}＋2.58 σ/√n
母標準偏差 σ が未知で n が大きいときは σ の代わりに標本の標準偏差を使う。

信頼度99%で 2.58 を使うのは 2×p(2.58)＝2×0.4951≒0.99 だからである。信頼度を上げると区間は広がり n を大きくすると区間は狭まる。区間の幅は 2×1.96σ/√n なので幅を半分にするには n を4倍にする。

信頼度95%の意味は図4のとおりである。同じ方法で何度も標本を取り区間を作ると全体の約95%の区間が母平均を含む。母平均は定数で区間のほうが標本ごとに動く。ある1つの区間を作った後でその区間が m を含むかどうかは含むか含まないかのどちらかである。

例題 4

ある工場の製品から100個を無作為に抽出すると重さの平均が 52.3 g で標準偏差が 8 g であった。製品全体の重さの母平均を信頼度95%で推定せよ。

解き方
手順1 n＝100 は大きいので母標準偏差の代わりに 8 を使う。σ/n=8/10=0.8\sigma/\sqrt{n}=8/10=0.8
手順2 1.96×0.8=1.5681.96\times 0.8=1.568
手順3 52.3−1.568=50.73252.3-1.568=50.732 と 52.3+1.568=53.86852.3+1.568=53.868。答え 50.7 g 以上 53.9 g 以下
例題 5

母標準偏差が10とわかっている母集団で母平均を信頼度95%で推定する。信頼区間の幅を2以下にするには標本の大きさ n をいくつ以上にすればよいか。

解き方
手順1 幅は 2×1.96×10n2\times 1.96\times\frac{10}{\sqrt{n}} である。これが2以下になる条件は 19.6n≤1\frac{19.6}{\sqrt{n}}\le 1 である。
手順2 n≥19.6\sqrt{n}\ge 19.6 で n≥384.16n\ge 384.16 である。
手順3 n は整数なので 385 以上。答え 385

典型的な誤りは「この区間に母平均が入る確率は95%である」と書く誤りである。95%は区間を作る方法の成功率を表す。もう1つは例題5で 384.16 を切り捨てて 384 とする誤りである。条件を満たすのは切り上げた整数である。

スタートアップで言えば

アンケートの誤差を半分にするには回答者を4倍集める

信頼区間の幅は √n に反比例する。100人の調査を400人に増やしてやっと幅が半分になる。

母比率の推定

母集団の中である性質 A をもつ要素の割合を母比率と呼び p で表す。大きさ n の標本の中で A をもつ要素の割合を標本比率と呼び R で表す。A をもつ要素の個数を X とすると R＝X/n である。

A をもつ要素を1・もたない要素を0とする母集団を考えるとこの母集団の母平均は p で母分散は p(1−p) である。標本比率 R はこの母集団からの標本平均である。したがって第3節の公式がそのまま使える。X は B(n, p) に従うので次のようにも確かめられる。

E(R)=E(X)n=npn=p,σ(R)=np(1−p)n=p(1−p)nE(R)=\frac{E(X)}{n}=\frac{np}{n}=p ,\qquad \sigma(R)=\frac{\sqrt{np(1-p)}}{n}=\sqrt{\frac{p(1-p)}{n}}

n が大きいとき R は近似的に N(p, p(1−p)/n) に従う。母平均の場合と同じ手順で信頼区間が得られる。σ(R) の中の p は未知なので標本比率 R で置き換える。

母比率の信頼区間 信頼度95% ・ R−1.96√(R(1−R)/n) ≤ p ≤ R＋1.96√(R(1−R)/n)
例題 6

ある政策について400人を無作為に抽出して調べると160人が賛成した。賛成の母比率を信頼度95%で推定せよ。

解き方
手順1 R=160/400=0.4R=160/400=0.4
手順2 0.4×0.6400=0.0006≒0.0245\sqrt{\frac{0.4\times 0.6}{400}}=\sqrt{0.0006}\fallingdotseq 0.0245
手順3 1.96×0.0245≒0.0481.96\times 0.0245\fallingdotseq 0.048 なので区間は 0.4−0.048 から 0.4＋0.048 である。答え 0.352 以上 0.448 以下

典型的な誤りは √ の中の n を外に出し忘れる誤りと R(1−R) の代わりに R を使う誤りである。標本比率の標準偏差は二項分布の標準偏差 √(np(1−p)) を n で割ったものであることから組み立て直せる。

現実世界の標本調査

標本の大きさより抽出の無作為性が重要であることを示した例が1936年のアメリカ大統領選挙の予測である。

200万超リテラリー・ダイジェスト誌の回収数
約5万ギャラップの標本の大きさ
60.8%ルーズベルトの実際の得票率
現実世界

リテラリー・ダイジェスト誌は約1000万人に投票用紙を郵送し200万通以上を回収した。結果は共和党のランドンが得票率約57%で勝つという予測であった。実際はルーズベルトが60.8%を得て圧勝した。宛先を電話帳や自動車の登録名簿などから選んだため標本が母集団の縮図になっていなかったことが原因とされる。約5万人の標本を使ったギャラップはルーズベルトの勝利を当てた。

確認問題

問1 ・ 調査の方法

次の調査のうち全数調査で行うのが適当なものを1つ選べ。

  1. ある缶詰工場の製品の品質検査
  2. 国内の全世帯と人口を把握する国勢調査
  3. テレビ番組の視聴率調査
  4. 内閣支持率の世論調査
解答と解説
正解は 2 である。1 は調べると製品が使えなくなるので標本調査で行う。3 と 4 は費用と時間の制約から標本調査で行う。
問2 ・ 標本平均の期待値と標準偏差

母平均50・母標準偏差20の母集団から大きさ100の無作為標本を抽出する。標本平均の期待値と標準偏差の組として正しいものを1つ選べ。

  1. 期待値 50・標準偏差 0.2
  2. 期待値 50・標準偏差 2
  3. 期待値 5・標準偏差 2
  4. 期待値 50・標準偏差 20
解答と解説
正解は 2 である。期待値は母平均の50のままである。標準偏差は 20/√100＝2 である。1 は σ/n とした誤りである。
問3 ・ 標本平均の確率

問2の標本平均 X‾\overline{X} について P(46≤X‾\overline{X}≤53) を小数第4位まで答えよ。

解答と解説
正解は 0.9104 である。X‾\overline{X} は近似的に N(50, 2²) に従う。46 は Z＝−2 で 53 は Z＝1.5 である。p(2)＋p(1.5)＝0.4772＋0.4332＝0.9104
問4 ・ 母平均の信頼区間

母標準偏差16の母集団から大きさ64の標本を取り出すと標本平均は120であった。母平均の95%信頼区間として正しいものを1つ選べ。

  1. 116.08 ≤ m ≤ 123.92
  2. 118.04 ≤ m ≤ 121.96
  3. 119.51 ≤ m ≤ 120.49
  4. 88.64 ≤ m ≤ 151.36
解答と解説
正解は 1 である。σ/√n＝16/8＝2 で 1.96×2＝3.92 である。2 は σ/√n を掛け忘れて 1.96 だけを足し引きした誤りである。3 は σ/n＝0.25 を使った誤りで 4 は σ をそのまま使った誤りである。
問5 ・ 必要な標本の大きさ

母標準偏差15の母集団の母平均を信頼度95%で推定する。信頼区間の幅を4以下にするのに必要な標本の大きさの最小値を答えよ。

解答と解説
正解は 217 である。幅は 2×1.96×15/√n で 4 以下になる条件は √n≥14.7 である。n≥216.09 なので最小の整数は217である。
問6 ・ 母比率の信頼区間

900人を無作為に抽出して調べると270人がある商品を知っていた。商品を知っている人の母比率の95%信頼区間に最も近いものを1つ選べ。

  1. 0.270 ≤ p ≤ 0.330
  2. 0.285 ≤ p ≤ 0.315
  3. 0.261 ≤ p ≤ 0.339
  4. 0.296 ≤ p ≤ 0.304
解答と解説
正解は 1 である。R＝0.3 で √(0.3×0.7/900)＝√0.000233≒0.0153 である。1.96×0.0153≒0.030 なので 0.270 から 0.330 である。2 は 1.96 を掛け忘れた幅で 3 は 2.58 を使った99%の区間である。
問7 ・ 信頼度95%の意味

母平均 m の95%信頼区間について正しい記述を1つ選べ。

  1. 母集団の95%の要素の値がこの区間に入る
  2. 同じ方法で区間を何度も作るとその約95%が m を含む
  3. 標本の95%の値がこの区間に入る
  4. m はこの区間の中を95%の確率で動く
解答と解説
正解は 2 である。信頼区間は母平均の範囲を示すもので個々の値の範囲ではない。m は動かない定数で動くのは標本ごとに作られる区間である。
問8 ・ 幅と標本の大きさ

標本の大きさ100で作った95%信頼区間の幅が W であった。同じ母集団で標本の大きさを400にすると幅はいくらになるか。

解答と解説
正解は W/2 である。幅は 1/√n に比例する。n が4倍になると √n は2倍なので幅は半分になる。

この章の要点

要点 標本調査では無作為抽出で母集団の縮図となる標本を得る。
母集団から1個取り出した値の分布が母集団分布で期待値が母平均 m である。
標本平均は E(X‾\overline{X})＝m・σ(X‾\overline{X})＝σ/√n で n を4倍にすると散らばりは半分になる。
大数の法則 n を大きくすると X‾\overline{X} は m に近づく。n が大きいと X‾\overline{X} は近似的に N(m, σ²/n) に従う。
母平均の95%信頼区間は X‾\overline{X}±1.96σ/√n で99%は 2.58 を使う。
母比率の95%信頼区間は R±1.96√(R(1−R)/n) である。

残っている問い

  • σ の代わりに標本の標準偏差を使う場合に大学の統計学では n が小さいと t 分布を使う。高校では n が大きいとして正規分布で近似する。
  • 標本の標準偏差を n で割って求めるか n−1 で割って求めるかは教科書によって扱いが分かれる。n が大きい場合は結果の差は小さい。
  • 学習指導要領解説の数学Bの記述には中心極限定理という名称は現れない。解説は n が十分大きければ標準化した標本平均の分布を標準正規分布とみなせるという事実を証明なしに用いる。名称を本文で用いるかどうかは教科書によって異なる。
  • リテラリー・ダイジェスト誌の回収数は約227万から約238万まで出典によって異なる。本文では200万通以上と記した。
  • リテラリー・ダイジェスト誌の予測が外れた原因は宛先名簿の偏りと回答者の自己選択の両方が挙げられる。両者の寄与の大きさは出典によって評価が異なる。
