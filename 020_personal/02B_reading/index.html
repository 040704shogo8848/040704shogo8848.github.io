Reading

本と論考の読書ノート。要約ではなく、その本について流通している説明が原典とどこでずれているかを書く。

ネタバレの有無は各ページの冒頭に明示している。出典は各ページ末尾にまとめ、裏が取れなかった事項は未確認事項として残す。

  • 2026-10-11 / 順路
    4冊の順路 自分と他者の境界から世界の意味づけまで
    Aさんから推薦された4冊を、2つの主題と読む順序で並べる。4冊は、手順や技法の当てはめを「理解」や「変化」と見なすことを退ける点で共通する。取扱説明書の資質と4冊の対応を1つの表に集めた。
    4冊 合計1,320頁4冊とも未読
  • 2026-10-11 / 補論
    自己変容型知性 相対化しながら当事者でいられるか
    キーガンの第5次元は、価値観を捨てた相対主義ではない。自分の体系を持ったまま、その不完全さを扱える状態を指す。面接研究では、相対化を語りつつ大きな構想を確信して語る人は、むしろ1つ手前の段階だった。
    Kegan 2000 / Berger 2005「1%」は出典未確認
  • 2026-10-11 / 読書ノート 順路1
    アービンジャー・インスティチュート『自分の小さな「箱」から脱出する方法』読書ノート
    箱は思い込みではない。すべきと感じたことに背く「自分への裏切り」から始まる自己欺瞞である。原著第1版と第2版の本文から物語を9段階で追い、読み終えた後の6つの問いに原典で答える。
    大和書房 20062026年5月に新版本書は未読
  • 2026-10-11 / 読書ノート 順路2
    ちきりん『自分のアタマで考えよう』読書ノート
    知識を捨てる本ではない。序章で知識が結論を先取りする現象を示し、終章で知識を「思考の棚」として結び直す。プロ野球、新規事業会議、婚活、省庁の命名、9・11報道まで、全11部の具体例を章ごとに追う。
    ダイヤモンド社 2011単独18万部本書は未読
  • 2026-10-11 / 読書ノート 順路3
    クリスチャン・マスビアウ『センスメイキング』読書ノート
    カール・ワイクの同名の組織論とは別物で、基盤はハイデガーにある。反データの本でもない。フォード、ソロス、ナパのワイン醸造家まで、章ごとの事例で5原則を追い、割れている海外の書評を並べる。
    プレジデント社 2018Goodreads 3.65本書は未読
  • 2026-10-11 / 読書ノート 順路4
    ロバート・キーガン リサ・ラスコウ・レイヒー『なぜ人と組織は変われないのか』読書ノート
    免疫マップは4列を記入して終わる道具ではない。原書第8〜10章の本文から、David と Cathy の固定観念が検証で書き換わる過程を追う。版元の85%という数字は、原著の7人に1人と一致しない。
    英治出版 2013440頁本書は未読
  • 2026-10-05 / 読書ノート
    関本剛『がんになった緩和ケア医が語る「残り2年」の生き方、考え方』読書ノート
    タイトルの2年は宣告された余命ではない。緩和ケア医である著者が自分の病期から読んだ生存期間中央値である。著者は告知の2年6か月後に亡くなった。流通している7つの説明を本人の公開発言と公的記録に突き合わせる。
    著者は2022年4月に死去宝島社 2020本書は未読
  • 2026-10-03 / 論考
    生成AIと思考力 — MIT脳波研究を一次情報で確認する
    生成AIを使うと脳の働きが落ちるという話の出どころは1本の未査読プレプリント。dDTFで測ったものと測っていないものを論文本体から確認し、日本語で流通する5つの要約を照合する。5項目のうち1項目は比較対象の取り違えだった。学習成果の向上を示した査読済みRCT2件も並べる。
    未査読プレプリント被験者54名 / EEG 32電極arXiv:2506.08872
  • 2026-10-03 / 読書ノート
    伊藤計劃『ハーモニー』読書ノート
    統治しているのはAIではない。WatchMeは脳のチップではない。皺寄せは貧困層ではなく生府の外部に出る。作中用語を査読論文と文庫の頁番号まで遡って確認し、よく語られる6つの要約を1件ずつ照合する。
    結末に言及あり日本SF大賞 / 星雲賞早川書房 2008
  • 2026-10-03 / 読書ノート
