第1章では1次独立な2本のベクトルで平面のどのベクトルも1通りに表せることを示した。第2章では内積で長さと角と垂直を計算した。この章ではこの2つを点と図形に使う。基準点を1つ決めて点をベクトルで表すと内分点・重心・交点が文字式の計算で求まる。直線と円も実数を動かす式で書ける。

共通テストのベクトルの大問で最も多い流れは次の3段である。図形の点を2本のベクトルで表す・2通りに表して係数を比べる・内積で長さや角を求める。2026年の第6問は等式を満たす点の存在範囲を扱った。この章の第3節がその準備になる。

位置ベクトルと分点

平面上に基準になる点Oを1つ決める。点Pに対し p⃗=OP→\vec{p}=\overrightarrow{OP} をOに関する点Pの位置ベクトルと呼ぶ。点Pの位置ベクトルが p⃗\vec{p} であることを P(p⃗)P(\vec{p}) と書く。基準点Oを原点にとれば位置ベクトルの成分は点の座標と一致する。

2点 A(a⃗)A(\vec{a}) と B(b⃗)B(\vec{b}) について第1章の差の式から次が成り立つ。

AB→=b⃗−a⃗\overrightarrow{AB}=\vec{b}-\vec{a}

どの矢印も終点の位置ベクトルから始点の位置ベクトルを引けば基準点Oからの矢印だけで書ける。これがこの章のすべての計算の出発点である。

線分ABを m:nm:n に内分する点Pを求める。m>0m>0 ・ n>0n>0 とする。PはAからBへ全体の mm+n\dfrac{m}{m+n} だけ進んだ点なので AP→=mm+nAB→\overrightarrow{AP}=\dfrac{m}{m+n}\overrightarrow{AB} である。

p⃗=a⃗+mm+n(b⃗−a⃗)=na⃗+mb⃗m+n\vec{p}=\vec{a}+\frac{m}{m+n}(\vec{b}-\vec{a})=\frac{n\vec{a}+m\vec{b}}{m+n}

係数の付き方に注意する。Aの係数は反対側の比 nn でBの係数は mm である。Bに近い点ほどBの重みが大きいので mm がBにつく。中点は m=nm=n の場合で a⃗+b⃗2\dfrac{\vec{a}+\vec{b}}{2} である。

線分ABを m:nm:n に外分する点Qは m≠nm\neq n の時に存在し内分の式の nn を −n-n に置き換えて得られる。

q⃗=−na⃗+mb⃗m−n\vec{q}=\frac{-n\vec{a}+m\vec{b}}{m-n}

m>nm>n ならQはBの外側にあり m<nm<n ならAの外側にある。

分点の式は基準点Oの選び方によらない。係数の和が nm+n+mm+n=1\dfrac{n}{m+n}+\dfrac{m}{m+n}=1 なので基準点を e⃗\vec{e} だけずらすと両辺が同じだけずれるからである。外分でも係数の和は −n+mm−n=1\dfrac{-n+m}{m-n}=1 である。そのため問題に合わせて三角形の頂点の1つを基準点にとってよい。頂点Aを基準にすると a⃗=0⃗\vec{a}=\vec{0} となり式が短くなる。

三角形ABCの重心Gは3本の中線の交点であり各中線を頂点から2対1に内分する。辺BCの中点を M(b⃗+c⃗2)M\left(\dfrac{\vec{b}+\vec{c}}{2}\right) としAMを2対1に内分すると次の式になる。

g⃗=1⋅a⃗+2⋅b⃗+c⃗23=a⃗+b⃗+c⃗3\vec{g}=\frac{1\cdot\vec{a}+2\cdot\dfrac{\vec{b}+\vec{c}}{2}}{3}=\frac{\vec{a}+\vec{b}+\vec{c}}{3}

結果は a⃗\vec{a} ・ b⃗\vec{b} ・ c⃗\vec{c} について対称である。BやCから出発しても同じ点になるので3本の中線は1点で交わる。学習指導要領解説は初等幾何による証明とベクトルによる証明を比べる例としてこの事実を挙げている。

例題 1

2点 A(a⃗)A(\vec{a}) ・ B(b⃗)B(\vec{b}) について線分ABを 2:12:1 に内分する点Pと外分する点Qと 1:31:3 に外分する点Rの位置ベクトルを求めよ。

解き方
手順1 内分 p⃗=1⋅a⃗+2b⃗2+1=a⃗+2b⃗3\vec{p}=\dfrac{1\cdot\vec{a}+2\vec{b}}{2+1}=\dfrac{\vec{a}+2\vec{b}}{3}。
手順2 外分 q⃗=−1⋅a⃗+2b⃗2−1=−a⃗+2b⃗\vec{q}=\dfrac{-1\cdot\vec{a}+2\vec{b}}{2-1}=-\vec{a}+2\vec{b}。
手順3 1:31:3 の外分は r⃗=−3a⃗+1⋅b⃗1−3=3a⃗−b⃗2\vec{r}=\dfrac{-3\vec{a}+1\cdot\vec{b}}{1-3}=\dfrac{3\vec{a}-\vec{b}}{2}。m<nm<n なのでRはAの外側にある。
答え a⃗+2b⃗3\dfrac{\vec{a}+2\vec{b}}{3} ・ −a⃗+2b⃗-\vec{a}+2\vec{b} ・ 3a⃗−b⃗2\dfrac{3\vec{a}-\vec{b}}{2}

3点が一直線上にある条件と2直線の交点

3点A・B・Cが一直線上にある条件は AC→\overrightarrow{AC} が AB→\overrightarrow{AB} の実数倍になることである。

A, B, C が一直線上  ⟺  AC→=kAB→ となる実数 k があるA,\ B,\ C\ \text{が一直線上}\iff\overrightarrow{AC}=k\overrightarrow{AB}\ \text{となる実数}\ k\ \text{がある}

これを位置ベクトルで書き直すと c⃗=a⃗+k(b⃗−a⃗)=(1−k)a⃗+kb⃗\vec{c}=\vec{a}+k(\vec{b}-\vec{a})=(1-k)\vec{a}+k\vec{b} である。点Cが直線AB上にあるのはCの位置ベクトルが sa⃗+tb⃗s\vec{a}+t\vec{b} で s+t=1s+t=1 と書ける時である。係数の和が1という条件は前節の内分の式で nm+n+mm+n=1\dfrac{n}{m+n}+\dfrac{m}{m+n}=1 となることと同じ内容である。

例題 4

三角形OABで OA→=a⃗\overrightarrow{OA}=\vec{a} ・ OB→=b⃗\overrightarrow{OB}=\vec{b} とする。辺OAを 1:21:2 に内分する点をC・辺OBの中点をDとし線分ADと線分BCの交点をPとする。OP→\overrightarrow{OP} を a⃗\vec{a} と b⃗\vec{b} で表せ。

直線のベクトル方程式と点の存在範囲

点 A(a⃗)A(\vec{a}) を通り 0⃗\vec{0} でないベクトル d⃗\vec{d} に平行な直線を考える。点 P(p⃗)P(\vec{p}) がこの直線上にあるのは AP→\overrightarrow{AP} が d⃗\vec{d} の実数倍になる時である。

p⃗=a⃗+td⃗(t は実数)\vec{p}=\vec{a}+t\vec{d}\qquad(t\ \text{は実数})

これを直線のベクトル方程式と呼ぶ。d⃗\vec{d} を方向ベクトルと呼び tt を媒介変数と呼ぶ。tt を動かすと点Pが直線上を動く。A(x1,y1)A(x_1,y_1) ・ d⃗=(l,m)\vec{d}=(l,m) として成分で書くと次の媒介変数表示になる。

x=x1+lt,y=y1+mtx=x_1+lt,\qquad y=y_1+mt

2式から tt を消去すると m(x−x1)−l(y−y1)=0m(x-x_1)-l(y-y_1)=0 となり数学Ⅱで学んだ直線の方程式に戻る。

2点 A(a⃗)A(\vec{a}) と B(b⃗)B(\vec{b}) を通る直線は方向ベクトルを b⃗−a⃗\vec{b}-\vec{a} にとって p⃗=(1−t)a⃗+tb⃗\vec{p}=(1-t)\vec{a}+t\vec{b} と書ける。0≤t≤10\le t\le1 に制限すると線分ABになる。これは前節の係数の和が1という条件と同じものである。

この見方を広げると点の存在範囲が分かる。OP→=sa⃗+tb⃗\overrightarrow{OP}=s\vec{a}+t\vec{b} の ss と tt に条件を付けた時Pが動く範囲は次のようになる。

条件Pの存在範囲
s+t=1s+t=1直線AB
s+t=1, s≥0, t≥0s+t=1,\ s\ge0,\ t\ge0線分AB
s+t≤1, s≥0, t≥0s+t\le1,\ s\ge0,\ t\ge0三角形OABの周と内部
0≤s≤1, 0≤t≤10\le s\le1,\ 0\le t\le1OA・OBを2辺とする平行四辺形の周と内部

3行目の理由を確かめる。s+t=ks+t=k で 0<k≤10<k\le1 とすると OP→=sk(ka⃗)+tk(kb⃗)\overrightarrow{OP}=\dfrac{s}{k}(k\vec{a})+\dfrac{t}{k}(k\vec{b}) で係数の和は1である。PはOAとOBを kk 倍した2点を結ぶ線分上にある。kk を0から1まで動かすとこの線分がOからABまで平行に移り三角形を覆う。k=0k=0 の場合はPはO自身である。係数の和を1にそろえるように基準のベクトルを伸縮するのが存在範囲の問題の定石である。

4行目の平行四辺形は ss と tt を別々に動かす場合である。tt を固定して ss を0から1まで動かすとPは tb⃗t\vec{b} の終点から a⃗\vec{a} の方向に長さ ∣a⃗∣|\vec{a}| の線分を描く。その線分を tt について0から1まで平行に動かすと平行四辺形になる。条件の不等式が ss と tt の和についてか個別についてかで範囲の形が変わる。

法線ベクトルと直線の方程式

直線を「通る点」と「垂直な向き」で表すこともできる。直線に垂直な 0⃗\vec{0} でないベクトルを法線ベクトルと呼ぶ。点 A(a⃗)A(\vec{a}) を通り法線ベクトルが n⃗\vec{n} の直線上の点 P(p⃗)P(\vec{p}) は AP→\overrightarrow{AP} が n⃗\vec{n} と垂直である点の集まりである。

n⃗⋅(p⃗−a⃗)=0\vec{n}\cdot(\vec{p}-\vec{a})=0

n⃗=(a,b)\vec{n}=(a,b) ・ A(x1,y1)A(x_1,y_1) ・ P(x,y)P(x,y) として成分で書くと次の式になる。

a(x−x1)+b(y−y1)=0a(x-x_1)+b(y-y_1)=0

展開すると ax+by+c=0ax+by+c=0 の形になる。直線 ax+by+c=0ax+by+c=0 の xx と yy の係数を並べた (a,b)(a,b) はその直線の法線ベクトルである。方向ベクトルは法線ベクトルに垂直なので (b,−a)(b,-a) にとれる。

法線ベクトルを使うと点と直線の距離の公式が導ける。点 Q(x0,y0)Q(x_0,y_0) から直線 ax+by+c=0ax+by+c=0 への距離 dd は直線上の点Aから見た AQ→\overrightarrow{AQ} の法線方向の成分の大きさである。第2章の正射影の長さの式から次が得られる。

d=∣n⃗⋅AQ→∣∣n⃗∣=∣a(x0−x1)+b(y0−y1)∣a2+b2=∣ax0+by0+c∣a2+b2d=\frac{|\vec{n}\cdot\overrightarrow{AQ}|}{|\vec{n}|}=\frac{|a(x_0-x_1)+b(y_0-y_1)|}{\sqrt{a^2+b^2}}=\frac{|ax_0+by_0+c|}{\sqrt{a^2+b^2}}

最後の変形ではAが直線上にあるので ax1+by1=−cax_1+by_1=-c となることを使った。数学Ⅱで学んだ公式がベクトルでは1行で導ける。

2直線のなす角は法線ベクトルのなす角から求める。法線ベクトルのなす角が θ\theta なら2直線のなす角は θ\theta と 180∘−θ180^\circ-\theta の小さい方である。

直線の表し方は3通りになった。問題で与えられる情報に合わせて選ぶ。

与えられる情報ベクトル方程式向いている問題
通る2点A・Bp⃗=(1−t)a⃗+tb⃗\vec{p}=(1-t)\vec{a}+t\vec{b}交点の係数比較 ／ 存在範囲

通る点Aと法線 n⃗\vec{n}n⃗⋅(p⃗−a⃗)=0\vec{n}\cdot(\vec{p}-\vec{a})=0垂直条件 ／ 距離 ／ 2直線のなす角

前の2つは媒介変数 tt を含み点を1つずつ生成する書き方である。最後の1つは条件を満たす点を判定する書き方で tt を含まない。第4章の空間では前の書き方が直線になり後の書き方が平面になる。同じ式の形が空間では異なる図形を表すので区別しておく。

典型的な誤りは法線ベクトルと方向ベクトルの取り違えである。ax+by+c=0ax+by+c=0 の係数 (a,b)(a,b) は直線に垂直な向きであり直線の向きではない。直線 y=2xy=2x すなわち 2x−y=02x-y=0 の法線ベクトルは (2,−1)(2,-1) で方向ベクトルは (1,2)(1,2) である。

p1x+p2y=Ip_1x+p_2y=I の法線は (p1,p2)(p_1,p_2)。所得が増えると線は法線方向へ平行移動し価格比が変わると法線が回転して傾きが変わる。

円のベクトル方程式

中心 C(c⃗)C(\vec{c}) ・半径 rr の円は中心からの距離が rr の点の集まりである。

∣p⃗−c⃗∣=rまたは(p⃗−c⃗)⋅(p⃗−c⃗)=r2|\vec{p}-\vec{c}|=r\qquad\text{または}\qquad(\vec{p}-\vec{c})\cdot(\vec{p}-\vec{c})=r^2

c⃗=(a,b)\vec{c}=(a,b) ・ p⃗=(x,y)\vec{p}=(x,y) として成分で書くと (x−a)2+(y−b)2=r2(x-a)^2+(y-b)^2=r^2 となり数学Ⅱの円の方程式と一致する。

2点 A(a⃗)A(\vec{a}) ・ B(b⃗)B(\vec{b}) を直径の両端とする円は次の形でも書ける。

(p⃗−a⃗)⋅(p⃗−b⃗)=0(\vec{p}-\vec{a})\cdot(\vec{p}-\vec{b})=0

理由は直径に対する円周角が直角であることである。P がA・Bと異なる円周上の点なら AP→⊥BP→\overrightarrow{AP}\perp\overrightarrow{BP} で内積は0である。PがAかBに一致する時も一方が 0⃗\vec{0} なので内積は0である。円周角の定理が内積0の1本の式に変わる。

円周上の点 P0(p0⃗)P_0(\vec{p_0}) における接線は半径 CP0CP_0 に垂直である。接線上の点 PP について (p0⃗−c⃗)⋅(p⃗−p0⃗)=0(\vec{p_0}-\vec{c})\cdot(\vec{p}-\vec{p_0})=0 が成り立つ。これを変形すると (p0⃗−c⃗)⋅(p⃗−c⃗)=r2(\vec{p_0}-\vec{c})\cdot(\vec{p}-\vec{c})=r^2 となる。法線ベクトルが p0⃗−c⃗\vec{p_0}-\vec{c} の直線であることが分かる。

円の問題の誤りは2つある。1つは ∣p⃗−c⃗∣=r|\vec{p}-\vec{c}|=r を2乗せずに成分の式へ直そうとして根号の計算で行き詰まることである。大きさの式は2乗して内積に直すという第2章の手順をここでも使う。もう1つは x2+y2+lx+my+n=0x^2+y^2+lx+my+n=0 の形がいつも円を表すと考えることである。平方完成した右辺が0なら1点であり負なら図形は存在しない。

現実世界 2隻の船は衝突するか

学習指導要領解説は直線のベクトル方程式を日常の問題に使う例として2隻の帆船の衝突を挙げている。帆船Aは位置 a⃗\vec{a} から速度 va⃗\vec{v_a} で進み帆船Bは位置 b⃗\vec{b} から速度 vb⃗\vec{v_b} で進む。ss 秒後のAの位置は a⃗+sva⃗\vec{a}+s\vec{v_a} で tt 秒後のBの位置は b⃗+tvb⃗\vec{b}+t\vec{v_b} である。

2本の航路の交点Cは a⃗+sva⃗=b⃗+tvb⃗\vec{a}+s\vec{v_a}=\vec{b}+t\vec{v_b} を解いて求まる。ただし交点があるだけでは衝突しない。衝突する条件は同じ時刻に交点に着くことで s=ts=t である。

数値で確かめる。単位を km と時間とし a⃗=(0,0)\vec{a}=(0,0) ・ va⃗=(3,4)\vec{v_a}=(3,4) ・ b⃗=(10,0)\vec{b}=(10,0) ・ vb⃗=(−2,4)\vec{v_b}=(-2,4) とする。時刻 tt の2隻の位置は (3t,4t)(3t,4t) と (10−2t,4t)(10-2t,4t) である。y成分は常に等しく x成分は 3t=10−2t3t=10-2t の時に等しくなる。t=2t=2 で2隻は点 (6,8)(6,8) に同時に着き衝突する。Bの速度が (−2,5)(-2,5) なら航路の交点は存在するが同じ時刻には着かない。

解説はもう1つの見方も示している。時刻 kk に衝突するなら AB→=k(va⃗−vb⃗)\overrightarrow{AB}=k(\vec{v_a}-\vec{v_b}) が成り立つ。点Bから vb⃗−va⃗\vec{v_b}-\vec{v_a} の向きに引いた半直線の上に点Aがあるかを調べる方法である。2点間の距離 ∣(b⃗+tvb⃗)−(a⃗+tva⃗)∣|(\vec{b}+t\vec{v_b})-(\vec{a}+t\vec{v_a})| の最小値を求めれば船の大きさを考えた衝突の判定にもなる。これは第2章の例題6と同じ最小値の計算である。

恋愛で言えば

道が交わるだけでは会えない。同じ時刻に交点にいて初めて会える

2人の位置を a⃗+su⃗\vec{a}+s\vec{u} と b⃗+tv⃗\vec{b}+t\vec{v} で書くと交点は ss と tt が異なっても存在する。出会うには s=ts=t が要る。

残っている問い

  • 学習指導要領解説は平面のベクトルについて「ベクトル方程式を取り扱うことも考えられる」と述べるにとどまる。直線と円のベクトル方程式を必須とする記述ではない。多くの教科書が本文で扱う範囲であるが教科書ごとの扱いの差は確認していない。
  • 外分の公式は m≠nm\neq n の時に限る。m=nm=n では分母が0になり外分点は存在しない。
  • 帆船の例は船を点とみなし速度が一定の場合の近似である。解説は潮の流れや風の影響を加えた考察も挙げている。
