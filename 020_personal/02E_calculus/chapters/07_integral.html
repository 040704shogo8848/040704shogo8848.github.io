積分と面積

微分すると f(x) になる関数を f(x) の原始関数と呼び原始関数を求める計算が不定積分である。原始関数の値の差が定積分で x=a から x=t までの面積を t で微分すると f(t) に戻ることから定積分は面積を表す。放物線と直線で囲まれた面積は 1/6 公式で一度に求まる。

第5章と第6章では関数から導関数を求めてグラフの形を調べた。この章では逆向きの計算を扱う。導関数が分かっているときに元の関数を求める計算が不定積分である。さらに不定積分を使って曲線で囲まれた図形の面積を求める。微分と積分が互いに逆の演算であることがこの章の中心である。

学習指導要領では数学Ⅱの積分は2次までの関数を中心に扱うとされている。共通テストでは定積分の計算・積分で定義された関数・放物線と直線で囲まれた面積が問われる。面積の問題は 16\frac{1}{6} 公式で計算時間を大きく短縮できる。三角関数や指数関数の積分は数学Ⅲの第12章で扱い体積は第13章で扱う。

不定積分

関数 f(x)f(x) に対し微分すると f(x)f(x) になる関数 F(x)F(x) を f(x)f(x) の原始関数と呼ぶ。F′(x)=f(x)F'(x)=f(x) を満たす関数である。たとえば (x2)′=2x(x^{2})'=2x なので x2x^{2} は 2x2x の原始関数である。

原始関数は1つではない。x2+1x^{2}+1 も x2−5x^{2}-5 も微分すれば 2x2x になる。定数の導関数は0だからである。逆に F(x)F(x) と G(x)G(x) がどちらも f(x)f(x) の原始関数なら {G(x)−F(x)}′=0\{G(x)-F(x)\}'=0 で G(x)−F(x)G(x)-F(x) は定数になる。導関数が常に0の関数は定数関数であるという性質は第6章で確認した。この性質の証明には第11章の平均値の定理を使う。したがって f(x)f(x) の原始関数は1つの原始関数 F(x)F(x) に任意の定数 CC を加えた形ですべて表せる。

∫f(x) dx=F(x)+C\int f(x)\,dx=F(x)+C

これを f(x)f(x) の不定積分と呼び CC を積分定数と呼ぶ。f(x)f(x) の不定積分を求めることを f(x)f(x) を積分すると言う。∫\int はライプニッツが和を表す summa の頭文字 SS を縦に伸ばした記号である。

xnx^{n} の不定積分

(xn+1)′=(n+1)xn(x^{n+1})'=(n+1)x^{n} であるから両辺を n+1n+1 で割れば xnx^{n} の原始関数が得られる。nn は0以上の整数とする。

∫xn dx=xn+1n+1+C\int x^n\,dx=\frac{x^{n+1}}{n+1}+C

微分では指数が係数に下りて指数が1つ減った。積分では逆に指数を1つ増やして新しい指数で割る。n=0n=0 の場合は ∫1 dx=x+C\int 1\,dx=x+C である。和と定数倍についての性質も微分と同じ形で成り立つ。kk・ll は定数とする。

∫{kf(x)+lg(x)} dx=k∫f(x) dx+l∫g(x) dx\int\{kf(x)+lg(x)\}\,dx=k\int f(x)\,dx+l\int g(x)\,dx

定積分の定義と性質

f(x)f(x) の原始関数の1つを F(x)F(x) とする。2つの実数 aa・bb に対し F(b)−F(a)F(b)-F(a) を f(x)f(x) の aa から bb までの定積分と呼び次のように書く。aa を下端・bb を上端と呼ぶ。

∫abf(x) dx=[F(x)]ab=F(b)−F(a)\int_a^b f(x)\,dx=\Bigl[F(x)\Bigr]_a^b=F(b)-F(a)

原始関数として F(x)+CF(x)+C を選んでも {F(b)+C}−{F(a)+C}=F(b)−F(a)\{F(b)+C\}-\{F(a)+C\}=F(b)-F(a) で CC は消える。定積分の値は原始関数の選び方によらず1つに定まる。このため定積分の計算では CC を書かない。

定積分の性質

定義 F(b)−F(a)F(b)-F(a) から次の性質が直接導ける。

∫aaf(x) dx=0,∫baf(x) dx=−∫abf(x) dx,∫acf(x) dx+∫cbf(x) dx=∫abf(x) dx\int_a^a f(x)\,dx=0,\qquad \int_b^a f(x)\,dx=-\int_a^b f(x)\,dx,\qquad \int_a^c f(x)\,dx+\int_c^b f(x)\,dx=\int_a^b f(x)\,dx

第3式は {F(c)−F(a)}+{F(b)−F(c)}=F(b)−F(a)\{F(c)-F(a)\}+\{F(b)-F(c)\}=F(b)-F(a) から成り立つ。cc は aa と bb の間になくてもよい。和と定数倍の性質も不定積分と同じく成り立つ。

偶関数と奇関数

区間が原点について対称な −a-a から aa までの定積分では次の性質が計算を短くする。

∫−aax奇数 dx=0,∫−aax偶数 dx=2∫0ax偶数 dx\int_{-a}^{a}x^{\text{奇数}}\,dx=0,\qquad \int_{-a}^{a}x^{\text{偶数}}\,dx=2\int_0^a x^{\text{偶数}}\,dx

xx の奇数乗は原始関数が偶数乗になり F(a)=F(−a)F(a)=F(-a) となるので差が0になる。xx の偶数乗は原始関数が奇数乗になり F(−a)=−F(a)F(-a)=-F(a) となるので差が 2F(a)2F(a) になる。

微分と積分の関係

aa を定数とし上端を変数 xx にした定積分を考える。これは xx の関数である。f(t)f(t) の原始関数を F(t)F(t) とすると次のように計算できる。

∫axf(t) dt=F(x)−F(a)\int_a^x f(t)\,dt=F(x)-F(a)

右辺の F(a)F(a) は定数なので xx で微分すると F′(x)=f(x)F'(x)=f(x) が残る。

ddx∫axf(t) dt=f(x)\frac{d}{dx}\int_a^x f(t)\,dt=f(x)

上端が xx の定積分を xx で微分すると被積分関数の tt を xx に置き換えた関数に戻る。積分の変数を tt と書くのは上端の xx と区別するためである。tt は積分すると消える変数でどの文字を使っても値は変わらない。

定積分と面積

区間 a≦x≦ba\leqq x\leqq b で f(x)≧0f(x)\geqq 0 とする。曲線 y=f(x)y=f(x) と xx 軸と2直線 x=ax=a・x=tx=t で囲まれた部分の面積を S(t)S(t) とする。tt を hh だけ増やすと面積は幅 hh の細い帯の分だけ増える。帯は高さが f(t)f(t) に近い長方形とみなせるので次の関係が成り立つ。

S(t+h)−S(t)h≈f(t)⟹S′(t)=f(t)\frac{S(t+h)-S(t)}{h}\approx f(t)\quad\Longrightarrow\quad S'(t)=f(t)

S(t)S(t) は f(t)f(t) の原始関数で S(a)=0S(a)=0 を満たす。原始関数 FF を使うと S(t)=F(t)−F(a)S(t)=F(t)-F(a) となる。t=bt=b とすれば面積が定積分で表される。

S=∫abf(x) dx(a≦x≦b で f(x)≧0)S=\int_a^b f(x)\,dx \qquad (a\leqq x\leqq b \text{ で } f(x)\geqq 0)

学習指導要領解説はこの S′(t)=f(t)S'(t)=f(t) による説明を定積分が面積を表す理由の例として示している。帯の高さは f(t)f(t) と f(t+h)f(t+h) の間にあり h→0h\to 0 で両方とも f(t)f(t) に近づく。この挟み込みが近似を等式に変える根拠である。

f(x)≦0f(x)\leqq 0 の区間では定積分の値は負になる。面積は正の量なので符号を変えて −∫abf(x) dx-\int _{a}^{b} f(x)\,dx とする。曲線が区間の途中で xx 軸と交わる場合は交点で区間を分け xx 軸の上の部分と下の部分を別々に計算する。

2曲線の間の面積

区間 a≦x≦ba\leqq x\leqq b で f(x)≧g(x)f(x)\geqq g(x) のとき2曲線 y=f(x)y=f(x)・y=g(x)y=g(x) と2直線 x=ax=a・x=bx=b で囲まれた部分の面積は次の式で求まる。

S=∫ab{f(x)−g(x)} dxS=\int_a^b\{f(x)-g(x)\}\,dx

2曲線をともに上下に同じだけ平行移動しても面積は変わらず f(x)−g(x)f(x)-g(x) も変わらない。両方を xx 軸より上に移せば第4節の面積の差になるので g(x)g(x) が負の値をとる場合もこの式で正しい。上のグラフの式から下のグラフの式を引いて積分する。xx 軸の位置は関係しない。

1/6 公式とその導出

例題6の計算は分数の通分が多く誤りやすい。放物線と直線や2つの放物線で囲まれた部分では被積分関数が2つの交点 α\alpha・β\beta を解にもつ2次式になる。この形の定積分には次の公式が成り立つ。

∫αβ(x−α)(x−β) dx=−(β−α)36\int_\alpha^\beta (x-\alpha)(x-\beta)\,dx=-\frac{(\beta-\alpha)^3}{6}

導出

x−β=(x−α)−(β−α)x-\beta =(x-\alpha )-(\beta -\alpha ) と書き直すと被積分関数は x−αx-\alpha のべきの式になる。

(x−α)(x−β)=(x−α)2−(β−α)(x−α)(x-\alpha)(x-\beta)=(x-\alpha)^2-(\beta-\alpha)(x-\alpha)

(x−α)2(x-\alpha )^{2} の原始関数は (x−α)3/3(x-\alpha )^{3}/3 で (x−α)(x-\alpha ) の原始関数は (x−α)2/2(x-\alpha )^{2}/2 である。どちらも微分すれば元に戻ることで確かめられる。下端 x=αx=\alpha では x−α=0x-\alpha =0 なので原始関数の値はどちらも0になる。上端 x=βx=\beta を代入すると次のようになる。

(β−α)33−(β−α)⋅(β−α)22=(13−12)(β−α)3=−(β−α)36\frac{(\beta-\alpha)^3}{3}-(\beta-\alpha)\cdot\frac{(\beta-\alpha)^2}{2}=\Bigl(\frac{1}{3}-\frac{1}{2}\Bigr)(\beta-\alpha)^3=-\frac{(\beta-\alpha)^3}{6}

値が負になるのは α<x<β\alpha <x<\beta で (x−α)(x−β)<0(x-\alpha )(x-\beta )<0 だからである。x2x^{2} の係数が aa の放物線と直線で囲まれた面積は差の式が a(x−α)(x−β)a(x-\alpha )(x-\beta ) になるので次の形になる。

S=∣a∣6(β−α)3S=\frac{|a|}{6}(\beta-\alpha)^3

面積は x2x^{2} の係数の絶対値と交点の間隔の3乗だけで決まる。2つの放物線で囲まれた場合は aa を2つの x2x^{2} の係数の差に置き換える。

直接計算でも ∫02(6x−3x2) dx=12−8=4\int _{0}^{2}(6x-3x^{2})\,dx=12-8=4 で一致する。

典型的な誤りは2つの放物線の場合に係数の差を使わず ∣a∣=1|a|=1 として計算することである。(2) で係数を1にすると 86=43\frac{8}{6}=\frac{4}{3} となり正しい値4の 13\frac{1}{3} になる。もう1つの誤りは区間の端が交点でない場合に公式を使うことである。16\frac{1}{6} 公式は積分区間の両端が2次式の2つの解であるときだけ使える。

現実世界の積分 アルキメデスの求積

放物線と弦で囲まれた弓形の面積を最初に求めたのは紀元前3世紀のアルキメデスである。著作『放物線の求積』で弓形の面積は弦の両端と弦に平行な接線の接点を頂点とする三角形の面積の 43\frac{4}{3} 倍であると証明した。証明には取り尽くし法を使い面積が 43\frac{4}{3} 倍より大きいと仮定しても小さいと仮定しても矛盾が生じることを示した。

例題6の図形で確かめる。弦の傾きは1なので傾き1の接線の接点は y′=2x=1y'=2x=1 から C(12,14)C(\frac{1}{2}, \frac{1}{4}) である。弦の両端 (−1,1)(-1, 1) と (2, 4) と CC の3点を頂点とする三角形の面積は 278\frac{27}{8} である。弓形の面積 92\frac{9}{2} との比は 92÷278=43\frac{9}{2}\div \frac{27}{8}=\frac{4}{3} となりアルキメデスの結果と一致する。

現実世界

学習指導要領解説は放物線とみなせる曲線と直線で囲まれた左右対称の窓の面積を求める問題を活用の例に挙げている。建築の窓やアーチの面積は 16\frac{1}{6} 公式で即座に求まる。

問8 ・ 定積分と面積の関係

次の記述のうち誤っているものを1つ選べ。

  1. 定積分の値は原始関数の選び方によらない
  2. ∫abf(x) dx\int _{a}^{b} f(x)\,dx は常に曲線と xx 軸の間の面積に等しい
  3. ddx∫1xf(t) dt=f(x)\frac{d}{dx} \int _{1}^{x} f(t)\,dt=f(x) である
  4. ∫aaf(x) dx=0\int _{a}^{a} f(x)\,dx=0 である

正解は 2 である。f(x)<0f(x)<0 の部分を含むと定積分は負の部分を差し引いた値になり面積とは一致しない。例題5がその例である。

この章の要点

要点 F′(x)=f(x)F'(x)=f(x) となる F(x)F(x) が原始関数で不定積分は F(x)+CF(x)+C と書く。CC を書き落とさない。
∫xn dx=xn+1/(n+1)+C\int x^{n}\,dx=x^{n+1}/(n+1)+C で指数を1つ増やして新しい指数で割る。
定積分は F(b)−F(a)F(b)-F(a) で CC は消える。−a-a から aa では奇数乗の項は0になる。
ddx∫axf(t) dt=f(x)\frac{d}{dx} \int _{a}^{x} f(t)\,dt=f(x) で積分と微分は逆の演算である。
面積は上のグラフから下のグラフを引いて積分する。xx 軸の下は符号を変える。
