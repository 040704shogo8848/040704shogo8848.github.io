微分積分 計算ドリル

CALCULUS DRILL

微分積分の計算問題は公式に値を代入して符号と分数を正しく処理する操作の反復である。このドリルは2次関数・指数と対数・三角関数・微分・積分・数列の9分野を毎回異なる数値で出題する。答えは整数か分数 a/b で入力する。根号や π や e を含む答えは4択で選ぶ。誤答には途中式を表示する。記録はこの端末のブラウザに保存する。

問題の解き方の型method

どの分野も公式に値を代入する前に式の形を整える。負の数を代入する時は括弧をつける。分数は約分してから次の計算に進む。

1. 2次関数は平方完成して軸と定義域を比べる
y = a(x − p)2 + q の形に直すと頂点は (p, q) である。定義域がある時は軸 x = p が定義域の内側か外側かで場合を分ける。最大値と最小値の候補は 定義域の両端の値 と 軸が内側にある時の頂点の値 の3つだけである。
y = x2 − 4x + 1　0 ≦ x ≦ 5
→ y = (x − 2)2 − 3 より軸は x = 2 で定義域の内側にある
→ f(0) = 1　f(5) = 6　f(2) = −3
→ 最大値 6　最小値 −3
第1章 関数とグラフを開く
2. 指数と対数は底をそろえて指数どうしで計算する
8 = 23 のように底を素数の累乗で書くと (am)n = amn で指数の掛け算になる。対数は log M + log N = log MN と log M − log N = log (M/N) で1つにまとめる。桁数は常用対数の整数部分に 1 を足した値である。
230 の桁数　log102 = 0.3010
→ log10230 = 30 × 0.3010 = 9.03
→ 109 ≦ 230 < 1010
→ 10桁

3. 三角関数は単位円の座標と加法定理で求める
角 θ の動径と単位円の交点の座標が (cos θ, sin θ) である。15° の倍数の角は 30° と 45° の和か差に分けて加法定理を使う。a sin x + b cos x は √(a2 + b2) sin(x + α) に合成でき 最大値は √(a2 + b2) である。
sin 75° = sin(45° + 30°)
→ sin 45° cos 30° + cos 45° sin 30°
→ (√2/2)(√3/2) + (√2/2)(1/2) = √6/4 + √2/4
→ (√6 + √2)/4
第4章 三角関数を開く
4. 微分係数は導関数を作ってから代入する
xn の導関数は nxn−1 である。f′(a) が x = a における接線の傾きであり 接線の方程式は y = f′(a)(x − a) + f(a) である。
f(x) = x3 − 2x2 + 3 の x = 2 における接線
→ f′(x) = 3x2 − 4x より f′(2) = 12 − 8 = 4
→ f(2) = 8 − 8 + 3 = 3
→ y = 4(x − 2) + 3 = 4x − 5
第5章 微分を開く
5. 極値は f′(x) = 0 の解の前後で符号を確認する
3次関数の f′(x) は2次式である。因数分解して2つの解 α < β を求める。x3 の係数が正なら x = α で極大 x = β で極小になる。係数が負なら逆になる。
f(x) = x3 − 3x2 − 9x + 2
→ f′(x) = 3x2 − 6x − 9 = 3(x + 1)(x − 3)
→ f(−1) = −1 − 3 + 9 + 2 = 7　f(3) = 27 − 27 − 27 + 2 = −25
→ 極大値 7　極小値 −25
第6章 微分の応用を開く
6. 放物線で囲まれた面積は 1/6 公式で求める
∫βα(x − α)(x − β) dx = −(β − α)3/6 である。放物線と x 軸の面積も 放物線と直線の面積も 2つの式の差が k(x − α)(x − β) になれば面積は |k|(β − α)3/6 である。
y = x2 − 2x − 3 と x 軸で囲まれた部分
→ x2 − 2x − 3 = (x + 1)(x − 3) より α = −1　β = 3
→ 面積 = 1 × 43/6 = 64/6
→ 32/3

7. 数列の和は3つの公式を組み合わせる
  • 等差数列の和 = 項数 × (初項 + 末項)/2
  • 等比数列の和 = a(1 − rn)/(1 − r)　r ≠ 1
  • Σk = n(n + 1)/2　Σk2 = n(n + 1)(2n + 1)/6
Σ10k=1(2k2 − k)
→ Σk2 = 10 × 11 × 21/6 = 385　Σk = 10 × 11/2 = 55

8. 数学Ⅲの微分は積・商・合成の公式を先に選ぶ
  • 積 (uv)′ = u′v + uv′
  • 商 (u/v)′ = (u′v − uv′)/v2
  • 合成 {f(g(x))}′ = f′(g(x)) g′(x)
  • (ex)′ = ex　(log x)′ = 1/x　(sin x)′ = cos x　(cos x)′ = −sin x
f(x) = x/(x2 + 1) の f′(2)
→ f′(x) = {(x2 + 1) − x × 2x}/(x2 + 1)2 = (1 − x2)/(x2 + 1)2
→ f′(2) = (1 − 4)/25
→ −3/25
