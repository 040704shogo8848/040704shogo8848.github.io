酸化と還元

酸化は電子を失う変化で還元は電子を受け取る変化である。電子を失う相手がいなければ電子は受け取れない。だから酸化と還元は必ず同時に起こり失った電子の物質量と受け取った電子の物質量は常に等しい。この等式1本で半反応式も滴定の計算も解ける。

第13章では酸が H+ を渡し塩基が H+ を受け取る反応を扱った。渡した H+ の物質量と受け取った H+ の物質量が等しいという1本の等式で中和滴定の計算が解けた。この章で移動するのは H+ ではなく電子である。電子を渡す反応と受け取る反応の組が酸化還元反応である。中和と同じく授受の量が等しいという等式が計算の軸になる。

共通テストでこの範囲から出る論点は5つである。酸化と還元の定義・酸化数の計算・酸化剤と還元剤の判別・半反応式とイオン反応式の組み立て・酸化還元滴定の量的関係である。H2O2 と SO2 が相手によって役割を変える点は定番の論点である。

酸化と還元の3つの定義

中学校では酸素と結びつく変化を酸化と呼び酸素を失う変化を還元と呼んだ。この定義は酸素が関わらない反応に使えない。そこで定義は酸素から水素へ・水素から電子へと3段階で広がった。3つの定義は互いに矛盾しない。後の定義ほど適用できる範囲が広い。

基準酸化還元例
酸素酸素を受け取る酸素を失う2Cu ＋ O2 → 2CuO で Cu は酸化された
水素水素を失う水素を受け取るH2S ＋ I2 → S ＋ 2HI で H2S は酸化された
電子電子を失う電子を受け取る2Na ＋ Cl2 → 2NaCl で Na は酸化された

電子の定義が最も基本である。Cu が O2 と結びつくと Cu は電子を2個失って Cu2+ になり O は電子を2個受け取って O2− になる。酸素を受け取った側が電子を失っているので酸素の定義と電子の定義は一致する。

ある物質が電子を失えばその電子は必ず別の物質が受け取る。電子は反応の途中で消えたり生じたりしない。したがって酸化だけが起こる反応や還元だけが起こる反応は存在しない。酸化と還元は常に同時に起こり1つの反応を酸化還元反応と呼ぶ。

恋愛で言えば

酸化だけの反応は受け取り手のいない贈り物と同じで成立しない

渡す側が酸化され受け取る側が還元される。渡した電子の数と受け取った数は必ず一致し Mg と O は電子2個の受け渡しである。

酸化数の決め方

H2 ＋ Cl2 → 2HCl のように共有結合の分子ができる反応では電子が完全には移動しない。そこで電子の移動を数値で追うために酸化数を使う。共有電子対を電気陰性度の大きい原子に全部割り当てたと仮定したときの各原子の電荷が酸化数である。

酸化数が増えれば酸化された。酸化数が減れば還元された。反応の前後で酸化数が変化した原子があれば酸化還元反応である。変化した原子が1つもなければ酸化還元反応ではない。

規則

順位規則例
1単体の原子の酸化数は 0H2 ・ O2 ・ Cu ・ S はすべて 0
2化合物を構成する原子の酸化数の総和は 0H2O は (＋1)×2 ＋ (−2) ＝ 0
3単原子イオンの酸化数はイオンの電荷に等しい ／ 多原子イオンでは総和がイオンの電荷に等しいFe3+ は ＋3 ／ SO42− の総和は −2
4化合物中のアルカリ金属は ＋1 で2族元素は ＋2NaCl の Na は ＋1
5化合物中の H は ＋1HCl ・ NH3 の H
6化合物中の O は −2CO2 ・ H2SO4 の O

規則どうしが矛盾する場合は順位の高い規則を優先する。これが例外の出どころである。

  • 過酸化水素 H2O2 では H を ＋1 とする規則5が O を −2 とする規則6に優先する。総和 0 から O は −1 である
  • 水素化ナトリウム NaH ではアルカリ金属の規則4が規則5に優先する。Na が ＋1 なので H は −1 である
  • O が F と結合した OF2 では電気陰性度が O より大きい F が −1 になり O は ＋2 になる。共通テストではまれである
野球で言えば

酸化数の規則は打球の優先権と同じく順位が上の側が捕る

H2O2 では H を＋1とする規則と O を−2とする規則が衝突する。順位が上の H の規則が捕り O は−1に譲る。

会計で言えば

酸化数は共有電子対を全額 Cl に計上する管理会計である

HCl の電子対は実際には共有 ／ 帳簿上は電気陰性度の大きい Cl に全額を計上し Cl は−1・H は＋1とする。

酸化数は帳簿上の数値であり実際の電荷ではない。

酸化剤と還元剤

相手の物質を酸化する物質を酸化剤と呼ぶ。相手を酸化するとは相手から電子を奪うことである。したがって酸化剤自身は電子を受け取って還元され酸化数が減る。相手を還元する物質を還元剤と呼び還元剤自身は電子を渡して酸化され酸化数が増える。名称と自身の変化が逆になる点で誤りやすい。

酸化剤や還元剤が電子をやり取りする変化を電子 e− を含む式で書いたものを半反応式と呼ぶ。次の表は共通テストに出る代表例である。生成物は暗記する。係数は次節の手順で毎回作れる。

二クロム酸カリウム 硫酸酸性Cr2O72− ＋ 14H+ ＋ 6e− → 2Cr3+ ＋ 7H2O赤橙 → 緑

H2O2 と SO2 はなぜ両方の役割をもつか

H2O2 の O は −1 で H2O の −2 と O2 の 0 の中間にある。SO2 の S は ＋4 で H2S の −2 と SO42− の ＋6 の中間にある。中間の酸化数をもつ原子は電子を受け取って下がることも電子を渡して上がることもできる。どちらに動くかは相手の強さで特定される。

  • H2O2 は KI や Fe2+ を相手にすると酸化剤として働く。強い酸化剤である KMnO4 や K2Cr2O7 を相手にすると還元剤として働き O2 を生じる
  • SO2 は多くの相手に対して還元剤として働く。強い還元剤である H2S を相手にすると酸化剤として働く。高校で扱う代表例はこの反応である。2H2S ＋ SO2 → 3S ＋ 2H2O で溶液が白濁する

ハロゲンの単体は酸化剤で酸化力は F2 ＞ Cl2 ＞ Br2 ＞ I2 の順である。酸化力の強いハロゲンは弱いハロゲンの陰イオンから電子を奪う。Cl2 ＋ 2KI → 2KCl ＋ I2 は進むが I2 ＋ 2KCl の向きには進まない。

野球で言えば

H2O2 と SO2 は酸化還元の大谷翔平である

相手が KI なら酸化剤として登板 ／ 相手が KMnO4 なら還元剤として打席に立つ。H2S は打者専任で KMnO4 は投手専任である。

男女で言えば

頼る側か頼られる側かは本人ではなく相手との差で決まる

SO2 はたいていの相手に電子を渡す ／ さらに電子を手放したい H2S と組むと受け取る側になる。

半反応式とイオン反応式の作り方

半反応式は暗記しなくても反応物と生成物さえわかれば4つの手順で作れる。手順は酸性の水溶液を前提とする。

  1. 反応物と生成物を書き着目する原子の数を左右で合わせる
  2. O の数を H2O で合わせる
  3. H の数を H+ で合わせる
  4. 電荷を e− で合わせる

還元剤の (COOH)2 も同じ手順で作れる。C を合わせて (COOH)2 → 2CO2 とし O は左右とも4個で合っている。H は右に H+ を2個加え電荷は右に e− を2個加えて合わせる。

イオン反応式への組み立て

酸化剤が受け取る e− の数と還元剤が渡す e− の数をそろえてから2式を足す。これで e− が消えてイオン反応式になる。

(MnO4− ＋ 8H+ ＋ 5e− → Mn2+ ＋ 4H2O) × 2
((COOH)2 → 2CO2 ＋ 2H+ ＋ 2e−) × 5
2MnO4− ＋ 6H+ ＋ 5(COOH)2 → 2Mn2+ ＋ 10CO2 ＋ 8H2Oe⁻ は両辺とも10個で消える。左の H⁺ 16個から右の H⁺ 10個を差し引いて6個が残る

イオン反応式に反応しなかったイオンを加えると化学反応式になる。KMnO4 の K+ と酸性にするための H2SO4 の SO42− を両辺に加える。

2KMnO4 ＋ 5(COOH)2 ＋ 3H2SO4 → K2SO4 ＋ 2MnSO4 ＋ 10CO2 ＋ 8H2OH⁺ 6個は H₂SO₄ 3個から供給される。S は左右とも3個である

酸性にするのに硫酸を使う理由も出題される。塩酸を使うと Cl− が MnO4− に酸化されて Cl2 になり KMnO4 の消費量が過大になる。硝酸はそれ自身が酸化剤なので還元剤の一部を酸化してしまう。硫酸の SO42− の S はすでに ＋6 で最高の酸化数なのでこの条件では反応しない。

スタートアップで言えば

半反応式の足し算は株式交換の比率計算である

共通の通貨は e−。MnO4− 1個は e− 5個分 ／ (COOH)2 1個は2個分。10にそろえて 2 対 5 で交換する。

酸化還元滴定の量的関係

濃度がわかっている酸化剤の水溶液で還元剤の水溶液の濃度を求める操作を酸化還元滴定と呼ぶ。逆に還元剤で酸化剤の濃度を求めることもある。計算に使う等式は1本である。

酸化剤が受け取る e− の物質量 ＝ 還元剤が渡す e− の物質量
a × c × V ＝ b × c′ × V′a と b は半反応式の e⁻ の係数 ・ c と c′ はモル濃度 mol/L ・ V と V′ は体積 L

中和滴定の等式で価数を e− の係数に置き換えた形である。第13章の解き方をそのまま使える。

過マンガン酸カリウム滴定の終点

ビュレットに KMnO4 水溶液を入れ硫酸酸性にしたシュウ酸水溶液に滴下する。還元剤が残っている間は滴下した MnO4− がすぐに Mn2+ に変わり赤紫色が消える。還元剤がなくなった後の1滴は反応せずに残る。溶液が無色から薄い赤紫色に変わり振り混ぜても消えなくなった点が終点である。KMnO4 自身の色が目印になるので指示薬を加えない。シュウ酸との反応は室温では遅いので約60〜70 ℃に温めて滴定する。

計算例1 KMnO4 の濃度を求める

0.0500 mol/L のシュウ酸水溶液 10.0 mL を硫酸酸性にして KMnO4 水溶液で滴定したところ 8.00 mL で終点に達した。KMnO4 のモル濃度を c とする。

5 × c × (8.00/1000) ＝ 2 × 0.0500 × (10.0/1000)
右辺 ＝ 1.00×10−3 mol → c ＝ 1.00×10−3 ÷ 0.0400 ＝ 0.0250 mol/L左辺の 5 × 0.00800 ＝ 0.0400 で割る

計算例2 H2O2 の濃度を求める

濃度不明の H2O2 水溶液 10.0 mL を硫酸酸性にして 0.0200 mol/L の KMnO4 水溶液で滴定したところ 12.0 mL で終点に達した。ここで H2O2 は還元剤として働き1 mol あたり e− 2 mol を渡す。

5 × 0.0200 × (12.0/1000) ＝ 2 × c′ × (10.0/1000)
左辺 ＝ 1.20×10−3 mol → c′ ＝ 1.20×10−3 ÷ 0.0200 ＝ 0.0600 mol/L右辺の 2 × 0.0100 ＝ 0.0200 で割る

現実世界の還元 製鉄と水素

酸化還元反応の産業で規模が最大のものは製鉄である。鉄鉱石の主成分は酸化鉄(Ⅲ) Fe2O3 で Fe の酸化数は ＋3 である。これを 0 の単体に戻す還元が製鉄である。高炉では原料の上からコークスを入れ下から熱風を吹き込む。コークスの C が燃えて生じた CO2 は高温の C と反応して一酸化炭素 CO になる。この CO が還元剤である。

Fe2O3 ＋ 3CO → 2Fe ＋ 3CO2Fe は ＋3 → 0 で還元され C は ＋2 → ＋4 で酸化される。Fe 2個が受け取る e⁻ 6個と C 3個が渡す e⁻ 6個が等しい

この反応は還元剤の C を CO2 として排出する。還元剤を水素に置き換えると生成物は水になる。

Fe2O3 ＋ 3H2 → 2Fe ＋ 3H2OH は 0 → ＋1 で酸化される。e⁻ 6個の収支は CO の場合と同じである
現実世界

日本では鉄鋼会社とエンジニアリング会社が NEDO の委託事業として2008年から COURSE50 と呼ぶ技術開発を進めてきた。参加企業の構成は合併を経て変わっている。高炉の還元剤の一部を水素に置き換える試みである。日本製鉄は君津地区にある内容積 12 m3 の試験高炉で加熱した水素を吹き込む Super COURSE50 の試験を2022年5月から行っている。同社の発表によれば高炉からの CO2 排出の削減率は2022年に22%・2023年に33%・2024年の試験で43%に達した。次の目標は大型高炉での実証である。

スウェーデンでは鉄鋼の SSAB と鉄鉱石の LKAB と電力の Vattenfall が HYBRIT という共同事業を進めている。化石燃料由来でない電力で水を電気分解して水素を作り高炉を使わずに鉄鉱石を固体のまま還元する方式である。2021年6月に試験設備で水素還元した海綿鉄を公表し同年8月にその鉄から作った鋼材を試験的に Volvo グループへ納入した。

どちらの方式も上の2本の反応式で説明できる。異なるのは還元剤の選択だけで Fe が受け取る電子の数は変わらない。水素の製造に要する電力の確保が実用化の条件になる。

確認問題

問1 ・ 酸化数

次の物質中の指定した原子のうち酸化数が最も大きいものを1つ選べ。

  1. K2Cr2O7 の Cr
  2. KMnO4 の Mn
  3. H2SO4 の S
  4. HNO3 の N
  5. H2O2 の O
解答と解説
正解は 2 である。Mn は ＋7 である。Cr は 2x ＋ 2 − 14 ＝ 0 より ＋6 ・ S は ＋6 ・ N は ＋5 ・ H2O2 の O は −1 である。
問2 ・ 酸化還元反応の判別

次の反応のうち酸化還元反応でないものを1つ選べ。

  1. 2H2S ＋ SO2 → 3S ＋ 2H2O
  2. CaCO3 ＋ 2HCl → CaCl2 ＋ H2O ＋ CO2
  3. Zn ＋ 2HCl → ZnCl2 ＋ H2
  4. Cl2 ＋ 2KI → 2KCl ＋ I2
  5. 2H2O2 → 2H2O ＋ O2
解答と解説
正解は 2 である。Ca は ＋2 ・ C は ＋4 ・ O は −2 ・ H は ＋1 ・ Cl は −1 のまま反応の前後で変化しない。弱酸の塩に強酸を加える反応で第13章の範囲である。5 は O が −1 から −2 と 0 に分かれる反応で H2O2 が酸化剤と還元剤を兼ねている。
問3 ・ 過酸化水素の役割

次の反応のうち H2O2 が還元剤として働いているものを1つ選べ。

  1. H2O2 ＋ 2KI ＋ H2SO4 → I2 ＋ K2SO4 ＋ 2H2O
  2. 2KMnO4 ＋ 5H2O2 ＋ 3H2SO4 → K2SO4 ＋ 2MnSO4 ＋ 5O2 ＋ 8H2O
  3. H2O2 ＋ SO2 → H2SO4
  4. H2O2 ＋ 2FeSO4 ＋ H2SO4 → Fe2(SO4)3 ＋ 2H2O
解答と解説
正解は 2 である。O が −1 から 0 の O2 に変化しているので H2O2 は酸化された。相手の KMnO4 が強い酸化剤だからである。1 と 3 と 4 では O が −1 から −2 に変化し H2O2 は酸化剤である。3 で SO2 の S は ＋4 から ＋6 に酸化されている。
問4 ・ 半反応式の係数

硫酸酸性の二クロム酸イオンの半反応式 Cr2O72− ＋ aH+ ＋ be− → 2Cr3+ ＋ 7H2O の係数 a と b の組み合わせとして正しいものを1つ選べ。

  1. a ＝ 7 ・ b ＝ 3
  2. a ＝ 7 ・ b ＝ 6
  3. a ＝ 14 ・ b ＝ 3
  4. a ＝ 14 ・ b ＝ 6
解答と解説
正解は 4 である。右辺の H2O 7個に含まれる H 14個を左辺の H+ で合わせるので a ＝ 14 である。左辺の電荷は −2 ＋ 14 ＝ ＋12 で右辺は ＋3 × 2 ＝ ＋6 なので差の6を e− で合わせる。Cr の酸化数は ＋6 から ＋3 に3ずつ減り Cr は2個なので合計6と一致する。
問5 ・ 酸化還元滴定の計算

濃度不明の過酸化水素水 10.0 mL を硫酸酸性にし 0.0200 mol/L の過マンガン酸カリウム水溶液で滴定したところ 12.0 mL で終点に達した。過酸化水素水のモル濃度は何 mol/L か。最も適当な数値を1つ選べ。

  1. 0.00960
  2. 0.0240
  3. 0.0600
  4. 0.120
解答と解説
正解は 3 である。KMnO4 が受け取る e− は 5 × 0.0200 × 0.0120 ＝ 1.20×10−3 mol である。H2O2 は1 mol あたり e− 2 mol を渡すので物質量は 6.00×10−4 mol で 0.0100 L で割ると 0.0600 mol/L である。2 は e− の係数を無視した値・1 は係数の比を逆にした値・4 は5だけを掛けて2で割らなかった値である。
問6 ・ 滴定の操作

硫酸酸性のシュウ酸水溶液を過マンガン酸カリウム水溶液で滴定する操作の記述として誤りを含むものを1つ選べ。

  1. 溶液を酸性にするために硫酸を用いる
  2. 塩酸で酸性にすると Cl− も酸化されるので KMnO4 の滴下量が過大になる
  3. 終点では溶液が無色から薄い赤紫色に変わり振り混ぜても色が消えなくなる
  4. 終点を判別するために指示薬としてフェノールフタレインを加える
解答と解説
正解は 4 である。MnO4− の赤紫色が目印になるので指示薬は加えない。フェノールフタレインは中和滴定で使う指示薬である。

この章の要点

要点 酸化は電子を失う変化で還元は電子を受け取る変化である。両者は必ず同時に起こる。
酸化数が増えれば酸化され減れば還元された。H₂O₂ の O は −1 で NaH の H は −1 である。
酸化剤は自身が還元され還元剤は自身が酸化される。中間の酸化数をもつ H₂O₂ と SO₂ は相手で役割が変わる。
半反応式は O を H₂O で合わせ H を H⁺ で合わせ電荷を e⁻ で合わせる。e⁻ の数をそろえて足すとイオン反応式になる。
酸化還元滴定は受け取る e⁻ の物質量＝渡す e⁻ の物質量で解く。KMnO₄ 滴定は無色から薄い赤紫で終点とする。

残っている問い

  • 酸化数は共有電子対を電気陰性度の大きい原子に全部割り当てる約束から計算した帳簿上の値である。実際の原子の電荷とは一致しない。KMnO4 の Mn に ＋7 の電荷が実在するわけではない。
  • KMnO4 は中性や塩基性では MnO2 まで還元され受け取る電子は3個になる。共通テストは硫酸酸性の5個を前提とするが条件で係数が変わる点は化学で扱う。
  • ハロゲンの酸化力の順や H2O2 がどの相手まで酸化剤として働くかは標準電極電位で定量的に比べられる。電極電位は高校の範囲外である。
  • Super COURSE50 の削減率43%は内容積 12 m3 の試験高炉での値である。数千 m3 規模の実機高炉で同じ削減率が得られるかは出典で確認できていない。
  • HYBRIT の工業規模の設備がいつ稼働するかは計画の変更が報じられており出典で確定していない。
