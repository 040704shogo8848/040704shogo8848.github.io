# 02C chemistry 執筆ガイド

高校「化学基礎」の教科書を1章1ファイルで書くための規約。手本は data/chapters/06_ionic-bond.frag である。書く前に必ず全文を読み、構成・密度・比喩の入れ方・図の描き方をこの水準に揃えること。

## 読者とゴール

- 慶應経済3年の文系学生。化学の知識はゼロに近い。数学は得意で経済とスタートアップと投資の話が通じる
- ゴールは大学入学共通テスト「化学基礎」50点満点。暗記ではなく理由から積み上げる
- 共通テストで実際に問われる論点は全部載せる。教科書の範囲を外れた深掘りは「残っている問い」か現実世界の囲みに回す

## ファイル形式

- 保存先 020_personal/02C_chemistry/data/chapters/NN_slug.frag
- 先頭に meta ヘッダ（JSON）。chapter は数値、part は編名、title は章題、thesis は要旨を1〜3文
- 本文は HTML 断片。h2 には id="s1" から連番を振る。h2 から目次が自動生成される
- ビルド: リポジトリのルートで `node 020_personal/02C_chemistry/build.mjs`。chapters/NN_slug.html が生成され ja_lint の結果が表示される
- 他の章のファイルと index.html と build.mjs と chapter.css は編集しない

## 章の構成（この順）

1. 導入の段落2つ。前の章とのつながりとこの章で共通テストが問う論点の一覧
2. 本文の h2 を4〜6個。概念 → 理由 → 計算や判別のやり方 → 例外 の順
3. 現実世界の h2 を1個。産業・科学史・企業の実例
4. 確認問題 h2。共通テスト形式の4択または5択を5〜6問。オリジナル問題で過去問の転載はしない
5. この章の要点 h2。tb-key で5行前後
6. 残っている問い h2。高校の説明が近似である箇所と出典で確定できなかった事実
7. 出典 h2。番号付きリスト。「タイトル — URL」の形

## 比喩（ユーザーの明示的な要望）

ユーザーは野球と男女の比喩・スタートアップと資本主義との対応で理解しやすい。各章に必ず以下を入れる。

- 野球で言えば（class="an an-bb"）を2個以上
- 恋愛で言えば または 男女で言えば（class="an an-lv"）を2個以上
- スタートアップで言えば ／ 資本主義で言えば ／ 投資で言えば ／ 会計で言えば（class="an an-biz"）を2個以上
- 現実世界（class="an an-rw"）を1個以上。ハーバー・ボッシュ法・半導体・電池・電力・製鉄・石油などの産業と科学史

比喩の書き方（2026-10-15 ユーザー指定。最優先）:
- **極めて簡潔に書く。** 囲み1つは見出し1行＋本文1〜2文。全体で100字前後を上限とする
- 見出し（p class="an-h"）で構造の一致を言い切る。読者が「あー確かに」と納得する意外な対応を選ぶ。例「NaCl はカップルではなく会場の男女比である」
- 本文（p）は何が何に対応するかを「A ／ B」や短文で示すだけにする。説明を重ねない
- 限界の注記は試験で失点につながる誤解を生む場合だけ p class="an-x" に1文で書く
- 比喩は必ず囲みの中に置く。本文は化学の用語だけで書く
- 男女の比喩は関係性（引き合う・共有する・渡す・取り合う・比率）で例える。性別に化学的な役割を割り当てない。性的な表現は使わない
- 手本は 06_ionic-bond.frag の比喩の囲み7個である

## 図（ビジュアライズが最重要）

- 各章に SVG の図を3個以上。figure class="tb-fig" の中に svg と figcaption を置く
- viewBox は幅720を基準。文字は font-size 12 以上。色は var(--warm) var(--cool) var(--accent) var(--ink) var(--sub) var(--muted) var(--line) var(--dim) を使う
- 図は装飾ではなく仕組みを示す。電子殻・粒子の並び・エネルギー収支・量の比・手順の流れ・グラフ
- 図の文字も日本語規範の検査対象である
- marker の id は章ごとに一意にする（例 ah07a）
- 他に使える部品: tb-tw（表）・tb-vs（2列比較）・tb-bars（横棒）・tb-kpi（数値カード）・tb-tl（年表）・fx（化学反応式や計算式）・tb-key（要点）・qz（確認問題）
- 化学式は sub と sup で書く。H<sub>2</sub>O ・ SO<sub>4</sub><sup>2−</sup>。マイナスは U+2212 の − を使う

## 日本語の規範（ja_lint で機械検査される。指摘ゼロまで直す）

- である調で書く
- **読点「、」を1個も使わない**。「〜し、」「〜ため、」「〜が、」は文を割るか連用形でつなぐ。列挙は中黒「・」か「／」
- 比喩として転用した動詞を本文で使わない。落ちる・効く・回す・握る・寄せる・埋める・乗せる・吸収・本質・正体・解像度 は検査で止まる
- 化学用語の吸収は検査で止まるため 吸熱・取り込む・要する で書く。引き寄せる は 引きつける で書く
- 擬人化しない: 覚える・理解する・気づく は検査で止まる。学習者の暗記は「暗記する」と書く
- 口語を使わない: ほぼ・かなり・とても・だいたい・ちゃんと・しっかり・ということ・となっている・する必要がある・出てくる・探す・読める は検査で止まる
- 「この章では〜を説明する」のような資料を説明するだけの文は導入以外に置かない

## 事実の正確さ

- 数値・定義・反応式・年号は WebSearch / WebFetch で確認してから書く。確認できたURLを出典に載せる
- 共通テストの範囲は文部科学省の学習指導要領解説（理科編）と大学入試センターの公表資料を基準にする
- 確認できなかった事実は本文で断定しない。残っている問いに回す
- 化学基礎の範囲外（電気分解の詳細・熱化学方程式・平衡など）は本文で深入りせず「化学で扱う」と書く
