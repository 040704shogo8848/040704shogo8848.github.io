第1章から第4章ではベクトルを矢印として扱い成分で計算した。この章では数学Ⅱで学んだ複素数を平面上の点として描く。複素数 a+bia+bi を点 (a,b)(a,b) に対応させると複素数の和は第1章のベクトルの和と同じ平行四辺形になる。ベクトルにない新しい操作が積である。複素数の積は点を回転させて拡大する操作になる。

共通テストの「数学Ⅱ・数学B・数学C」では数列・統計的な推測・ベクトル・平面上の曲線と複素数平面の4題から3題を選ぶ。複素数平面の題で問われる論点は主に5つである。絶対値と共役の計算・極形式・積と商の図形的意味・ド・モアブルの定理と累乗根・回転を使った図形の問題である。この章はこの順に積み上げる。

複素数の復習

2乗すると −1-1 になる数を虚数単位と呼び ii で表す。i2=−1i^2=-1 である。実数 a,ba, b を使って a+bia+bi の形で表される数を複素数と呼ぶ。aa を実部・bb を虚部と呼ぶ。b=0b=0 なら実数であり b≠0b\neq 0 の複素数を虚数と呼ぶ。a=0a=0 かつ b≠0b\neq 0 の数 bibi を純虚数と呼ぶ。

2つの複素数が等しいのは実部どうしと虚部どうしがそれぞれ等しいときに限る。

a+bi=c+di  ⟺  a=c かつ b=da+bi=c+di \iff a=c \text{ かつ } b=d

四則計算は ii を文字として扱い i2i^2 が現れたら −1-1 に置き換える。割り算は分母の共役複素数を分母と分子に掛けて分母を実数にする。a+bia+bi の共役複素数は a−bia-bi である。理由は次の積が実数になるからである。

(a+bi)(a−bi)=a2−(bi)2=a2+b2(a+bi)(a-bi)=a^2-(bi)^2=a^2+b^2
例題 1

(2+3i)(1−2i)(2+3i)(1-2i) と 3+i1−i\dfrac{3+i}{1-i} を a+bia+bi の形で表せ。

解き方
積を展開する。2−4i+3i−6i22-4i+3i-6i^2 である。
i2=−1i^2=-1 を代入して 2+6−i=8−i2+6-i=8-i を得る。
商は分母と分子に 1+i1+i を掛ける。分母は 12+12=21^2+1^2=2 である。
分子は (3+i)(1+i)=3+3i+i+i2=2+4i(3+i)(1+i)=3+3i+i+i^2=2+4i である。
答えは 8−i8-i と 2+4i2=1+2i\dfrac{2+4i}{2}=1+2i である。

典型的な誤りは負の数の平方根の積である。−2 −3\sqrt{-2}\,\sqrt{-3} は 6\sqrt{6} ではない。−2=2 i\sqrt{-2}=\sqrt{2}\,i と書き直してから掛けると 2 i⋅3 i=6 i2=−6\sqrt{2}\,i\cdot\sqrt{3}\,i=\sqrt{6}\,i^2=-\sqrt{6} になる。ab=ab\sqrt{a}\sqrt{b}=\sqrt{ab} は a,ba, b が負でないときだけ成り立つ規則である。

複素数を使うと実数係数の2次方程式 ax2+bx+c=0ax^2+bx+c=0 はいつも解をもつ。判別式 D=b2−4acD=b^2-4ac が負のとき解は −b±−D i2a\dfrac{-b\pm\sqrt{-D}\,i}{2a} で互いに共役な2つの虚数になる。実数係数の方程式では α\alpha が解なら αˉ\bar{\alpha} も解である。方程式の両辺の共役をとっても係数は実数なので変わらないからである。この性質は3次以上の実数係数の方程式でも成り立つ。

複素数平面と絶対値と共役

複素数 z=a+biz=a+bi を座標平面の点 (a,b)(a,b) に対応させる。この平面を複素数平面と呼ぶ。横軸を実軸・縦軸を虚軸と呼ぶ。実数は実軸上の点であり純虚数は原点を除く虚軸上の点である。

原点 O から点 zz までの距離を zz の絶対値と呼び ∣z∣|z| で表す。三平方の定理から次の式が成り立つ。

∣z∣=∣a+bi∣=a2+b2|z|=|a+bi|=\sqrt{a^2+b^2}

共役複素数 zˉ=a−bi\bar{z}=a-bi は点 zz を実軸に関して対称に移した点である。−z-z は原点に関して対称な点である。第1節の計算 (a+bi)(a−bi)=a2+b2(a+bi)(a-bi)=a^2+b^2 は次の形で使う。

zzˉ=∣z∣2z\bar{z}=|z|^2

和と差は成分ごとの計算なので第1章のベクトルの和と差と一致する。z+wz+w は O と zz と ww を3頂点とする平行四辺形の第4の頂点である。2点 z,wz, w の距離は ∣z−w∣|z-w| である。この1行が円や垂直二等分線の方程式の出発点になる。

共役複素数には次の性質がある。証明は z=a+biz=a+bi と w=c+diw=c+di を代入して両辺を比べればよい。

z+w‾=zˉ+wˉ,zw‾=zˉ wˉ,(zw)‾=zˉwˉ\overline{z+w}=\bar{z}+\bar{w},\qquad \overline{zw}=\bar{z}\,\bar{w},\qquad \overline{\left(\frac{z}{w}\right)}=\frac{\bar{z}}{\bar{w}}

実数と純虚数の判定にも共役を使う。zz が実数であることと zˉ=z\bar{z}=z は同値である。zz が純虚数であることと zˉ=−z\bar{z}=-z かつ z≠0z\neq 0 は同値である。

例題 2

2点 α=1+2i\alpha=1+2i と β=4−2i\beta=4-2i の距離を求めよ。また ∣z∣=1|z|=1 のとき 1z=zˉ\dfrac{1}{z}=\bar{z} であることを示せ。

解き方
β−α=3−4i\beta-\alpha=3-4i である。
距離は ∣3−4i∣=9+16=5|3-4i|=\sqrt{9+16}=5 である。
後半は zzˉ=∣z∣2=1z\bar{z}=|z|^2=1 から始める。
両辺を zz で割ると zˉ=1z\bar{z}=\dfrac{1}{z} を得る。

和の絶対値については三角不等式 ∣z+w∣≦∣z∣+∣w∣|z+w|\leqq|z|+|w| が成り立つ。O と zz と z+wz+w を頂点とする三角形の2辺の和が他の1辺以上であることを式にしたものである。等号は zz と ww が原点から同じ向きにあるときに成り立つ。

例題 3

z≠0z\neq 0 とする。z+1zz+\dfrac{1}{z} が実数になるための条件を求めよ。

解き方
実数であることは共役と等しいことと同値である。zˉ+1zˉ=z+1z\bar{z}+\dfrac{1}{\bar{z}}=z+\dfrac{1}{z} を変形する。
移項して (z−zˉ)−z−zˉzzˉ=0(z-\bar{z})-\dfrac{z-\bar{z}}{z\bar{z}}=0 である。
zzˉ=∣z∣2z\bar{z}=|z|^2 を使い (z−zˉ)(1−1∣z∣2)=0(z-\bar{z})\left(1-\dfrac{1}{|z|^2}\right)=0 と因数分解する。
z=zˉz=\bar{z} または ∣z∣=1|z|=1 である。
答えは z が0でない実数であるか z が原点を中心とする半径1の円周上にあることである。
野球で言えば

共役複素数は打席を左右で入れ替えた打者である

実軸がホームから二塁への線なら共役は同じ打球を左右反転させた位置である。飛距離に相当する絶対値は変わらない。

極形式

点 zz の位置は直交座標 (a,b)(a,b) だけでなく原点からの距離 rr と実軸の正の向きから測った角 θ\theta でも決まる。r=∣z∣r=|z| であり θ\theta を zz の偏角と呼び arg⁡z\arg z で表す。三角比の定義から a=rcos⁡θa=r\cos\theta と b=rsin⁡θb=r\sin\theta が成り立つ。代入すると次の形になる。これを極形式と呼ぶ。

z=r(cos⁡θ+isin⁡θ)(r>0)z=r(\cos\theta+i\sin\theta)\qquad (r>0)

偏角は 2π2\pi の整数倍だけ異なる値を同じ向きとみなす。範囲を指定されない限り 0≦θ<2π0\leqq\theta<2\pi か −π<θ≦π-\pi<\theta\leqq\pi の1つを答える。z=0z=0 の偏角は定めない。

例題 4

−1+i-1+i と −23−2i-2\sqrt{3}-2i を極形式で表せ。偏角は 0≦θ<2π0\leqq\theta<2\pi とする。

解き方
∣−1+i∣=2|-1+i|=\sqrt{2} である。
cos⁡θ=−12\cos\theta=-\dfrac{1}{\sqrt{2}} かつ sin⁡θ=12\sin\theta=\dfrac{1}{\sqrt{2}} から θ=34π\theta=\dfrac{3}{4}\pi である。
答えは 2(cos⁡34π+isin⁡34π)\sqrt{2}\left(\cos\dfrac{3}{4}\pi+i\sin\dfrac{3}{4}\pi\right) である。
∣−23−2i∣=12+4=4|-2\sqrt{3}-2i|=\sqrt{12+4}=4 である。
cos⁡θ=−32\cos\theta=-\dfrac{\sqrt{3}}{2} かつ sin⁡θ=−12\sin\theta=-\dfrac{1}{2} から θ=76π\theta=\dfrac{7}{6}\pi である。
答えは 4(cos⁡76π+isin⁡76π)4\left(\cos\dfrac{7}{6}\pi+i\sin\dfrac{7}{6}\pi\right) である。

典型的な誤りは2つある。1つ目は tan⁡θ=ba\tan\theta=\dfrac{b}{a} だけで偏角を決めることである。−1+i-1+i と 1−i1-i はどちらも tan⁡θ=−1\tan\theta=-1 であるが偏角は 34π\dfrac{3}{4}\pi と 74π\dfrac{7}{4}\pi で異なる。点がどの象限にあるかを必ず確認する。2つ目は −2(cos⁡θ+isin⁡θ)-2(\cos\theta+i\sin\theta) を極形式とみなすことである。rr は正でなければならない。−1=cos⁡π+isin⁡π-1=\cos\pi+i\sin\pi を使い 2(cos⁡(θ+π)+isin⁡(θ+π))2(\cos(\theta+\pi)+i\sin(\theta+\pi)) と直す。

積と商の図形的意味

2つの複素数を極形式で z1=r1(cos⁡θ1+isin⁡θ1)z_1=r_1(\cos\theta_1+i\sin\theta_1) と z2=r2(cos⁡θ2+isin⁡θ2)z_2=r_2(\cos\theta_2+i\sin\theta_2) とする。積を展開して実部と虚部をまとめる。

z1z2=r1r2{(cos⁡θ1cos⁡θ2−sin⁡θ1sin⁡θ2)+i(sin⁡θ1cos⁡θ2+cos⁡θ1sin⁡θ2)}z_1z_2=r_1r_2\{(\cos\theta_1\cos\theta_2-\sin\theta_1\sin\theta_2)+i(\sin\theta_1\cos\theta_2+\cos\theta_1\sin\theta_2)\}

かっこの中は数学Ⅱの加法定理そのものである。したがって次の式が成り立つ。

z1z2=r1r2{cos⁡(θ1+θ2)+isin⁡(θ1+θ2)}z_1z_2=r_1r_2\{\cos(\theta_1+\theta_2)+i\sin(\theta_1+\theta_2)\}

積の絶対値は絶対値の積になり積の偏角は偏角の和になる。式で書くと ∣z1z2∣=∣z1∣∣z2∣|z_1z_2|=|z_1||z_2| と arg⁡(z1z2)=arg⁡z1+arg⁡z2\arg(z_1z_2)=\arg z_1+\arg z_2 である。同じ計算で商は絶対値の商と偏角の差になる。

z1z2=r1r2{cos⁡(θ1−θ2)+isin⁡(θ1−θ2)}\frac{z_1}{z_2}=\frac{r_1}{r_2}\{\cos(\theta_1-\theta_2)+i\sin(\theta_1-\theta_2)\}

図形で言い換える。点 zz に w=r(cos⁡θ+isin⁡θ)w=r(\cos\theta+i\sin\theta) を掛けると点 wzwz は z を原点のまわりに θ\theta だけ回転し原点からの距離を rr 倍した点になる。特に i=cos⁡π2+isin⁡π2i=\cos\dfrac{\pi}{2}+i\sin\dfrac{\pi}{2} を掛けると 90∘90^\circ の回転になる。ii を2回掛けると 180∘180^\circ 回って −1-1 倍になる。i2=−1i^2=-1 はこの図形的な事実を式で表したものである。

例題 5

点 z=2+iz=2+i を原点のまわりに π3\dfrac{\pi}{3} だけ回転した点を求めよ。

解き方
回転は cos⁡π3+isin⁡π3=12+32i\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{3}=\dfrac{1}{2}+\dfrac{\sqrt{3}}{2}i を掛ける操作である。
(2+i)(12+32i)=1+3 i+12i+32i2(2+i)\left(\dfrac{1}{2}+\dfrac{\sqrt{3}}{2}i\right)=1+\sqrt{3}\,i+\dfrac{1}{2}i+\dfrac{\sqrt{3}}{2}i^2 である。
実部は 1−321-\dfrac{\sqrt{3}}{2} で虚部は 3+12\sqrt{3}+\dfrac{1}{2} である。
答えは (1−32)+(3+12)i\left(1-\dfrac{\sqrt{3}}{2}\right)+\left(\sqrt{3}+\dfrac{1}{2}\right)i である。

商の公式は割り算を回転の巻き戻しとして読む。z1z2\dfrac{z_1}{z_2} は z1z_1 を arg⁡z2\arg z_2 だけ逆向きに回して 1∣z2∣\dfrac{1}{|z_2|} 倍した点である。極形式と直交形式の両方で同じ商を計算すると三角関数の値が求まる。

例題 6

1+3 i1+i\dfrac{1+\sqrt{3}\,i}{1+i} を2通りに計算して cos⁡π12\cos\dfrac{\pi}{12} の値を求めよ。

解き方
極形式では分子は 2(cos⁡π3+isin⁡π3)2\left(\cos\dfrac{\pi}{3}+i\sin\dfrac{\pi}{3}\right) で分母は 2(cos⁡π4+isin⁡π4)\sqrt{2}\left(\cos\dfrac{\pi}{4}+i\sin\dfrac{\pi}{4}\right) である。
商は 2(cos⁡π12+isin⁡π12)\sqrt{2}\left(\cos\dfrac{\pi}{12}+i\sin\dfrac{\pi}{12}\right) である。π3−π4=π12\dfrac{\pi}{3}-\dfrac{\pi}{4}=\dfrac{\pi}{12} だからである。
直交形式では分母と分子に 1−i1-i を掛ける。分子は (1+3 i)(1−i)=(1+3)+(3−1)i(1+\sqrt{3}\,i)(1-i)=(1+\sqrt{3})+(\sqrt{3}-1)i で分母は2である。
実部を比べて 2cos⁡π12=1+32\sqrt{2}\cos\dfrac{\pi}{12}=\dfrac{1+\sqrt{3}}{2} である。
答えは cos⁡π12=1+322=6+24\cos\dfrac{\pi}{12}=\dfrac{1+\sqrt{3}}{2\sqrt{2}}=\dfrac{\sqrt{6}+\sqrt{2}}{4} である。

典型的な誤りは商の偏角を足してしまうことである。積は偏角の和で商は偏角の差である。また原点以外の点を中心とする回転に w を掛けるだけで済ませる誤りも多い。w を掛ける操作の中心は必ず原点である。中心が別の点の場合は第7節で扱う。

投資で言えば

偏角は対数リターンと同じで掛け算が足し算に変わる

2期の成長率は倍率を掛けるが対数では足し算になる。複素数の積も絶対値は掛け算で偏角は足し算である。

ド・モアブルの定理

第4節の積の公式で z1=z2=cos⁡θ+isin⁡θz_1=z_2=\cos\theta+i\sin\theta とすると偏角が 2θ2\theta になる。もう1回掛けると 3θ3\theta になる。これを繰り返すと次の定理を得る。

(cos⁡θ+isin⁡θ)n=cos⁡nθ+isin⁡nθ(\cos\theta+i\sin\theta)^n=\cos n\theta+i\sin n\theta

これをド・モアブルの定理と呼ぶ。自然数 nn について数学的帰納法で示せる。nn のときに成り立つと仮定して両辺に cos⁡θ+isin⁡θ\cos\theta+i\sin\theta を掛けると積の公式から n+1n+1 のときも成り立つ。n=0n=0 と負の整数でも成り立つ。1cos⁡θ+isin⁡θ=cos⁡(−θ)+isin⁡(−θ)\dfrac{1}{\cos\theta+i\sin\theta}=\cos(-\theta)+i\sin(-\theta) だからである。

絶対値が1でない場合は {r(cos⁡θ+isin⁡θ)}n=rn(cos⁡nθ+isin⁡nθ)\{r(\cos\theta+i\sin\theta)\}^n=r^n(\cos n\theta+i\sin n\theta) となる。n 乗は長さを n 乗し角を n 倍する操作である。

例題 7

(1+i)10(1+i)^{10} を計算せよ。

解き方
極形式にする。1+i=2(cos⁡π4+isin⁡π4)1+i=\sqrt{2}\left(\cos\dfrac{\pi}{4}+i\sin\dfrac{\pi}{4}\right) である。
定理から (1+i)10=(2)10(cos⁡10π4+isin⁡10π4)(1+i)^{10}=(\sqrt{2})^{10}\left(\cos\dfrac{10\pi}{4}+i\sin\dfrac{10\pi}{4}\right) である。
(2)10=25=32(\sqrt{2})^{10}=2^5=32 である。
10π4=2π+π2\dfrac{10\pi}{4}=2\pi+\dfrac{\pi}{2} なので角は π2\dfrac{\pi}{2} と同じ向きである。
答えは 32(0+1⋅i)=32i32(0+1\cdot i)=32i である。

この定理から三角関数の公式も導ける。n=2n=2 とすると左辺は cos⁡2θ−sin⁡2θ+2isin⁡θcos⁡θ\cos^2\theta-\sin^2\theta+2i\sin\theta\cos\theta である。右辺の実部と虚部と比べると cos⁡2θ=cos⁡2θ−sin⁡2θ\cos 2\theta=\cos^2\theta-\sin^2\theta と sin⁡2θ=2sin⁡θcos⁡θ\sin 2\theta=2\sin\theta\cos\theta を得る。数学Ⅱの2倍角の公式である。

典型的な誤りは極形式にせずに展開を始めることである。10乗を二項定理で展開すると11項になり計算の誤りが増える。また rr を n 乗し忘れる誤りも多い。

経済で言えば

ド・モアブルの定理は複利の公式に角度を付けたものである

元本 rr 倍を n 期続けると rnr^n 倍になる。複素数ではそれに加えて向きが毎期 θ\theta ずつ進む。

1の n 乗根

方程式 zn=1z^n=1 の解を1の n 乗根と呼ぶ。解を z=r(cos⁡θ+isin⁡θ)z=r(\cos\theta+i\sin\theta) と置く。ド・モアブルの定理から rn(cos⁡nθ+isin⁡nθ)=1r^n(\cos n\theta+i\sin n\theta)=1 である。右辺の 11 は cos⁡0+isin⁡0\cos 0+i\sin 0 である。絶対値と偏角を比べる。

rn=1,nθ=2kπ(k は整数)r^n=1,\qquad n\theta=2k\pi\quad(k\text{ は整数})

r>0r>0 なので r=1r=1 である。偏角は θ=2kπn\theta=\dfrac{2k\pi}{n} となる。k=0,1,…,n−1k=0,1,\ldots,n-1 で異なる n 個の解が得られ k=nk=n で k=0k=0 の解に戻る。1の n 乗根は単位円に内接する正 n 角形の頂点で1点は1である。

n＝3 の場合を詳しく見る。z3−1=(z−1)(z2+z+1)=0z^3-1=(z-1)(z^2+z+1)=0 なので虚数解は z2+z+1=0z^2+z+1=0 の2解である。その1つを ω\omega と置くと次の関係が成り立つ。

ω3=1,ω2+ω+1=0,ωˉ=ω2\omega^3=1,\qquad \omega^2+\omega+1=0,\qquad \bar{\omega}=\omega^2

複素数と図形

積が回転を表すことを使うと平面図形の問題を計算で解ける。共通テストで最もよく使う道具は次の3つである。

1つ目は点のまわりの回転である。点 β\beta を点 α\alpha のまわりに θ\theta だけ回転した点を γ\gamma とする。まず全体を −α-\alpha だけ平行移動して α\alpha を原点に移す。そこで回転してから α\alpha だけ戻す。

γ−α=(cos⁡θ+isin⁡θ)(β−α)\gamma-\alpha=(\cos\theta+i\sin\theta)(\beta-\alpha)

2つ目は角の大きさである。3点 A(α)A(\alpha)・B(β)B(\beta)・C(γ)C(\gamma) について γ−αβ−α\dfrac{\gamma-\alpha}{\beta-\alpha} の偏角は半直線 AB から半直線 AC へ測った回転角である。絶対値は ACAB\dfrac{AC}{AB} である。この値が実数なら3点は一直線上にある。純虚数なら AB⊥ACAB\perp AC である。

3つ目は三角形の形状である。γ−αβ−α=cos⁡π3±isin⁡π3\dfrac{\gamma-\alpha}{\beta-\alpha}=\cos\dfrac{\pi}{3}\pm i\sin\dfrac{\pi}{3} なら AB＝AC で挟む角が 60∘60^\circ なので三角形 ABC は正三角形である。γ−αβ−α=±i\dfrac{\gamma-\alpha}{\beta-\alpha}=\pm i なら AB＝AC で直角をはさむので直角二等辺三角形である。

現実世界の複素数平面 交流回路

複素数を平面上の点として描く考え方はノルウェー出身の測量技師ヴェッセルの論文と1806年のアルガンの著作に現れる。ヴェッセルの論文は1797年にデンマーク王立科学アカデミーで発表され1799年に同アカデミーの紀要に掲載された。ガウスもこの表示を用いて普及させた。ド・モアブルは17世紀末から18世紀前半に活動したフランス出身の数学者でロンドンで研究した。

現実世界

家庭のコンセントの電圧は一定の周期で向きを変える交流である。電気工学では電圧と電流を複素数平面上の回転する矢印で表す。コイルやコンデンサーは電流の位相を 90∘90^\circ ずらす。この操作は ii を掛ける回転として計算できる。電気工学では電流の記号 i と区別して虚数単位を j と書く。
