平面ベクトル

ベクトルは向きと大きさだけで定まり位置を問わない。和と差と実数倍は数の計算と同じ法則に従う。平行でない2本のベクトルを決めると平面のどのベクトルも1通りに分解でき係数を比べる計算が可能になる。

序章ではベクトルを大きさと向きをもつ量として導入した。この章ではその定義を厳密にして計算の規則を組み立てる。足し算・引き算・実数倍の3つの演算を定義し数の計算と同じ法則が成り立つことを確かめる。続いて平面のどのベクトルも平行でない2本のベクトルで1通りに表せることを示す。最後に座標を使ってベクトルを数の組で表す。

共通テストで直接問われるのは主に3点である。図形の中のベクトルを2本の基本のベクトルで表すこと・平行条件から未知数を求めること・成分から大きさを求めることである。第1点の分解の一意性は第3章の交点の計算と第4章の空間の計算を支える。

有向線分とベクトルの相等

線分ABに A から B への向きをつけたものを有向線分ABと呼ぶ。Aを始点・Bを終点という。有向線分は位置と向きと長さの3つをもつ。

有向線分から位置の情報を捨てて向きと長さだけを考えたものをベクトルと呼ぶ。有向線分ABが表すベクトルを AB→\overrightarrow{AB} と書く。1文字で a⃗\vec{a} と書くこともある。ベクトル a⃗\vec{a} の長さを大きさといい ∣a⃗∣|\vec{a}| で表す。

2つのベクトル a⃗\vec{a} と b⃗\vec{b} の向きが同じで大きさも等しい時 a⃗=b⃗\vec{a}=\vec{b} と書き相等であるという。平行移動して重なる有向線分はすべて同じベクトルを表す。位置が異なっていても等しい。

特別なベクトルが3つある。大きさが1のベクトルを単位ベクトルと呼ぶ。始点と終点が一致する AA→\overrightarrow{AA} は大きさが0であり零ベクトルと呼んで 0⃗\vec{0} で表す。零ベクトルの向きは考えない。a⃗\vec{a} と大きさが等しく向きが反対のベクトルを逆ベクトルと呼び −a⃗-\vec{a} で表す。BA→=−AB→\overrightarrow{BA}=-\overrightarrow{AB} である。

位置を捨てる理由は計算を簡単にするためである。移動や速度では「どこから」より「どちらへどれだけ」が問題になる。東へ3 kmの移動は東京駅から始めても大阪駅から始めても同じ移動である。位置を捨てておけば矢印を自由に平行移動して始点と終点をつなげる。次節の加法はこの自由を前提にしている。

大きさ ∣a⃗∣|\vec{a}| は0以上の実数でありスカラーである。∣a⃗∣=0|\vec{a}|=0 となるのは a⃗=0⃗\vec{a}=\vec{0} の時だけである。絶対値記号と同じ縦棒を使うが中身がベクトルの時は長さを表す。

例題 1

平行四辺形ABCDで AB→\overrightarrow{AB} と等しいベクトルと AD→\overrightarrow{AD} と等しいベクトルを頂点の記号で答えよ。また CB→\overrightarrow{CB} を AD→\overrightarrow{AD} で表せ。

解き方
手順1 平行四辺形では向かい合う辺が平行で長さが等しい。
手順2 ABと平行で同じ向きの辺は D から C へ向かう辺である。よって AB→=DC→\overrightarrow{AB}=\overrightarrow{DC}。
手順3 同様に AD→=BC→\overrightarrow{AD}=\overrightarrow{BC}。
手順4 CB→\overrightarrow{CB} は BC→\overrightarrow{BC} の逆ベクトルなので CB→=−AD→\overrightarrow{CB}=-\overrightarrow{AD}。
答え DC→\overrightarrow{DC} ・ BC→\overrightarrow{BC} ・ −AD→-\overrightarrow{AD}

典型的な誤りは頂点の順序である。平行四辺形ABCDで AB→=CD→\overrightarrow{AB}=\overrightarrow{CD} と書くのは誤りである。CからDへの向きはAからBへの向きと反対だからである。頂点は周に沿って順に並ぶことを図で確かめてから式を書く。

恋愛で言えば

ベクトルの相等は出会った場所を問わない

2人の関係を向きと距離で表すなら出会いが大学でも職場でも同じ関係である。位置を捨てて向きと大きさだけを比べるのが相等である。

ベクトルの加法と減法

2つのベクトル a⃗\vec{a} と b⃗\vec{b} の和を次のように定める。a⃗=AB→\vec{a}=\overrightarrow{AB} となる点A・Bをとり b⃗=BC→\vec{b}=\overrightarrow{BC} となる点Cをとる。この時 AC→\overrightarrow{AC} を a⃗+b⃗\vec{a}+\vec{b} とする。つまり

AB→+BC→=AC→\overrightarrow{AB}+\overrightarrow{BC}=\overrightarrow{AC}

である。1つ目の終点を2つ目の始点につなぐので三角形の法則と呼ぶ。始点をそろえて2本を辺とする平行四辺形を描くと対角線が和になる。これを平行四辺形の法則と呼ぶ。2つの法則は同じ和を与える。序章の東へ3 kmと北へ4 kmの移動の合成はこの加法である。

加法では数の足し算と同じ法則が成り立つ。

a⃗+b⃗=b⃗+a⃗,(a⃗+b⃗)+c⃗=a⃗+(b⃗+c⃗),a⃗+0⃗=a⃗,a⃗+(−a⃗)=0⃗\vec{a}+\vec{b}=\vec{b}+\vec{a},\qquad (\vec{a}+\vec{b})+\vec{c}=\vec{a}+(\vec{b}+\vec{c}),\qquad \vec{a}+\vec{0}=\vec{a},\qquad \vec{a}+(-\vec{a})=\vec{0}

交換法則は平行四辺形の2通りの辺のたどり方が同じ対角線に着くことから分かる。

加法を繰り返すと折れ線のつなぎ方の規則が得られる。AB→+BC→+CD→=AD→\overrightarrow{AB}+\overrightarrow{BC}+\overrightarrow{CD}=\overrightarrow{AD} のように途中の点が順に消え最初の始点と最後の終点だけが残る。始点に戻る閉じた折れ線では和が零ベクトルになる。三角形ABCでは AB→+BC→+CA→=0⃗\overrightarrow{AB}+\overrightarrow{BC}+\overrightarrow{CA}=\vec{0} である。この性質は等式の証明で途中の点を差し込む時に使う。例えば AC→\overrightarrow{AC} を AB→+BC→\overrightarrow{AB}+\overrightarrow{BC} と書き換えるのは点Bを経由する道に置き換える操作である。

差は逆ベクトルを足すことで定める。a⃗−b⃗=a⃗+(−b⃗)\vec{a}-\vec{b}=\vec{a}+(-\vec{b}) である。始点をそろえて a⃗=OA→\vec{a}=\overrightarrow{OA} と b⃗=OB→\vec{b}=\overrightarrow{OB} とすると差は次の形になる。

OA→−OB→=BA→\overrightarrow{OA}-\overrightarrow{OB}=\overrightarrow{BA}

差 a⃗−b⃗\vec{a}-\vec{b} は b⃗\vec{b} の終点から a⃗\vec{a} の終点へ向かう矢印である。引く側から引かれる側へ向かう点に注意する。この形を裏返した AB→=OB→−OA→\overrightarrow{AB}=\overrightarrow{OB}-\overrightarrow{OA} は始点を O にそろえる変形として第3章で何度も使う。

例題 2

正六角形ABCDEFの中心をOとし AB→=a⃗\overrightarrow{AB}=\vec{a} と AF→=b⃗\overrightarrow{AF}=\vec{b} とする。AO→\overrightarrow{AO} と AC→\overrightarrow{AC} と AD→\overrightarrow{AD} と CE→\overrightarrow{CE} を a⃗\vec{a} と b⃗\vec{b} で表せ。

解き方
手順1 正六角形は中心Oで6つの正三角形に分かれる。四角形ABOFはひし形なので AO→=a⃗+b⃗\overrightarrow{AO}=\vec{a}+\vec{b}。
手順2 BC→\overrightarrow{BC} は AO→\overrightarrow{AO} と平行で同じ長さなので BC→=a⃗+b⃗\overrightarrow{BC}=\vec{a}+\vec{b}。
手順3 AC→=AB→+BC→=2a⃗+b⃗\overrightarrow{AC}=\overrightarrow{AB}+\overrightarrow{BC}=2\vec{a}+\vec{b}。
手順4 DはAOの延長上でAD＝2AOなので AD→=2a⃗+2b⃗\overrightarrow{AD}=2\vec{a}+2\vec{b}。
手順5 AE→=AF→+FE→=b⃗+(a⃗+b⃗)=a⃗+2b⃗\overrightarrow{AE}=\overrightarrow{AF}+\overrightarrow{FE}=\vec{b}+(\vec{a}+\vec{b})=\vec{a}+2\vec{b}。始点をAにそろえて CE→=AE→−AC→=−a⃗+b⃗\overrightarrow{CE}=\overrightarrow{AE}-\overrightarrow{AC}=-\vec{a}+\vec{b}。
答え a⃗+b⃗\vec{a}+\vec{b} ・ 2a⃗+b⃗2\vec{a}+\vec{b} ・ 2a⃗+2b⃗2\vec{a}+2\vec{b} ・ b⃗−a⃗\vec{b}-\vec{a}

ベクトルの等式を示す時も始点をそろえる方針が使える。全部の矢印を同じ1点から出る矢印の差に書き直せば図に頼らず文字式の計算だけで確かめられる。

例題 3

任意の4点A・B・C・Dについて AB→+CD→=AD→+CB→\overrightarrow{AB}+\overrightarrow{CD}=\overrightarrow{AD}+\overrightarrow{CB} が成り立つことを示せ。

解き方
手順1 左辺から右辺を引いて 0⃗\vec{0} になることを示す。
手順2 AB→−AD→=DB→\overrightarrow{AB}-\overrightarrow{AD}=\overrightarrow{DB} である。始点がAでそろっているので差は終点Dから終点Bへ向かう。
手順3 CD→−CB→=BD→\overrightarrow{CD}-\overrightarrow{CB}=\overrightarrow{BD} である。
手順4 合計は DB→+BD→=DD→=0⃗\overrightarrow{DB}+\overrightarrow{BD}=\overrightarrow{DD}=\vec{0}。
答え 左辺と右辺の差が 0⃗\vec{0} なので等式が成り立つ。別解として点Oを1つ決め全部を OB→−OA→\overrightarrow{OB}-\overrightarrow{OA} の形に直すと両辺とも OB→+OD→−OA→−OC→\overrightarrow{OB}+\overrightarrow{OD}-\overrightarrow{OA}-\overrightarrow{OC} になる。
会計で言えば

AB ＝ OB − OA は期末残高から期首残高を引く計算である

O を基準日にとると OA が期首残高で OB が期末残高である。増減額 AB は後から前を引く。逆に引くと符号が反対になる。

実数倍と平行条件

実数 kk とベクトル a⃗\vec{a} に対し ka⃗k\vec{a} を次のように定める。a⃗≠0⃗\vec{a}\neq\vec{0} の時

  • k>0k>0 なら a⃗\vec{a} と同じ向きで大きさが k∣a⃗∣k|\vec{a}| のベクトル
  • k<0k<0 なら a⃗\vec{a} と反対の向きで大きさが ∣k∣∣a⃗∣|k||\vec{a}| のベクトル
  • k=0k=0 なら 0⃗\vec{0}

とする。a⃗=0⃗\vec{a}=\vec{0} の時は k0⃗=0⃗k\vec{0}=\vec{0} とする。(−1)a⃗(-1)\vec{a} は逆ベクトル −a⃗-\vec{a} と一致する。実数倍についても数の計算と同じ法則が成り立つ。

k(la⃗)=(kl)a⃗,(k+l)a⃗=ka⃗+la⃗,k(a⃗+b⃗)=ka⃗+kb⃗k(l\vec{a})=(kl)\vec{a},\qquad (k+l)\vec{a}=k\vec{a}+l\vec{a},\qquad k(\vec{a}+\vec{b})=k\vec{a}+k\vec{b}

3つ目の分配法則は三角形を kk 倍に拡大すると3辺がすべて kk 倍になる相似から分かる。この法則があるので 3(a⃗−2b⃗)−2(a⃗+b⃗)=a⃗−8b⃗3(\vec{a}-2\vec{b})-2(\vec{a}+\vec{b})=\vec{a}-8\vec{b} のような計算を文字式と同じ手順で進めてよい。

0⃗\vec{0} でない2つのベクトルの向きが同じか反対である時 a⃗\vec{a} と b⃗\vec{b} は平行であるといい a⃗∥b⃗\vec{a}\parallel\vec{b} と書く。実数倍の定義から次の平行条件が成り立つ。

a⃗≠0⃗, b⃗≠0⃗ のときa⃗∥b⃗  ⟺  b⃗=ka⃗ となる実数 k がある\vec{a}\neq\vec{0},\ \vec{b}\neq\vec{0}\ \text{のとき}\quad \vec{a}\parallel\vec{b}\iff \vec{b}=k\vec{a}\ \text{となる実数}\ k\ \text{がある}

a⃗≠0⃗\vec{a}\neq\vec{0} の時 a⃗∣a⃗∣\dfrac{\vec{a}}{|\vec{a}|} は a⃗\vec{a} と同じ向きの単位ベクトルである。大きさを ∣a⃗∣|\vec{a}| で割ると1になるからである。a⃗\vec{a} に平行な単位ベクトルは向きが同じものと反対のものの2つあり ±a⃗∣a⃗∣\pm\dfrac{\vec{a}}{|\vec{a}|} である。

例題 4

∣a⃗∣=4|\vec{a}|=4 とする。a⃗\vec{a} に平行な単位ベクトルと a⃗\vec{a} と反対向きで大きさ10のベクトルを a⃗\vec{a} で表せ。

解き方
手順1 平行な単位ベクトルは ±a⃗∣a⃗∣=±14a⃗\pm\dfrac{\vec{a}}{|\vec{a}|}=\pm\dfrac{1}{4}\vec{a}。
手順2 反対向きで大きさ10は単位ベクトル −14a⃗-\dfrac{1}{4}\vec{a} の10倍である。
答え ±14a⃗\pm\dfrac{1}{4}\vec{a} ・ −52a⃗-\dfrac{5}{2}\vec{a}

演算法則が数と同じなのでベクトルを未知数とする1次方程式も移項で解ける。ただしベクトルどうしの割り算は定義しない。両辺を割ってよいのは0でない実数だけである。

例題 5

3(a⃗−2b⃗)−2(a⃗+b⃗)3(\vec{a}-2\vec{b})-2(\vec{a}+\vec{b}) を簡単にせよ。また 2x⃗+a⃗=5b⃗−x⃗2\vec{x}+\vec{a}=5\vec{b}-\vec{x} を満たす x⃗\vec{x} を a⃗\vec{a} と b⃗\vec{b} で表せ。

解き方
手順1 分配法則で 3a⃗−6b⃗−2a⃗−2b⃗=a⃗−8b⃗3\vec{a}-6\vec{b}-2\vec{a}-2\vec{b}=\vec{a}-8\vec{b}。
手順2 後半は x⃗\vec{x} を左辺へ・ a⃗\vec{a} を右辺へ移項して 3x⃗=5b⃗−a⃗3\vec{x}=5\vec{b}-\vec{a}。
手順3 両辺に実数 13\dfrac{1}{3} をかけて x⃗=5b⃗−a⃗3\vec{x}=\dfrac{5\vec{b}-\vec{a}}{3}。
答え a⃗−8b⃗\vec{a}-8\vec{b} ・ x⃗=−13a⃗+53b⃗\vec{x}=-\dfrac{1}{3}\vec{a}+\dfrac{5}{3}\vec{b}

典型的な誤りは平行な単位ベクトルを1つしか答えないことである。平行は向きが同じ場合と反対の場合の両方を含む。問題文が「同じ向き」と指定していない限り符号の2通りを答える。

投資で言えば

実数倍はレバレッジで負の実数倍は空売りである

2倍は同じ向きに損益を2倍にし −1倍は向きを反転させる。0倍はポジションを持たないことで零ベクトルに当たる。

1次独立とベクトルの分解

平面の2つのベクトル a⃗\vec{a} と b⃗\vec{b} がどちらも 0⃗\vec{0} でなく平行でもない時 a⃗\vec{a} と b⃗\vec{b} は1次独立であるという。1次独立な2本のベクトルについて次の定理が成り立つ。

ベクトルの分解 a⃗\vec{a} と b⃗\vec{b} が1次独立ならば平面の任意のベクトル p⃗\vec{p} は p⃗=sa⃗+tb⃗\vec{p}=s\vec{a}+t\vec{b} の形にただ1通りに表せる。

表せる理由 始点をOにそろえて a⃗=OA→\vec{a}=\overrightarrow{OA} と b⃗=OB→\vec{b}=\overrightarrow{OB} と p⃗=OP→\vec{p}=\overrightarrow{OP} とする。Pを通りOBに平行な直線と直線OAの交点をA′とする。Pを通りOAに平行な直線と直線OBの交点をB′とする。a⃗\vec{a} と b⃗\vec{b} が平行でないので2つの交点は必ず存在する。OA′はOAと同じ直線上にあるので OA′→=sa⃗\overrightarrow{OA'}=s\vec{a} と書ける。同様に OB′→=tb⃗\overrightarrow{OB'}=t\vec{b} と書ける。平行四辺形OA′PB′から p⃗=sa⃗+tb⃗\vec{p}=s\vec{a}+t\vec{b} である。

1通りである理由 sa⃗+tb⃗=s′a⃗+t′b⃗s\vec{a}+t\vec{b}=s'\vec{a}+t'\vec{b} とする。移項すると (s−s′)a⃗=(t′−t)b⃗(s-s')\vec{a}=(t'-t)\vec{b} である。もし s≠s′s\neq s' なら両辺を s−s′s-s' で割って a⃗=t′−ts−s′b⃗\vec{a}=\dfrac{t'-t}{s-s'}\vec{b} となる。これは a⃗\vec{a} と b⃗\vec{b} が平行であるか a⃗=0⃗\vec{a}=\vec{0} であることを意味し仮定に反する。よって s=s′s=s' で同様に t=t′t=t' である。

一意性から次の係数比較が使える。

a⃗, b⃗ が1次独立のときsa⃗+tb⃗=s′a⃗+t′b⃗  ⟺  s=s′ かつ t=t′\vec{a},\ \vec{b}\ \text{が1次独立のとき}\quad s\vec{a}+t\vec{b}=s'\vec{a}+t'\vec{b}\iff s=s'\ \text{かつ}\ t=t'

1次独立な2本のベクトルは平面に斜めの座標軸を張る。係数 (s,t)(s,t) はその斜交座標での座標である。sa⃗+tb⃗=0⃗s\vec{a}+t\vec{b}=\vec{0} ならば s=t=0s=t=0 という形もよく使う。

例題 6

a⃗\vec{a} と b⃗\vec{b} は1次独立とする。(s+1)a⃗+(2t−3)b⃗=0⃗(s+1)\vec{a}+(2t-3)\vec{b}=\vec{0} を満たす実数 ss と tt を求めよ。また (2s−t)a⃗+(s+t)b⃗=4a⃗+5b⃗(2s-t)\vec{a}+(s+t)\vec{b}=4\vec{a}+5\vec{b} を満たす ss と tt を求めよ。

解き方
手順1 1次独立なので 0⃗\vec{0} を表す係数はどちらも0である。s+1=0s+1=0 と 2t−3=02t-3=0 から s=−1s=-1 ・ t=32t=\dfrac{3}{2}。
手順2 後半は係数比較で 2s−t=42s-t=4 と s+t=5s+t=5。
手順3 2式を足して 3s=93s=9 から s=3s=3。代入して t=2t=2。
検算 2×3−2=42\times3-2=4 ・ 3+2=53+2=5。
答え 前半 s=−1, t=32s=-1,\ t=\dfrac{3}{2} ・ 後半 s=3, t=2s=3,\ t=2

典型的な誤りは1次独立を確かめずに係数を比べることである。例えば b⃗=2a⃗\vec{b}=2\vec{a} の時 2a⃗+0b⃗2\vec{a}+0\vec{b} と 0a⃗+1b⃗0\vec{a}+1\vec{b} は同じベクトルである。係数比較は1次独立という前提があって初めて成り立つ。

平面では1次独立なベクトルは最大で2本である。3本目の c⃗\vec{c} は定理により必ず c⃗=sa⃗+tb⃗\vec{c}=s\vec{a}+t\vec{b} と書けるので他の2本から作れてしまう。平面を表すのに必要な独立な方向の数が2であることを平面の次元が2であるという。第4章の空間では独立な方向が3本になり第6章では一般の nn 本に広げる。

分解の定理は図形の問題を計算に変える出発点でもある。三角形OABで OA→=a⃗\overrightarrow{OA}=\vec{a} と OB→=b⃗\overrightarrow{OB}=\vec{b} とおけば三角形の上のどの点への矢印も sa⃗+tb⃗s\vec{a}+t\vec{b} と書ける。例えば辺ABの中点Mについて OM→=OA→+12AB→=a⃗+12(b⃗−a⃗)=12a⃗+12b⃗\overrightarrow{OM}=\overrightarrow{OA}+\dfrac{1}{2}\overrightarrow{AB}=\vec{a}+\dfrac{1}{2}(\vec{b}-\vec{a})=\dfrac{1}{2}\vec{a}+\dfrac{1}{2}\vec{b} である。この計算を一般の内分点に広げるのが第3章である。

野球で言えば

1次独立は打撃と守備の2軸で選手を評価することである

2軸が打率と長打率のように同じ向きを測ると守備の差を表せない。向きの異なる2軸なら選手を1組の数で書き分けられる。

ベクトルの成分表示と大きさ

座標平面でx軸の正の向きの単位ベクトルを e1⃗\vec{e_1} とし y軸の正の向きの単位ベクトルを e2⃗\vec{e_2} とする。この2本を基本ベクトルと呼ぶ。2本は1次独立なので前節の定理により任意のベクトルは a⃗=a1e1⃗+a2e2⃗\vec{a}=a_1\vec{e_1}+a_2\vec{e_2} とただ1通りに表せる。この係数を並べて

a⃗=(a1,a2)\vec{a}=(a_1,a_2)

と書くのが成分表示である。a1a_1 をx成分・ a2a_2 をy成分と呼ぶ。始点を原点Oに置いた時の終点の座標が成分と一致する。

成分表示の利点は演算が成分ごとの計算になることである。前節までの法則から次の式が成り立つ。

(a1,a2)±(b1,b2)=(a1±b1, a2±b2),k(a1,a2)=(ka1, ka2)(a_1,a_2)\pm(b_1,b_2)=(a_1\pm b_1,\ a_2\pm b_2),\qquad k(a_1,a_2)=(ka_1,\ ka_2)

相等は成分がすべて等しいことと同値である。(a1,a2)=(b1,b2)  ⟺  a1=b1(a_1,a_2)=(b_1,b_2)\iff a_1=b_1 かつ a2=b2a_2=b_2 である。

大きさは三平方の定理で求める。成分が a1a_1 と a2a_2 の矢印は横 ∣a1∣|a_1| ・縦 ∣a2∣|a_2| の直角三角形の斜辺である。

∣a⃗∣=a1 2+a2 2|\vec{a}|=\sqrt{a_1^{\,2}+a_2^{\,2}}

2点 A(a1,a2)A(a_1,a_2) と B(b1,b2)B(b_1,b_2) について AB→=OB→−OA→=(b1−a1, b2−a2)\overrightarrow{AB}=\overrightarrow{OB}-\overrightarrow{OA}=(b_1-a_1,\ b_2-a_2) である。成分は終点の座標から始点の座標を引く。大きさ ∣AB→∣|\overrightarrow{AB}| は2点間の距離と一致する。

平行条件を成分で書く。a⃗=(a1,a2)\vec{a}=(a_1,a_2) と b⃗=(b1,b2)\vec{b}=(b_1,b_2) が 0⃗\vec{0} でない時 a⃗∥b⃗  ⟺  a1b2−a2b1=0\vec{a}\parallel\vec{b}\iff a_1b_2-a_2b_1=0 である。b⃗=ka⃗\vec{b}=k\vec{a} を成分で書いて kk を消去すると得られる。

この式は比の形 a1:a2=b1:b2a_1:a_2=b_1:b_2 を分母を払って書いたものである。比の形で暗記すると成分に0がある時に割り算ができず誤る。a1b2−a2b1=0a_1b_2-a_2b_1=0 の形なら0を含む場合もそのまま使える。この量 a1b2−a2b1a_1b_2-a_2b_1 は第2章で三角形の面積として再び現れ第7章では行列式と呼ばれる。

成分による計算法則は基本ベクトルの式から確かめられる。a⃗+b⃗=(a1e1⃗+a2e2⃗)+(b1e1⃗+b2e2⃗)=(a1+b1)e1⃗+(a2+b2)e2⃗\vec{a}+\vec{b}=(a_1\vec{e_1}+a_2\vec{e_2})+(b_1\vec{e_1}+b_2\vec{e_2})=(a_1+b_1)\vec{e_1}+(a_2+b_2)\vec{e_2} である。交換法則・結合法則・分配法則を使って同じ基本ベクトルの項をまとめただけである。成分表示は新しい規則ではなく第4節の分解を座標軸の方向で行ったものである。

例題 7

a⃗=(2,1)\vec{a}=(2,1) と b⃗=(−1,3)\vec{b}=(-1,3) とする。(1) p⃗=(1,11)\vec{p}=(1,11) を sa⃗+tb⃗s\vec{a}+t\vec{b} の形で表せ。(2) c⃗=(x,6)\vec{c}=(x,6) が d⃗=(2,3)\vec{d}=(2,3) と平行になる xx を求めよ。

解き方
手順1 sa⃗+tb⃗=(2s−t, s+3t)s\vec{a}+t\vec{b}=(2s-t,\ s+3t)。成分を比べて 2s−t=12s-t=1 と s+3t=11s+3t=11。
手順2 1式目を3倍して2式目に足すと 7s=147s=14 から s=2s=2。代入して t=3t=3。
検算 2×2−3=12\times2-3=1 ・ 2+3×3=112+3\times3=11。
手順3 平行条件 x×3−6×2=0x\times3-6\times2=0 から x=4x=4。このとき c⃗=(4,6)=2d⃗\vec{c}=(4,6)=2\vec{d} である。
答え (1) p⃗=2a⃗+3b⃗\vec{p}=2\vec{a}+3\vec{b} (2) x=4x=4
例題 8

a⃗=(3,−4)\vec{a}=(3,-4) と同じ向きの単位ベクトルを成分で求めよ。また2点 A(−1,2)A(-1,2) と B(5,−6)B(5,-6) について AB→\overrightarrow{AB} と ∣AB→∣|\overrightarrow{AB}| を求めよ。

解き方
手順1 ∣a⃗∣=9+16=5|\vec{a}|=\sqrt{9+16}=5。単位ベクトルは 15(3,−4)=(35,−45)\dfrac{1}{5}(3,-4)=\left(\dfrac{3}{5},-\dfrac{4}{5}\right)。

例題 9

4点 A(1,1)A(1,1) ・ B(4,2)B(4,2) ・ C(5,5)C(5,5) ・ D(x,y)D(x,y) を頂点とする四角形ABCDが平行四辺形になる時 DD の座標を求めよ。

解き方
手順1 ABCDが平行四辺形である条件は AD→=BC→\overrightarrow{AD}=\overrightarrow{BC} である。頂点の順序から向かい合う辺はADとBCである。
手順2 BC→=(5−4, 5−2)=(1,3)\overrightarrow{BC}=(5-4,\ 5-2)=(1,3)。
手順3 AD→=(x−1, y−1)\overrightarrow{AD}=(x-1,\ y-1) を (1,3)(1,3) と等しくおいて x=2x=2 ・ y=4y=4。
検算 AB→=(3,1)\overrightarrow{AB}=(3,1) と DC→=(3,1)\overrightarrow{DC}=(3,1) も等しい。
答え D(2,4)D(2,4)

典型的な誤りは AB→\overrightarrow{AB} の成分で始点から終点を引くことである。(a1−b1, a2−b2)(a_1-b_1,\ a_2-b_2) は BA→\overrightarrow{BA} の成分であり符号が反対になる。大きさは同じなので距離の問題では誤りが表に現れず内積や平行条件の問題で失点する。

もう1つの誤りは和の大きさを大きさの和で求めることである。a⃗=(3,0)\vec{a}=(3,0) と b⃗=(0,4)\vec{b}=(0,4) では ∣a⃗∣+∣b⃗∣=7|\vec{a}|+|\vec{b}|=7 だが ∣a⃗+b⃗∣=∣(3,4)∣=5|\vec{a}+\vec{b}|=|(3,4)|=5 である。一般に ∣a⃗+b⃗∣≤∣a⃗∣+∣b⃗∣|\vec{a}+\vec{b}|\le|\vec{a}|+|\vec{b}| が成り立ち等号は2本が同じ向きの時かどちらかが 0⃗\vec{0} の時に限る。三角形の2辺の和が残りの1辺より長いことと同じ内容であり三角不等式と呼ぶ。和の大きさは先に成分を足してから求める。

現実世界 航空機の対地速度

航空機の速度は2つのベクトルの和である。空気に対する速度を対気速度と呼び地面に対する速度を対地速度と呼ぶ。風速をベクトルで表すと次の関係が成り立つ。

対地速度=対気速度+風速\text{対地速度}=\text{対気速度}+\text{風速}

例として機首を真北に向けて対気速度 400 km/h で飛ぶ機体を考える。西から東へ 30 km/h の風が吹くと東を x 軸・北を y 軸として対地速度は (0,400)+(30,0)=(30,400)(0,400)+(30,0)=(30,400) である。大きさは 302+4002=160900≈401.1\sqrt{30^2+400^2}=\sqrt{160900}\approx 401.1 km/h で機体は北から東へ流される。

真北へ進むには対気速度のx成分を −30-30 にして風を打ち消す。対気速度の大きさが400なので y成分は 4002−302≈398.9\sqrt{400^2-30^2}\approx 398.9 となる。機首は北から西へ約4.3°向き対地速度は約 398.9 km/h になる。これは速度を北向きと東向きの1次独立な2方向に分解して成分ごとに考えた計算である。

学習指導要領解説は物理で扱うベクトルと数学Cのベクトルの関係にも触れている。物理では速度や運動量の合成と分解を中心に学び数学Cでは演算の法則と図形の性質を中心に学ぶ。航空機の例は物理の題材を数学の分解の定理で整理したものである。物体に複数の力がはたらく時の合力も同じ加法で求める。

現実世界

操縦士が使う飛行計算盤 E6B は風の三角形をこのベクトルの和として図で解く道具である。横風成分と向かい風成分への分解も同じ計算である。

確認問題

問1 ・ 正六角形のベクトル

正六角形ABCDEFで AB→=a⃗\overrightarrow{AB}=\vec{a} と AF→=b⃗\overrightarrow{AF}=\vec{b} とする。AD→\overrightarrow{AD} を表すものを1つ選べ。

  1. a⃗+b⃗\vec{a}+\vec{b}
  2. 2a⃗+b⃗2\vec{a}+\vec{b}
  3. 2a⃗+2b⃗2\vec{a}+2\vec{b}
  4. 3a⃗+3b⃗3\vec{a}+3\vec{b}
解答と解説
正解は 3 である。中心をOとすると AO→=a⃗+b⃗\overrightarrow{AO}=\vec{a}+\vec{b} で AD は AO の2倍である。
問2 ・ 差のベクトル

問1と同じ設定で CE→\overrightarrow{CE} を表すものを1つ選べ。

  1. a⃗−b⃗\vec{a}-\vec{b}
  2. b⃗−a⃗\vec{b}-\vec{a}
  3. a⃗+b⃗\vec{a}+\vec{b}
  4. 2b⃗−a⃗2\vec{b}-\vec{a}
解答と解説
正解は 2 である。AC→=2a⃗+b⃗\overrightarrow{AC}=2\vec{a}+\vec{b} と AE→=a⃗+2b⃗\overrightarrow{AE}=\vec{a}+2\vec{b} から CE→=AE→−AC→=−a⃗+b⃗\overrightarrow{CE}=\overrightarrow{AE}-\overrightarrow{AC}=-\vec{a}+\vec{b} である。1 は引く順序を逆にした誤りである。
問3 ・ 平行条件

a⃗=(2,−1)\vec{a}=(2,-1) と b⃗=(x,3)\vec{b}=(x,3) が平行になる xx の値を求めよ。

  1. −6-6
  2. −32-\dfrac{3}{2}
  3. 32\dfrac{3}{2}
  4. 6
解答と解説
正解は 1 である。a1b2−a2b1=2×3−(−1)×x=6+x=0a_1b_2-a_2b_1=2\times3-(-1)\times x=6+x=0 から x=−6x=-6。このとき b⃗=(−6,3)=−3a⃗\vec{b}=(-6,3)=-3\vec{a} で向きは反対である。
問4 ・ 単位ベクトル

a⃗=(−5,12)\vec{a}=(-5,12) と同じ向きの単位ベクトルを1つ選べ。

  1. (−512,1)\left(-\dfrac{5}{12},1\right)
  2. (−513,1213)\left(-\dfrac{5}{13},\dfrac{12}{13}\right)
  3. (513,−1213)\left(\dfrac{5}{13},-\dfrac{12}{13}\right)
  4. (−57,127)\left(-\dfrac{5}{7},\dfrac{12}{7}\right)
解答と解説
正解は 2 である。∣a⃗∣=25+144=13|\vec{a}|=\sqrt{25+144}=13 で割る。3 は反対向きの単位ベクトルである。
問5 ・ 係数比較

a⃗\vec{a} と b⃗\vec{b} は1次独立である。(2s−1)a⃗+(s+t)b⃗=3a⃗−b⃗(2s-1)\vec{a}+(s+t)\vec{b}=3\vec{a}-\vec{b} が成り立つ時 tt の値を求めよ。

  1. −3-3
  2. −1-1
  3. 1
  4. 2
解答と解説
正解は 1 である。係数比較で 2s−1=32s-1=3 から s=2s=2。s+t=−1s+t=-1 から t=−3t=-3。
問6 ・ 分解

a⃗=(1,2)\vec{a}=(1,2) と b⃗=(3,−1)\vec{b}=(3,-1) を用いて p⃗=(7,0)\vec{p}=(7,0) を sa⃗+tb⃗s\vec{a}+t\vec{b} と表す。s+ts+t の値を求めよ。

  1. 1
  2. 2
  3. 3
  4. 7
解答と解説
正解は 3 である。s+3t=7s+3t=7 と 2s−t=02s-t=0。2式目から t=2st=2s で1式目に代入して 7s=77s=7。s=1s=1 ・ t=2t=2 で s+t=3s+t=3。検算 (1,2)+2(3,−1)=(7,0)(1,2)+2(3,-1)=(7,0)。
問7 ・ 2点を結ぶベクトル

A(−1,4)A(-1,4) と B(2,0)B(2,0) について ∣AB→∣|\overrightarrow{AB}| を求めよ。

  1. 3
  2. 4
  3. 5
  4. 7

正解は 3 の 5 である。AB→=(2−(−1), 0−4)=(3,−4)\overrightarrow{AB}=(2-(-1),\ 0-4)=(3,-4) で大きさは 9+16=5\sqrt{9+16}=5。
問8 ・ 定義の確認

次の記述のうち誤っているものを1つ選べ。

  1. 0a⃗0\vec{a} は零ベクトルである
  2. 平行四辺形ABCDで AB→=DC→\overrightarrow{AB}=\overrightarrow{DC} である
  3. a⃗\vec{a} と b⃗\vec{b} が平行でも 0⃗\vec{0} でなければ1次独立である
  4. AB→+BA→=0⃗\overrightarrow{AB}+\overrightarrow{BA}=\vec{0} である
解答と解説
正解は 3 である。1次独立には 0⃗\vec{0} でないことに加えて平行でないことが必要である。平行な2本では平面のベクトルを分解できない。

この章の要点

要点 ベクトルは向きと大きさだけで定まり平行移動して重なる矢印は等しい。
AB→+BC→=AC→\overrightarrow{AB}+\overrightarrow{BC}=\overrightarrow{AC} ・ AB→=OB→−OA→\overrightarrow{AB}=\overrightarrow{OB}-\overrightarrow{OA} で始点をそろえる。
a⃗∥b⃗  ⟺  b⃗=ka⃗\vec{a}\parallel\vec{b}\iff\vec{b}=k\vec{a}。平行な単位ベクトルは ±a⃗∣a⃗∣\pm\dfrac{\vec{a}}{|\vec{a}|} の2つである。
1次独立な a⃗\vec{a} と b⃗\vec{b} で任意のベクトルは sa⃗+tb⃗s\vec{a}+t\vec{b} とただ1通りに表せ係数比較ができる。
成分は終点から始点を引き ∣a⃗∣=a1 2+a2 2|\vec{a}|=\sqrt{a_1^{\,2}+a_2^{\,2}} で求める。
成分の平行条件は a1b2−a2b1=0a_1b_2-a_2b_1=0 である。

残っている問い

  • この章はベクトルを「平行移動して重なる有向線分の集まり」として定義した。大学の線形代数では加法と実数倍の法則を満たす集合をベクトル空間と定義し矢印の図を前提にしない。数列や関数もその意味でベクトルになる。第6章以降でこの見方に移る。
  • 航空機の例は風が一定で上昇や下降をしない場合の近似である。実際の運航では高度ごとに風が異なる。
  • 学習指導要領解説は平面上のベクトルの導入を風の吹き方や物体の移動などの具体的な事象から始めるよう述べている。どの教科書がどの例を使うかは確認していない。
