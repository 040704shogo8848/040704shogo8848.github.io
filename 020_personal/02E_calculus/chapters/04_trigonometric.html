三角関数

数学Ⅰの三角比は0°から180°までの図形の計量の道具であった。角を回転の量として一般角に広げ単位円上の点の座標で定義し直すと三角関数になる。加法定理を1本導けば2倍角・半角・合成はすべてそこから導ける。

第1章では関数をグラフで調べる方法を整理し第2章と第3章で指数関数と対数関数を扱った。この章の三角関数は周期をもつ関数である。数学Ⅰの三角比は三角形の辺と角の関係を表す道具で角は0°から180°に限られていた。ここでは角を回転の量として負の角や360°を超える角まで広げ単位円を使って定義し直す。

共通テストの数学Ⅱでは三角関数が毎年のように大問の題材になる。問われるのは弧度法での値の計算・グラフの平行移動と周期・加法定理から導く2倍角と合成・範囲つきの方程式と不等式である。この章はこの順に積み上げる。微分法を学ぶ第10章では角を弧度法で測ることが前提になるので第2節の弧度法は確実に身につける。

三角比の復習と一般角

直角三角形で直角でない角の1つを θ\theta とする。斜辺を rr・θ\theta の向かいの辺を yy・θ\theta に隣り合う辺を xx とすると数学Ⅰでは次のように定めた。

sin⁡θ=yr,cos⁡θ=xr,tan⁡θ=yx\sin\theta=\frac{y}{r},\qquad \cos\theta=\frac{x}{r},\qquad \tan\theta=\frac{y}{x}

数学Ⅰではさらに座標平面の半円を使って 0∘≦θ≦180∘0^\circ \leqq \theta \leqq 180^\circ まで定義を広げた。原点を中心とする半径 rr の半円の周上に点 P(x,y)P(x, y) をとり OPOP と xx 軸の正の向きとのなす角を θ\theta とすると上と同じ式で三角比が定まる。90° を超えると xx が負になるので cos⁡θ\cos \theta と tan⁡θ\tan \theta は負になる。

正弦定理と余弦定理の要点

三角形 ABCABC の角 AA・BB・CC の向かいの辺の長さを aa・bb・cc とし外接円の半径を RR とする。数学Ⅰで扱った2つの定理は次のとおりである。

asin⁡A=bsin⁡B=csin⁡C=2Ra2=b2+c2−2bccos⁡A\frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}=2R \qquad\qquad a^2=b^2+c^2-2bc\cos A

正弦定理は外接円の直径 2R2R を基準にして辺と向かいの角の正弦が比例することを示す。余弦定理は三平方の定理に −2bccos⁡A-2bc \cos A の補正を加えたもので A=90∘A=90^\circ のとき cos⁡A=0\cos A=0 となり三平方の定理に戻る。2辺とその間の角が分かれば余弦定理で残りの辺が求まり1辺と向かいの角が分かれば正弦定理で外接円の半径が求まる。第5節の加法定理の導出では余弦定理と同じ考え方の距離の計算を使う。

一般角

平面上で点 OO を中心に半直線 OPOP を回転させる。最初の位置の半直線 OXOX を始線と呼び回転した半直線 OPOP を動径と呼ぶ。反時計回りを正の向き・時計回りを負の向きとして回転の量を角で表す。こうすると −45∘-45^\circ や 400° のような角も意味をもつ。回転の量として表した角を一般角と呼ぶ。

400° の動径は 40° の動径と同じ位置にある。1回転 360° ごとに動径は元の位置に戻るからである。動径 OPOP が始線となす角の1つを α\alpha とすると OPOP の表す一般角は次の式でまとめて表せる。

θ=α+360∘×n(n は整数)\theta=\alpha+360^\circ\times n \qquad (n \text{ は整数})

典型的な誤りは動径の位置と角の大きさを混同することである。400° と 40° は動径の位置が同じでも角としては異なる。三角関数の値は動径の位置だけで決まるので sin⁡400∘=sin⁡40∘\sin 400^\circ =\sin 40^\circ が成り立つ。

弧度法

度数法は1回転を360等分した単位で360という数に数学上の理由はない。数学Ⅱからは長さを基準にした角の測り方を使う。半径 rr の円で長さ rr の弧に対する中心角を 1ラジアンと定める。角を弧の長さと半径の比で表す方法を弧度法と呼ぶ。

θ=弧の長さ半径\theta=\frac{\text{弧の長さ}}{\text{半径}}

半径 rr の円周の長さは 2πr2\pi r なので1回転の中心角は 2πr÷r=2π2\pi r\div r=2\pi ラジアンである。これが 360° に当たるので次の対応が成り立つ。

180∘=π ラジアン,1 ラジアン=180∘π≈57.3∘180^\circ=\pi \text{ ラジアン},\qquad 1 \text{ ラジアン}=\frac{180^\circ}{\pi}\approx 57.3^\circ

弧度法の利点は扇形の公式が簡潔になる点である。半径 rr で中心角 θ\theta の扇形を考える。弧の長さは中心角に比例し1回転 2π2\pi のとき 2πr2\pi r である。面積も中心角に比例し1回転のとき πr2\pi r^{2} である。

単位円による定義と相互関係

原点 OO を中心とする半径1の円を単位円と呼ぶ。一般角 θ\theta の動径と単位円の交点を P(x,y)P(x, y) とする。このとき三角関数を次のように定義する。

sin⁡θ=y,cos⁡θ=x,tan⁡θ=yx(x≠0)\sin\theta=y,\qquad \cos\theta=x,\qquad \tan\theta=\frac{y}{x}\quad(x\neq 0)

半径 rr の円で定めた数学Ⅰの式で r=1r=1 とした形である。三角比の値は円の大きさによらないので半径を1にすれば sin⁡θ\sin \theta と cos⁡θ\cos \theta は点の座標そのものになる。tan⁡θ\tan \theta は直線 OPOP の傾きであり直線 x=1x=1 と直線 OPOP の交点の yy 座標にも等しい。

θ\theta がどの象限の角かで符号が定まる。sin⁡θ\sin \theta は yy 座標なので第1・第2象限で正である。cos⁡θ\cos \theta は xx 座標なので第1・第4象限で正である。tan⁡θ\tan \theta は傾きなので第1・第3象限で正である。値の範囲は −1≦sin⁡θ≦1-1\leqq \sin \theta \leqq 1 と −1≦cos⁡θ≦1-1\leqq \cos \theta \leqq 1 で tan⁡θ\tan \theta はすべての実数値をとる。

相互関係

P(cos⁡θ,sin⁡θ)P(\cos \theta , \sin \theta ) は単位円の周上にあるので x2+y2=1x^{2}+y^{2}=1 を満たす。両辺を cos⁡2θ\cos ^{2}\theta で割ると第3の式が得られる。

sin⁡2θ+cos⁡2θ=1,tan⁡θ=sin⁡θcos⁡θ,1+tan⁡2θ=1cos⁡2θ\sin^2\theta+\cos^2\theta=1,\qquad \tan\theta=\frac{\sin\theta}{\cos\theta},\qquad 1+\tan^2\theta=\frac{1}{\cos^2\theta}

3つの式は数学Ⅰと同じ形であるが一般角でも成り立つ。sin⁡2θ\sin ^{2}\theta は (sin⁡θ)2(\sin \theta )^{2} を表す記法である。

グラフと周期

θ\theta を横軸にとり sin⁡θ\sin \theta の値を縦軸にとると波の形のグラフになる。これを正弦曲線と呼ぶ。θ\theta が 0 から π2\frac{\pi}{2} まで増えると PP は単位円を上っていき yy 座標は0から1まで増える。π2\frac{\pi}{2} から 3π2\frac{3\pi}{2} までは1から −1-1 まで減り 3π2\frac{3\pi}{2} から 2π2\pi までは −1-1 から0まで戻る。

関数 f(x)f(x) に対し0でない定数 pp があってすべての xx で f(x+p)=f(x)f(x+p)=f(x) が成り立つとき f(x)f(x) を周期関数と呼ぶ。pp のうち正で最小のものを周期と呼ぶ。sin⁡θ\sin \theta と cos⁡θ\cos \theta の周期は 2π2\pi である。動径が1回転すると PP が元の位置に戻るからである。y=sin⁡θy=\sin \theta のグラフは原点について対称で y=cos⁡θy=\cos \theta のグラフは yy 軸について対称である。sin⁡(−θ)=−sin⁡θ\sin (-\theta )=-\sin \theta と cos⁡(−θ)=cos⁡θ\cos (-\theta )=\cos \theta がこの対称性を表している。

tan⁡θ\tan \theta の周期は π\pi である。動径が半回転すると PP は原点について反対側に移るが直線 OPOP の傾きは変わらないからである。cos⁡θ=0\cos \theta =0 となる θ=π2+nπ\theta =\frac{\pi}{2}+n\pi では tan⁡θ\tan \theta は定義されない。

加法定理とその導出

sin⁡75∘\sin 75^\circ や cos⁡15∘\cos 15^\circ は 30°・45°・60° の値の組み合わせで表せる。そのための公式が加法定理である。4つの式があるが導出するのは1つでよい。残りはそこから導ける。

cos⁡(α−β)=cos⁡αcos⁡β+sin⁡αsin⁡β\cos(\alpha-\beta)=\cos\alpha\cos\beta+\sin\alpha\sin\beta

距離を2通りに計算する

単位円の周上に P(cos⁡α,sin⁡α)P(\cos \alpha , \sin \alpha ) と Q(cos⁡β,sin⁡β)Q(\cos \beta , \sin \beta ) をとる。2点間の距離の2乗を座標で計算する。

PQ2=(cos⁡α−cos⁡β)2+(sin⁡α−sin⁡β)2=2−2(cos⁡αcos⁡β+sin⁡αsin⁡β)PQ^2=(\cos\alpha-\cos\beta)^2+(\sin\alpha-\sin\beta)^2=2-2(\cos\alpha\cos\beta+\sin\alpha\sin\beta)

展開の途中で cos⁡2α+sin⁡2α=1\cos ^{2}\alpha +\sin ^{2}\alpha =1 と cos⁡2β+sin⁡2β=1\cos ^{2}\beta +\sin ^{2}\beta =1 を使った。次に図全体を原点のまわりに −β-\beta だけ回転させる。QQ は A(1,0)A(1, 0) に移り PP は P′(cos⁡(α−β),sin⁡(α−β))P'(\cos (\alpha -\beta ), \sin (\alpha -\beta )) に移る。回転しても2点間の距離は変わらないので PQ=P′APQ=P'A である。

P′A2=(cos⁡(α−β)−1)2+sin⁡2(α−β)=2−2cos⁡(α−β)P'A^2=(\cos(\alpha-\beta)-1)^2+\sin^2(\alpha-\beta)=2-2\cos(\alpha-\beta)

2つの式を等しいとおくと cos⁡(α−β)=cos⁡αcos⁡β+sin⁡αsin⁡β\cos (\alpha -\beta )=\cos \alpha \cos \beta +\sin \alpha \sin \beta が得られる。

残りの3式

β\beta を −β-\beta に置き換えると cos⁡(−β)=cos⁡β\cos (-\beta )=\cos \beta と sin⁡(−β)=−sin⁡β\sin (-\beta )=-\sin \beta から cos⁡\cos の和の式が得られる。α\alpha を π2−α\frac{\pi}{2}-\alpha に置き換えると cos⁡(π2−α)=sin⁡α\cos (\frac{\pi}{2}-\alpha )=\sin \alpha から sin⁡\sin の式が得られる。

cos⁡(α±β)=cos⁡αcos⁡β∓sin⁡αsin⁡β\cos(\alpha\pm\beta)=\cos\alpha\cos\beta\mp\sin\alpha\sin\beta
sin⁡(α±β)=sin⁡αcos⁡β±cos⁡αsin⁡β\sin(\alpha\pm\beta)=\sin\alpha\cos\beta\pm\cos\alpha\sin\beta
tan⁡(α±β)=tan⁡α±tan⁡β1∓tan⁡αtan⁡β\tan(\alpha\pm\beta)=\frac{\tan\alpha\pm\tan\beta}{1\mp\tan\alpha\tan\beta}

tan⁡\tan の式は sin⁡(α+β)/cos⁡(α+β)\sin (\alpha +\beta )/\cos (\alpha +\beta ) の分子と分母を cos⁡αcos⁡β\cos \alpha \cos \beta で割って得る。複号は上下の順に対応させて読む。cos⁡\cos の式で符号が反転する点が典型的な誤りの原因である。cos⁡(α+β)\cos (\alpha +\beta ) の右辺は引き算である。

tan⁡75∘=(tan⁡45∘+tan⁡30∘)/(1−tan⁡45∘tan⁡30∘)=(1+1/3)/(1−1/3)=(3+1)/(3−1)\tan 75^\circ =(\tan 45^\circ +\tan 30^\circ )/(1-\tan 45^\circ \tan 30^\circ )=(1+1/\sqrt{3})/(1-1/\sqrt{3})=(\sqrt{3}+1)/(\sqrt{3}-1) である。
分母を有理化すると (3+1)2/2=(4+23)/2=2+3(\sqrt{3}+1)^{2}/2=(4+2\sqrt{3})/2=2+\sqrt{3} である。

2直線のなす角

直線 y=m1xy=m_{1}x と y=m2xy=m_{2}x が xx 軸の正の向きとなす角を α\alpha・β\beta とすると m1=tan⁡αm_{1}=\tan \alpha で m2=tan⁡βm_{2}=\tan \beta である。2直線のなす角 θ\theta は tan⁡\tan の加法定理で求まる。

tan⁡θ=∣m1−m21+m1m2∣(1+m1m2≠0)\tan\theta=\left|\frac{m_1-m_2}{1+m_1m_2}\right| \qquad (1+m_1m_2\neq 0)

1+m1m2=01+m_{1}m_{2}=0 すなわち m1m2=−1m_{1}m_{2}=-1 のとき2直線は垂直である。数学Ⅱの図形と方程式で扱う垂直条件と一致する。

2倍角・半角・合成

2倍角の公式

加法定理で β=α\beta =\alpha とおくと次の式が得られる。cos⁡2α\cos 2\alpha は sin⁡2α+cos⁡2α=1\sin ^{2}\alpha +\cos ^{2}\alpha =1 を使って3通りに書ける。

sin⁡2α=2sin⁡αcos⁡α,cos⁡2α=cos⁡2α−sin⁡2α=1−2sin⁡2α=2cos⁡2α−1\sin2\alpha=2\sin\alpha\cos\alpha,\qquad \cos2\alpha=\cos^2\alpha-\sin^2\alpha=1-2\sin^2\alpha=2\cos^2\alpha-1
tan⁡2α=2tan⁡α1−tan⁡2α\tan2\alpha=\frac{2\tan\alpha}{1-\tan^2\alpha}

半角の公式

cos⁡2α=1−2sin⁡2α\cos 2\alpha =1-2\sin ^{2}\alpha と cos⁡2α=2cos⁡2α−1\cos 2\alpha =2\cos ^{2}\alpha -1 を sin⁡2α\sin ^{2}\alpha と cos⁡2α\cos ^{2}\alpha について解く。α\alpha を α/2\alpha /2 に置き換えると次の形になる。

sin⁡2α2=1−cos⁡α2,cos⁡2α2=1+cos⁡α2,tan⁡2α2=1−cos⁡α1+cos⁡α\sin^2\frac{\alpha}{2}=\frac{1-\cos\alpha}{2},\qquad \cos^2\frac{\alpha}{2}=\frac{1+\cos\alpha}{2},\qquad \tan^2\frac{\alpha}{2}=\frac{1-\cos\alpha}{1+\cos\alpha}

半角の公式は2乗を1乗の cos⁡\cos に直す変形である。第12章の積分で sin⁡2x\sin ^{2}x を積分する場面でこの変形を使う。

例題 6

0<α<π20<\alpha <\frac{\pi}{2} で sin⁡α=35\sin \alpha =\frac{3}{5} のとき sin⁡2α\sin 2\alpha と cos⁡2α\cos 2\alpha を求めよ。また cos⁡π8\cos \frac{\pi}{8} の値を求めよ。

解き方
α\alpha は第1象限の角なので cos⁡α=1−925=45\cos \alpha =\sqrt{1-\frac{9}{25}}=\frac{4}{5} である。
sin⁡2α=2×35×45=2425\sin 2\alpha =2\times \frac{3}{5}\times \frac{4}{5}=\frac{24}{25} である。cos⁡2α=1−2×925=725\cos 2\alpha =1-2\times \frac{9}{25}=\frac{7}{25} である。
検算として (2425)2+(725)2=(576+49)/625=1\left(\frac{24}{25}\right)^{2}+\left(\frac{7}{25}\right)^{2}=(576+49)/625=1 で一致する。
半角の公式で cos⁡2(π8)=(1+cos⁡π4)/2=(2+2)/4\cos ^{2}(\frac{\pi}{8})=(1+\cos \frac{\pi}{4})/2=(2+\sqrt{2})/4 である。π8\frac{\pi}{8} は第1象限の角なので cos⁡π8=2+2/2\cos \frac{\pi}{8}=\sqrt{2+\sqrt{2}}/2 である。

三角関数の合成

asin⁡θ+bcos⁡θa \sin \theta +b \cos \theta の形の式は1つの正弦の式にまとめられる。これを三角関数の合成と呼ぶ。座標平面上に点 (a,b)(a, b) をとり原点からの距離を rr・動径の角を α\alpha とする。a=rcos⁡αa=r \cos \alpha・b=rsin⁡αb=r \sin \alpha であるから加法定理を逆向きに使うと次の式になる。

asin⁡θ+bcos⁡θ=r(sin⁡θcos⁡α+cos⁡θsin⁡α)=rsin⁡(θ+α),r=a2+b2a\sin\theta+b\cos\theta=r(\sin\theta\cos\alpha+\cos\theta\sin\alpha)=r\sin(\theta+\alpha),\qquad r=\sqrt{a^2+b^2}
例題 7

0≦θ<2π0\leqq \theta <2\pi のとき y=sin⁡θ+3cos⁡θy=\sin \theta +\sqrt{3}\cos \theta の最大値と最小値とそのときの θ\theta を求めよ。

解き方
点 (1,3)(1, \sqrt{3}) をとると r=1+3=2r=\sqrt{1+3}=2 で α=π3\alpha =\frac{\pi}{3} である。
y=2sin⁡(θ+π3)y=2\sin (\theta +\frac{\pi}{3}) となる。θ+π3\theta +\frac{\pi}{3} のとりうる範囲は π3≦θ+π3<7π3\frac{\pi}{3}\leqq \theta +\frac{\pi}{3}<\frac{7\pi}{3} である。
この範囲で sin⁡(θ+π3)=1\sin (\theta +\frac{\pi}{3})=1 となるのは θ+π3=π2\theta +\frac{\pi}{3}=\frac{\pi}{2} のときで θ=π6\theta =\frac{\pi}{6} である。最大値は2である。
sin⁡(θ+π3)=−1\sin (\theta +\frac{\pi}{3})=-1 となるのは θ+π3=3π2\theta +\frac{\pi}{3}=\frac{3\pi}{2} のときで θ=7π6\theta =\frac{7\pi}{6} である。最小値は −2-2 である。

典型的な誤りは点の座標を (b,a)(b, a) の順にとり α\alpha を取り違えることである。sin⁡θ\sin \theta の係数を xx 座標・cos⁡θ\cos \theta の係数を yy 座標にとる。

投資で言えば

三角関数の合成は相関ゼロの2銘柄の分散投資である

振れ幅 aa と bb の波を足しても振れ幅は a+ba+b ではなく a2+b2\sqrt{a^{2}+b^{2}} になる。相関0の2資産を合わせた標準偏差と同じ式である。

方程式と不等式

三角関数を含む方程式と不等式は単位円で解く。sin⁡θ=k\sin \theta =k なら直線 y=ky=k と単位円の交点を求め cos⁡θ=k\cos \theta =k なら直線 x=kx=k との交点を求める。解は θ\theta の範囲の指定に従って書き出す。

例題 8

0≦θ<2π0\leqq \theta <2\pi のとき方程式 2sin⁡2θ−cos⁡θ−1=02\sin ^{2}\theta -\cos \theta -1=0 を解け。

解き方
sin⁡2θ=1−cos⁡2θ\sin ^{2}\theta =1-\cos ^{2}\theta を代入して cos⁡θ\cos \theta だけの式にする。2(1−cos⁡2θ)−cos⁡θ−1=02(1-\cos ^{2}\theta )-\cos \theta -1=0 である。
整理すると 2cos⁡2θ+cos⁡θ−1=02\cos ^{2}\theta +\cos \theta -1=0 となり (2cos⁡θ−1)(cos⁡θ+1)=0(2\cos \theta -1)(\cos \theta +1)=0 である。
cos⁡θ=12\cos \theta =\frac{1}{2} のとき θ=π3\theta =\frac{\pi}{3} と 5π3\frac{5\pi}{3} である。cos⁡θ=−1\cos \theta =-1 のとき θ=π\theta =\pi である。
答えは θ=π3\theta =\frac{\pi}{3}・π\pi・5π3\frac{5\pi}{3} である。
例題 9

0≦θ<2π0\leqq \theta <2\pi のとき不等式 sin⁡θ≧12\sin \theta \geqq \frac{1}{2} を解け。また方程式 sin⁡θ+3cos⁡θ=1\sin \theta +\sqrt{3}\cos \theta =1 を解け。

解き方
単位円で yy 座標が 12\frac{1}{2} 以上になる部分を求める。境界は θ=π6\theta =\frac{\pi}{6} と 5π6\frac{5\pi}{6} で答えは π6≦θ≦5π6\frac{\pi}{6}\leqq \theta \leqq \frac{5\pi}{6} である。
後半は合成して 2sin⁡(θ+π3)=12\sin (\theta +\frac{\pi}{3})=1 すなわち sin⁡(θ+π3)=12\sin (\theta +\frac{\pi}{3})=\frac{1}{2} とする。
t=θ+π3t=\theta +\frac{\pi}{3} とおくと tt の範囲は π3≦t<7π3\frac{\pi}{3}\leqq t<\frac{7\pi}{3} である。この範囲で sin⁡t=12\sin t=\frac{1}{2} となる tt は 5π6\frac{5\pi}{6} と 13π6\frac{13\pi}{6} である。
θ=t−π3\theta =t-\frac{\pi}{3} から θ=π2\theta =\frac{\pi}{2} と 11π6\frac{11\pi}{6} である。検算として θ=π2\theta =\frac{\pi}{2} で 1+0=11+0=1 となり成り立つ。

典型的な誤りは tt の範囲を 0≦t<2π0\leqq t<2\pi のまま解いて t=π6t=\frac{\pi}{6} を答えに含めることである。t=π6t=\frac{\pi}{6} なら θ=−π6\theta =-\frac{\pi}{6} となり範囲の外である。置き換えたら変数の範囲も必ず置き換える。

現実世界の三角関数 交流電力

家庭のコンセントの電圧は時間 tt の正弦関数 V=V0sin⁡(2πft)V=V_{0}\sin (2\pi ft) で表される。ff は1秒あたりの振動の回数で周波数と呼ぶ。周期は 1/f1/f 秒である。日本では東日本が 50 Hz で西日本が 60 Hz と2つの周波数が併存する。境界は静岡県の富士川と新潟県の糸魚川の付近とされる。明治期に東京は欧州製の発電機を入れ大阪は米国製の発電機を入れたことが起源と説明される。

現実世界

2つの周波数の系統はそのままでは接続できない。周波数変換所で一度直流に変えてから相手の周波数の交流に直して電力を融通する。周期 150\frac{1}{50} 秒の波と 160\frac{1}{60} 秒の波は位相をそろえられないからである。

回転運動と波動は周期をもつので三角関数で表される。学習指導要領解説は観覧車がある高さ以上にある時間を求める活動を例に挙げている。半径 rr の観覧車が一定の速さで回るとき高さは h=h0−rcos⁡ωth=h_{0}-r \cos \omega t の形の式になる。h≧kh\geqq k を解く問題は第7節の不等式と同じ手順で解ける。

確認問題

問1 ・ 弧度法

210° を弧度法で表したものを1つ選べ。

  1. 5π6\frac{5\pi}{6}
  2. 7π6\frac{7\pi}{6}
  3. 4π3\frac{4\pi}{3}
  4. 7π4\frac{7\pi}{4}
解答と解説
正解は 2 である。210×π180=7π6210\times \frac{\pi}{180}=\frac{7\pi}{6} である。
問2 ・ 扇形

半径4で弧の長さが6の扇形がある。中心角 θ\theta と面積 SS を求めよ。

解答と解説
θ=64=32\theta =\frac{6}{4}=\frac{3}{2} で S=rl/2=4×6÷2=12S=rl/2=4\times 6\div 2=12 である。中心角は弧度法で 32\frac{3}{2} ラジアンで約 86° である。
問3 ・ 相互関係

π<θ<3π2\pi <\theta <\frac{3\pi}{2} で cos⁡θ=−35\cos \theta =-\frac{3}{5} のとき tan⁡θ\tan \theta の値を求めよ。

解答と解説
tan⁡θ=43\tan \theta =\frac{4}{3} である。sin⁡2θ=1−925=1625\sin ^{2}\theta =1-\frac{9}{25}=\frac{16}{25} で θ\theta は第3象限の角なので sin⁡θ=−45\sin \theta =-\frac{4}{5} である。tan⁡θ=(−45)÷(−35)=43\tan \theta =(-\frac{4}{5})\div (-\frac{3}{5})=\frac{4}{3} となり第3象限で tan⁡θ\tan \theta が正である事実とも一致する。
問4 ・ 周期

関数 y=3cos⁡(4θ+π)y=3\cos (4\theta +\pi ) の周期として正しいものを1つ選べ。

  1. π4\frac{\pi}{4}
  2. π2\frac{\pi}{2}
  3. 2π2\pi
  4. 8π8\pi
解答と解説
正解は 2 である。周期は 2π4=π2\frac{2\pi}{4}=\frac{\pi}{2} である。係数3は振幅を変えるだけで周期に影響しない。+π+\pi は平行移動で周期に影響しない。
問5 ・ 加法定理

cos⁡105∘\cos 105^\circ の値として正しいものを1つ選べ。

  1. (6+2)/4(\sqrt{6}+\sqrt{2})/4
  2. (6−2)/4(\sqrt{6}-\sqrt{2})/4
  3. (2−6)/4(\sqrt{2}-\sqrt{6})/4
  4. −(6+2)/4-(\sqrt{6}+\sqrt{2})/4
解答と解説
正解は 3 である。cos⁡(60∘+45∘)=cos⁡60∘cos⁡45∘−sin⁡60∘sin⁡45∘=12(22)−(32)(22)=(2−6)/4\cos (60^\circ +45^\circ )=\cos 60^\circ \cos 45^\circ -\sin 60^\circ \sin 45^\circ =\frac{1}{2}(\frac{\sqrt{2}}{2})-(\frac{\sqrt{3}}{2})(\frac{\sqrt{2}}{2})=(\sqrt{2}-\sqrt{6})/4 である。105° は第2象限の角なので負の値になり符号も一致する。
問6 ・ 合成と最大最小

0≦θ≦π20\leqq \theta \leqq \frac{\pi}{2} のとき y=3sin⁡θ+4cos⁡θy=3\sin \theta +4\cos \theta の最大値と最小値を求めよ。

解答と解説
最大値5・最小値3である。点 (3, 4) から r=5r=5 で y=5sin⁡(θ+α)y=5\sin (\theta +\alpha ) となる。α\alpha は cos⁡α=35\cos \alpha =\frac{3}{5}・sin⁡α=45\sin \alpha =\frac{4}{5} を満たす角で約 53° である。θ+α\theta +\alpha は α\alpha 以上 α+π2\alpha +\frac{\pi}{2} 以下を動き π2\frac{\pi}{2} を含むので最大値は5である。最小値は区間の端で調べる。θ=0\theta =0 で y=4y=4 となり θ=π2\theta =\frac{\pi}{2} で y=3y=3 となるので最小値は3である。
問7 ・ 2倍角を含む方程式

0≦θ<2π0\leqq \theta <2\pi のとき方程式 cos⁡2θ=cos⁡θ\cos 2\theta =\cos \theta の解の個数を求めよ。

解答と解説
3個である。cos⁡2θ=2cos⁡2θ−1\cos 2\theta =2\cos ^{2}\theta -1 を代入して 2cos⁡2θ−cos⁡θ−1=02\cos ^{2}\theta -\cos \theta -1=0 となる。(2cos⁡θ+1)(cos⁡θ−1)=0(2\cos \theta +1)(\cos \theta -1)=0 より cos⁡θ=1\cos \theta =1 で θ=0\theta =0 である。cos⁡θ=−12\cos \theta =-\frac{1}{2} で θ=2π3\theta =\frac{2\pi}{3} と 4π3\frac{4\pi}{3} である。
問8 ・ グラフの性質

次の記述のうち誤っているものを1つ選べ。

  1. y=sin⁡θy=\sin \theta のグラフは原点について対称である
  2. y=cos⁡θy=\cos \theta のグラフは yy 軸について対称である
  3. y=tan⁡θy=\tan \theta の周期は 2π2\pi である
  4. y=sin⁡2θy=\sin 2\theta の周期は π\pi である
解答と解説
正解は 3 である。tan⁡(θ+π)=tan⁡θ\tan (\theta +\pi )=\tan \theta が成り立つので y=tan⁡θy=\tan \theta の周期は π\pi である。

この章の要点

要点 一般角は回転の量で表した角である。動径の位置が同じなら三角関数の値は等しい。
弧度法は弧の長さ÷半径で角を測る。180∘=π180^\circ =\pi で扇形は l=rθl=r\theta と S=r2θ/2S=r^{2}\theta /2 である。
単位円の周上の点 PP の xx 座標が cos⁡θ\cos \theta・yy 座標が sin⁡θ\sin \theta・直線 OPOP の傾きが tan⁡θ\tan \theta である。
sin⁡θ\sin \theta と cos⁡θ\cos \theta の周期は 2π2\pi で tan⁡θ\tan \theta の周期は π\pi である。y=sin⁡kθy=\sin k\theta の周期は 2π/k2\pi /k である。
加法定理は2点間の距離を回転の前後で比べて導く。2倍角と半角は加法定理から導く。
asin⁡θ+bcos⁡θa \sin \theta +b \cos \theta は点 (a,b)(a, b) を使って a2+b2sin⁡(θ+α)\sqrt{a^{2}+b^{2}}\sin (\theta +\alpha ) に合成する。
方程式と不等式は単位円で解く。置き換えた変数は範囲も置き換える。

残っている問い

  • 数学Ⅱでは三角関数を単位円上の点の座標で定義した。角の大きさの定義には弧の長さを使っており弧の長さそのものの厳密な定義は積分を使う第13章の曲線の長さまで持ち越している。
  • 半角の公式は学習指導要領と解説の本文に明記されていない。解説が挙げるのは加法定理と2倍角の公式と合成である。共通テストでは2倍角の公式からその場で導けば足りる。
  • 東日本と西日本の周波数の起源は明治期に輸入した発電機の違いとする説明が一般的である。発電機の導入年と事業者の一次資料は確認できていない。
