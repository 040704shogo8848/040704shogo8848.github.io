- 比喩とトリビアは理解の補助である。本文の1割以下とする

## 章の構成（この順）

1. 導入の段落1〜2つ。前の章とのつながり・この章で身につける内容・共通テストで問われる論点
2. 本文の h2 を4〜7個。各 h2 の中で次の3要素を必ず入れる
   - **定義**: 重要語は初出で <strong> で示し、1文で定義する
   - **年表または統計**: 世界史は tb-tl（年表）を各章2個以上。地理は tb-tw（表）か tb-bars（横棒）で統計を示し、全ての数値に時点と出典番号を付ける
   - **因果の整理**: 背景 → 出来事 → 結果 の流れを SVG の図か tb-tw の表で示す
3. 例題は各 h2 に1題を目安とする。形式は WRITING_GUIDE.md の ex と同じ。資料や地図の読み取りを手順で示す
4. 現実世界の h2 を1個。産業・企業・現代の国際関係との接点を短く
5. 確認問題 h2。共通テスト形式の4択を6〜8問。形式は qz（手本の章と同じ）。種類を混ぜる：正誤の組合せ・年代整序（世界史）・地図や統計の読み取り（地理）・資料文の読み取り・因果の判断。**共通テストの過去問は転載しない。** 出題傾向を踏まえた自作の問題だけを使う。統計を使う問題の数値は本文に出典付きで示した値と一致させる
6. この章の要点 h2。tb-key で5〜7行
7. 考えるための問い h2。答えが一つに定まらない問い（定義・立場・評価・因果の重み付けで答えが変わるもの）を、読者が考えるきっかけとして挙げる。冒頭に説明の1文を置き、ul の li class="tb-vnote" に「<strong>問い（疑問文）</strong> 手がかり（本文の内容から立場の対立を1〜2文。答えは書かない）」の形で並べる。作業の記録（資料を開けなかった等）・細かい数値の差・調べれば答えが出る事実は載せない
8. 出典 h2。番号付きリスト。「タイトル — URL」の形

## 事実の正確さ（最重要）

- **全ての数値と年代に時点と出典を付ける。** 書式は本文中に「（2023年、出典3）」のように括弧で添える。年代そのものが主題の世界史の年表項目は、章末の出典で裏付けられていればよい
- 統計は WebFetch で一次資料（総務省統計局・e-Stat・国土地理院・気象庁・外務省・経済産業省・農林水産省・資源エネルギー庁・FAO・World Bank・UN・IEA・WTO・UNWTO など）から取得する。curl は使えない。WebFetch に PDF や xlsx を渡すとローカルに保存され、結果にパスが出る。pdf は pdftotext -layout で読む
- **単位の誤読が起きやすい。** 千トン・万人・百万ドル・％などの単位は一次資料で再確認する
- 確認できない項目は推測しない。本文に「確認できず」と書く。考えるための問いには載せない（調べれば答えが出る事実だからである）
- 出典が食い違う場合は両方を書く。例「1,234万人（A統計、2020年、出典2）とする資料と1,198万人（B統計、2020年、出典5）とする資料がある」。平均を取らない
- 構成比・増減率など自分で計算した値は「本書による算出値」と書く
- Wikipedia は補助にとどめ、可能な限り一次資料か学術的な資料で裏付ける

## 表記の規範

- **国境・地名・係争地の表記は日本政府の公式見解に従う。** 北方領土（択捉島・国後島・色丹島・歯舞群島）・竹島・尖閣諸島は日本固有の領土として扱う。尖閣諸島について日本政府は領有権の問題は存在しないとの立場である。竹島と北方領土はそれぞれ韓国とロシアによる不法占拠とする政府見解を事実として紹介する。海域名は日本海・東シナ海を用いる。クリミアはウクライナの領域として扱う。国名と地域名は外務省の「国・地域」の表記に従う（例 台湾は地域として扱う）
- 世界史の通説が分かれる論点は立場を併記する。「A とする見方と B とする見方がある」と書き、どちらかを本文で断定しない。教科書で定着した説明と新しい研究の説明が異なる場合も両方を書く
- 人名・地名・王朝名は高校教科書で一般的な表記を用い、必要なら別表記を括弧で添える。年代は西暦で書く

## 地図と図

- 各章に SVG の図を4個以上置く。うち地理は地図を2個以上、世界史は地図を1個以上とする。figure class="tb-fig" の中に svg と figcaption を置く
- 外部 CDN・外部画像・外部フォントに依存しない。インライン SVG だけで作る
- 地図は手描きせず、次の生成ツールを使う。Natural Earth（パブリックドメイン）の国境データから SVG を出力する。北方領土・クリミアの扱いは日本政府見解に合わせ済みである。竹島と尖閣諸島はデータの上で小さすぎるため --japan-islands で点として描く

```

例 世界図: --bbox -180,-58,180,84 --proj robinson --fill "BRA=var(--warm),ARG=var(--warm)" --graticule 30 --id k12a

--inner を付けると <g> の中身だけを出力する。自分で <svg viewBox=…> を書き、凡例や文字を加える
```

- 地図1枚は 70KB 以下にする。世界全図は1章2枚まで。地域図は bbox を必要な範囲に絞る。サイズが大きい時は --tol 1.5 で簡略化を強める
- 国の塗り分けは ISO3 コードで指定する。歴史地図（帝国の範囲など）は現代の国境を薄く描いた上に、範囲を path や polygon で重ねてよい。その場合は「範囲はおおよそである」と figcaption に書く
- 年表・因果図・グラフは手書きの SVG でよい。グラフは座標を計算してから描く。数値と目盛りを一致させる
- viewBox の幅は720を基準とする。文字は font-size 12 以上。色は var(--warm) var(--cool) var(--accent) var(--ink) var(--sub) var(--muted) var(--line) var(--dim) を使う
- id（marker・clipPath・地図の --id）は章ごとに一意にする。接頭辞は 02J なら j＋章番号2桁、02K なら k＋章番号2桁とする（例 j07a、k12b）
- 図の中の文字も日本語規範の検査対象である
- --shot でスクリーンショットを撮り、Read で見て、重なり・はみ出し・誤りを直す

## 比喩とトリビア（補助）

- 各章に3〜5個。class は an an-bb（野球で言えば）・an an-lv（男女で言えば／恋愛で言えば）・an an-biz（スタートアップで言えば／投資で言えば／経済で言えば）・an an-rw（現実世界）
- 見出し p class="an-h" の1行で構造の一致を言い切る。本文は1〜2文。全体で100字前後を上限とする
- 例「モンスーンは季節ごとに入れ替わる先発ローテーションである」「ハンザ同盟はスタートアップの業界団体である」のように、読者が納得する意外で正確な対応を選ぶ
- 男女の比喩は関係性で例える。性別に役割を割り当てない。戦争・虐殺・差別を茶化す比喩は使わない

## 日本語の規範（ja_lint で機械検査される。指摘ゼロまで直す）

- である調で書く
- 読点は適切に使う。1文に読点が3個以上になったら文を割る。意味の切れ目でない読点は削る
- 比喩として転用した動詞・名詞を本文で使わない。落ちる・効く・回す・握る・寄せる・埋める・乗せる・吸収・本質・正体・解像度 などは検査で止まる
- 擬人化しない。覚える・理解する・気づく は検査で止まる。学習者の暗記は「暗記する」と書く
- 口語を使わない。ほぼ・かなり・とても・だいたい・ちゃんと・しっかり・ということ・となっている・する必要がある・出てくる・探す・読める は検査で止まる
- 「この章では〜を説明する」のような資料を説明するだけの文は導入以外に置かない
- 正式な用語や固有名詞が検査に当たる場合は、言い換えずに担当者への報告に書く（統括者が .ja-lint-ignore に登録する）
