極限

極限は「限りなく近づく先の値」を定める操作である。不定形は式を変形してから値を決める。r の n 乗の振る舞い・sin x / x → 1・e の定義の3つが数学Ⅲの微分の出発点になる。

第8章では数列の一般項と和を求めた。この章では n を限りなく大きくしたときに数列の値がどこへ向かうかを調べる。続いて同じ考え方を関数に広げ x を限りなく a に近づけたときの値を調べる。第5章で導関数を定義したときに使った lim⁡h→0\lim_{h\to 0} はこの章の関数の極限である。第5章では多項式だけを扱ったので極限の計算は単純であった。三角関数・指数関数・対数関数を微分するには lim⁡x→0sin⁡  xx=1\lim_{x\to 0}\frac{\sin\;x}{x}=1 と e の定義が必要になる。この章はその2つを導くことを目標にする。

数学Ⅲは大学入学共通テストの出題範囲に含まれない。理系の個別試験と経済学部の数理系科目で使う。数列の極限と無限等比級数は数学Ⅲの最初の単元で第8章の公式をそのまま使う。

数列の極限 収束と発散

数列 {an}\{a_n\} で n を限りなく大きくすると ana_n が一定の値 α に限りなく近づくとき数列は α に収束すると言う。α を極限値と呼び次のように書く。

lim⁡n→∞an=αまたはan→α (n→∞)\lim_{n\to\infty}a_n=\alpha \qquad \text{または}\qquad a_n\to\alpha\ (n\to\infty)

収束しない数列は発散すると言う。発散は3通りに分かれる。

振る舞い例書き方
収束1n\frac{1}{n} は 1・0.5・0.33・… と 0 に近づくlim⁡1n=0\lim\frac{1}{n}=0
正の無限大に発散n2n^2 は限りなく大きくなるlim⁡  n2=∞\lim\;n^2=\infty
負の無限大に発散−2n-2n は負で絶対値が限りなく大きくなるlim⁡(−2n)=−∞\lim(-2n)=-\infty
振動(−1)n(-1)^n は −1 と 1 を交互にとる極限はない

∞ は数ではなく「限りなく大きくなる」状態を表す記号である。したがって ∞−∞\infty-\infty や ∞∞\frac{\infty}{\infty} を 0 や 1 と計算することはできない。このような形を不定形と呼ぶ。

極限の性質と不定形の解消

lim⁡  an=α\lim\;a_n=\alpha と lim⁡  bn=β\lim\;b_n=\beta がともに収束するとき和・差・定数倍・積・商の極限はそれぞれ α+β\alpha+\beta ・ α−β\alpha-\beta ・ kαk\alpha ・ αβ\alpha\beta ・ αβ\frac{\alpha}{\beta}（β≠0）になる。不定形の場合はこの性質をそのまま使えないので先に式を変形する。

例題 1

lim⁡n→∞3n2+nn2−2\lim_{n\to\infty}\frac{3n^2+n}{n^2-2} を求めよ。

解き方
分母と分子は ∞ に発散するので ∞∞\frac{\infty}{\infty} の不定形である。
分母の最高次の n2n^2 で分母と分子を割る。3+1n1−2n2\frac{3+\frac{1}{n}}{1-\frac{2}{n^2}}
1n→0\frac{1}{n}\to 0 ・ 2n2→0\frac{2}{n^2}\to 0 なので極限は 31\frac{3}{1}
答え 3
例題 2

lim⁡n→∞(n2+n−n)\lim_{n\to\infty}\left(\sqrt{n^2+n}-n\right) を求めよ。

解き方
∞−∞\infty-\infty の不定形である。分子の有理化を行う。
(n2+n−n)(n2+n+n)n2+n+n=nn2+n+n\frac{(\sqrt{n^2+n}-n)(\sqrt{n^2+n}+n)}{\sqrt{n^2+n}+n}=\frac{n}{\sqrt{n^2+n}+n}
分母と分子を n で割る。11+1n+1→11+1\frac{1}{\sqrt{1+\frac{1}{n}}+1}\to\frac{1}{1+1}
答え 12\frac{1}{2}

典型的な誤りは例題2を「どちらも ∞ なので差は 0」とすることである。n＝100 で計算すると 10100−100=0.498⋯\sqrt{10100}-100=0.498\cdots で 0 ではない。

はさみうちの原理

すべての n で an≤cn≤bna_n\le c_n\le b_n が成り立ち lim⁡  an=lim⁡  bn=α\lim\;a_n=\lim\;b_n=\alpha ならば lim⁡  cn=α\lim\;c_n=\alpha である。これをはさみうちの原理と呼ぶ。cnc_n を直接計算できないとき両側から収束する数列で挟む。たとえば −1≤  sin⁡  n≤1-1\le\;\sin\;n\le 1 から −1n≤sin⁡  nn≤1n-\frac{1}{n}\le\frac{\sin\;n}{n}\le\frac{1}{n} で両端が 0 に収束するので lim⁡sin⁡  nn=0\lim\frac{\sin\;n}{n}=0 である。

投資で言えば

∞−∞ は売上と費用がともに膨らむ事業の利益である

売上と費用がどちらも限りなく増えても利益は0とは限らない。差は両者の増え方の比較で定まる。

rⁿ の極限

等比数列 {rn}\{r^n\} の極限は r の値で4通りに分かれる。数学Ⅲの数列の極限の多くはこの結果に帰着する。

r の範囲lim⁡  rn\lim\;r^n
r>1r>1∞\infty に発散
r=1r=11 に収束
−1<r<1-1<r<10 に収束
r≤−1r\le -1振動して極限はない

r>1r>1 の場合の理由を示す。r=1+hr=1+h（h＞0）とおくと二項定理から (1+h)n≥1+nh(1+h)^n\ge 1+nh である。右辺は n とともに ∞ に発散するので rn→∞r^n\to\infty である。0<r<10<r<1 の場合は 1r>1\frac{1}{r}>1 なので (1r)n→∞\left(\frac{1}{r}\right)^n\to\infty となりその逆数の rnr^n は 0 に収束する。−1<r<0-1<r<0 の場合は ∣rn∣=∣r∣n→0|r^n|=|r|^n\to 0 から 0 に収束する。

lim⁡n→∞3n−2n3n+2n\lim_{n\to\infty}\frac{3^n-2^n}{3^n+2^n} を求めよ。

解き方
底の最も大きい 3n3^n で分母と分子を割る。
1−(23)n1+(23)n\frac{1-\left(\frac{2}{3}\right)^n}{1+\left(\frac{2}{3}\right)^n} で (23)n→0\left(\frac{2}{3}\right)^n\to 0
答え 1
例題 4

lim⁡n→∞rn1+rn\lim_{n\to\infty}\frac{r^n}{1+r^n} を r の値で場合分けして求めよ。ただし r≠−1r\neq -1 とする。

解き方
∣r∣<1|r|<1 のとき rn→0r^n\to 0 なので極限は 0
r=1r=1 のとき 12\frac{1}{2}
∣r∣>1|r|>1 のとき分母と分子を rnr^n で割り 1(1r)n+1→1\frac{1}{\left(\frac{1}{r}\right)^n+1}\to 1
答え ∣r∣<1|r|<1 で 0 ・ r=1r=1 で 12\frac{1}{2} ・ ∣r∣>1|r|>1 で 1

典型的な誤りは r=−1r=-1 を「1 と同じく収束する」とすることである。(−1)n(-1)^n は −1 と 1 を交互にとるので振動する。もう1つは場合分けで r=1r=1 を落とすことである。境界の値は不等式の範囲に含まれないので個別に計算する。

野球で言えば

打率3割の打者の n 打席連続安打の確率は 0.3n で 0 に近づく

各打席を独立とみなすと 10打席連続で約 0.0006％ になる。公比が1未満の等比数列の典型である。

無限級数と無限等比級数

数列 {an}\{a_n\} の項を限りなく足した式 a1+a2+a3+⋯a_1+a_2+a_3+\cdots を無限級数と呼び ∑n=1∞an\sum_{n=1}^{\infty}a_n と書く。無限個の足し算は直接は実行できない。そこで第 n 項までの部分和 Sn=∑k=1nakS_n=\sum_{k=1}^{n}a_k をつくり {Sn}\{S_n\} の極限で和を定める。lim⁡  Sn=S\lim\;S_n=S なら級数は S に収束し S を級数の和と呼ぶ。

無限等比級数の収束条件

初項 a ・公比 r の無限等比級数 a+ar+ar2+⋯a+ar+ar^2+\cdots を考える。a＝0 なら和は 0 である。a≠0 で r≠1r\neq 1 なら第8章の公式から部分和は Sn=a(1−rn)1−rS_n=\frac{a(1-r^n)}{1-r} である。−1<r<1-1<r<1 なら rn→0r^n\to 0 で Sn→a1−rS_n\to\frac{a}{1-r} となる。r≥1r\ge 1 または r≤−1r\le -1 なら SnS_n は発散する。r＝1 なら Sn=naS_n=na で発散する。

無限等比級数 a＝0 または −1<r<1-1<r<1 のとき収束する。
−1<r<1-1<r<1 のとき和は a1−r\frac{a}{1-r} である。
例題 5

循環小数 0.2˙7˙=0.272727⋯0.\dot{2}\dot{7}=0.272727\cdots を分数で表せ。

解き方
0.27+0.0027+0.000027+⋯0.27+0.0027+0.000027+\cdots は初項 0.27 ・公比 0.01 の無限等比級数
∣0.01∣<1|0.01|<1 なので収束し和は 0.271−0.01=2799\frac{0.27}{1-0.01}=\frac{27}{99}
答え 311\frac{3}{11}

同じ計算で 0.999⋯=0.91−0.1=10.999\cdots=\frac{0.9}{1-0.1}=1 である。0.999… は 1 より小さい数ではなく 1 そのものを表す。

例題 6

無限等比級数 1+(x−2)+(x−2)2+⋯1+(x-2)+(x-2)^2+\cdots が収束する x の範囲と和を求めよ。

解き方
初項は 1 で 0 ではないので公比の条件だけを調べる。
公比 x−2x-2 について −1<x−2<1-1<x-2<1 で 1<x<31<x<3
和は 11−(x−2)=13−x\frac{1}{1-(x-2)}=\frac{1}{3-x}
答え 1<x<31<x<3 ・ 和 13−x\frac{1}{3-x}

無限級数は等比型に限らない。第8章の部分分数分解を使うと部分和が求まる級数がある。

例題 7

∑n=1∞1n(n+2)\sum_{n=1}^{\infty}\frac{1}{n(n+2)} の和を求めよ。

解き方
1n(n+2)=12(1n−1n+2)\frac{1}{n(n+2)}=\frac{1}{2}\left(\frac{1}{n}-\frac{1}{n+2}\right)
部分和は1つおきに打ち消し合い Sn=12(1+12−1n+1−1n+2)S_n=\frac{1}{2}\left(1+\frac{1}{2}-\frac{1}{n+1}-\frac{1}{n+2}\right)
n → ∞ で 12⋅32\frac{1}{2}\cdot\frac{3}{2}
答え 34\frac{3}{4}

部分和を作らずに無限個の項を並べて消すのは誤りである。必ず有限の部分和を式にしてから極限をとる。

収束の必要条件

∑an\sum a_n が収束するなら an=Sn−Sn−1→S−S=0a_n=S_n-S_{n-1}\to S-S=0 である。対偶をとると ana_n が 0 に収束しない級数は発散する。逆は成り立たない。調和級数 1+12+13+⋯1+\frac{1}{2}+\frac{1}{3}+\cdots は項が 0 に近づくが発散する。13+14>12\frac{1}{3}+\frac{1}{4}>\frac{1}{2} ・ 15+⋯+18>12\frac{1}{5}+\dots+\frac{1}{8}>\frac{1}{2} と区切ると 12\frac{1}{2} より大きい塊が限りなく続くからである。

典型的な誤りは収束条件を −1≤r≤1-1\le r\le 1 と端を含めることである。r＝1 では和が na で r＝−1 では部分和が振動する。もう1つは初項に文字を含むとき a＝0 の場合を落とすことである。

経済で言えば

政府支出の乗数効果は無限等比級数である

限界消費性向 c なら支出1が 1＋c＋c²＋… の所得を生む。c＝0.8 なら和は 1÷(1−0.8)＝5 倍である。

関数の極限と片側極限

準備 分数関数・無理関数・合成関数・逆関数

学習指導要領は数学Ⅲの極限の単元で関数の極限の前に4種の関数を扱う。極限と微分の計算に必要な範囲を確認する。

分数関数 y=kx−p+qy=\frac{k}{x-p}+q（k≠0）のグラフは y=kxy=\frac{k}{x} を x 軸方向に p ・ y 軸方向に q だけ平行移動した双曲線である。直線 x＝p と y＝q が漸近線になる。x → p で値は ±∞ に発散し x → ±∞ で値は q に近づく。漸近線は極限で定まる直線である。

無理関数 y=ax+by=\sqrt{ax+b} の定義域は根号の中が0以上の範囲である。グラフは放物線 x=y2−bax=\frac{y^2-b}{a} の y≥0y\ge 0 の部分になる。

関数 f(x)f(x) の値を関数 gg に入れた g(f(x))g(f(x)) を合成関数と呼び (g∘f)(x)(g\circ f)(x) と書く。一般に g∘fg\circ f と f∘gf\circ g は一致しない。f(x)=x+1f(x)=x+1 ・ g(x)=x2g(x)=x^2 なら g(f(x))=(x+1)2g(f(x))=(x+1)^2 で f(g(x))=x2+1f(g(x))=x^2+1 である。

y=f(x)y=f(x) で x と y が1対1に対応するとき x について解いて x と y を入れ替えた関数を逆関数と呼び f−1(x)f^{-1}(x) と書く。逆関数のグラフはもとのグラフと直線 y＝x に関して対称である。y=exy=e^x の逆関数は y=log⁡  xy=\log\;x である。第10章では合成関数と逆関数を微分する。

例題 8

f(x)=2x+1x−1f(x)=\frac{2x+1}{x-1} の漸近線と逆関数を求めよ。

解き方
2x+1x−1=2(x−1)+3x−1=3x−1+2\frac{2x+1}{x-1}=\frac{2(x-1)+3}{x-1}=\frac{3}{x-1}+2
漸近線は x＝1 と y＝2
y=2x+1x−1y=\frac{2x+1}{x-1} を x について解く。y(x−1)=2x+1y(x-1)=2x+1 から x(y−2)=y+1x(y-2)=y+1 で x=y+1y−2x=\frac{y+1}{y-2}
x と y を入れ替えて答え f−1(x)=x+1x−2f^{-1}(x)=\frac{x+1}{x-2}
逆関数の漸近線は x＝2 と y＝1 でもとの漸近線を入れ替えた直線になる。

関数 f(x)f(x) で x が a と異なる値をとりながら a に限りなく近づくとき f(x)f(x) が一定の値 α に限りなく近づくなら次のように書く。

lim⁡x→af(x)=α\lim_{x\to a}f(x)=\alpha

ここで x は a に一致しない。したがって f(a)f(a) が定義されていなくても極限は存在しうる。導関数の定義 lim⁡h→0f(x+h)−f(x)h\lim_{h\to 0}\frac{f(x+h)-f(x)}{h} では h＝0 を代入できないがこの極限は存在する。多項式や分母が0にならない分数式は x＝a を代入した値が極限値になる。

例題 9

lim⁡x→1x2+ax+bx−1=3\lim_{x\to 1}\frac{x^2+ax+b}{x-1}=3 となる定数 a ・ b を求めよ。

解き方
分母は 0 に近づく。極限が有限の値をもつには分子も 0 に近づく必要がある。
分子に x＝1 を代入して 1+a+b=01+a+b=0 で b=−1−ab=-1-a
分子は x2+ax−1−a=(x−1)(x+1+a)x^2+ax-1-a=(x-1)(x+1+a) と因数分解できる
約分して lim⁡x→1(x+1+a)=2+a=3\lim_{x\to 1}(x+1+a)=2+a=3
答え a=1a=1 ・ b=−2b=-2

例題9の「分母 → 0 なら分子 → 0」は極限が有限であるための必要条件である。これで得た条件を使って実際に極限値を計算し与えられた値と一致するか確かめる。

x → ∞ と x → −∞

x を限りなく大きくする場合も数列と同じ方法で計算する。x → −∞ では x=−tx=-t とおき t → ∞ に直すと符号の誤りを防げる。

例題 10

lim⁡x→−∞(x2+2x+x)\lim_{x\to-\infty}\left(\sqrt{x^2+2x}+x\right) を求めよ。

解き方
x=−tx=-t とおくと t → ∞ で式は t2−2t−t\sqrt{t^2-2t}-t
有理化して −2tt2−2t+t=−21−2t+1→−22\frac{-2t}{\sqrt{t^2-2t}+t}=\frac{-2}{\sqrt{1-\frac{2}{t}}+1}\to\frac{-2}{2}
答え −1

典型的な誤りは x のまま x2=x\sqrt{x^2}=x と変形することである。x＜0 では x2=∣x∣=−x\sqrt{x^2}=|x|=-x である。この誤りをすると分母が 0 に近づき極限値 −1 が得られない。

片側極限

x が a より大きい側から a に近づくときの極限を右側極限と呼び lim⁡x→a+0f(x)\lim_{x\to a+0}f(x) と書く。小さい側からの極限を左側極限と呼び lim⁡x→a−0f(x)\lim_{x\to a-0}f(x) と書く。a＝0 のときは x→+0x\to +0 ・ x→−0x\to -0 と書く。lim⁡x→af(x)\lim_{x\to a}f(x) が存在するのは右側極限と左側極限が存在して一致するときだけである。

例として f(x)=∣x∣xf(x)=\frac{|x|}{x} を考える。x＞0 なら値は 1 で x＜0 なら値は −1 である。右側極限は 1 ・左側極限は −1 で一致しないので lim⁡x→0∣x∣x\lim_{x\to 0}\frac{|x|}{x} は存在しない。1x\frac{1}{x} では lim⁡x→+01x=∞\lim_{x\to+0}\frac{1}{x}=\infty ・ lim⁡x→−01x=−∞\lim_{x\to-0}\frac{1}{x}=-\infty である。

恋愛で言えば

極限は2人の言い分が一致したときだけ確定する

右から近づいた値と左から近づいた値が同じなら極限が存在する。食い違えば極限はない。

三角関数の極限 sin x / x → 1

三角関数を微分するには次の極限が必要になる。x の単位は弧度法のラジアンである。

lim⁡x→0sin⁡  xx=1\lim_{x\to 0}\frac{\sin\;x}{x}=1

x＝0 を代入すると 00\frac{0}{0} の不定形になる。そこで単位円の面積の比較から導く。0<x<π20<x<\frac{\pi}{2} とし原点 O ・ A(1, 0) ・単位円上で角 x の点 B ・ A での接線と OB の延長との交点 T をとる。

面積の大小 12  sin⁡  x<12x<12  tan⁡  x\frac{1}{2}\;\sin\;x<\frac{1}{2}x<\frac{1}{2}\;\tan\;x を2倍し各辺を正の数 sin⁡  x\sin\;x で割って逆数をとると次の式になる。

1<xsin⁡  x<1cos⁡  x⟹cos⁡  x<sin⁡  xx<11<\frac{x}{\sin\;x}<\frac{1}{\cos\;x}\quad\Longrightarrow\quad \cos\;x<\frac{\sin\;x}{x}<1

x→+0x\to+0 で cos⁡  x→1\cos\;x\to 1 なのではさみうちの原理から sin⁡  xx→1\frac{\sin\;x}{x}\to 1 である。x＜0 の場合は sin⁡(−x)−x=sin⁡  xx\frac{\sin(-x)}{-x}=\frac{\sin\;x}{x} なので同じ値になる。左右の片側極限が一致するので極限は 1 である。

例題 11

(1) lim⁡x→0sin⁡  3xx\lim_{x\to 0}\frac{\sin\;3x}{x} ・ (2) lim⁡x→01−cos⁡  xx2\lim_{x\to 0}\frac{1-\cos\;x}{x^2} を求めよ。

解き方
(1) sin⁡  3xx=3⋅sin⁡  3x3x\frac{\sin\;3x}{x}=3\cdot\frac{\sin\;3x}{3x} で 3x=θ3x=\theta とおくと θ → 0
答え 3
(2) 分母と分子に 1+cos⁡  x1+\cos\;x を掛ける。1−cos⁡2  xx2(1+cos⁡  x)=(sin⁡  xx)2⋅11+cos⁡  x\frac{1-\cos^2\;x}{x^2(1+\cos\;x)}=\left(\frac{\sin\;x}{x}\right)^2\cdot\frac{1}{1+\cos\;x}
→12⋅12\to 1^2\cdot\frac{1}{2}
答え 12\frac{1}{2}

典型的な誤りは sin⁡  3xx\frac{\sin\;3x}{x} を 1 とすることである。公式は sin の中と分母が同じ式のときに使う。もう1つは度数法で考えることである。x を度で測ると極限は π180\frac{\pi}{180} になり 1 にならない。

e の定義

次の数列を考える。n＝1 で 2 ・ n＝2 で 2.25 ・ n＝5 で約 2.488 と増えていく。

an=(1+1n)na_n=\left(1+\frac{1}{n}\right)^n

この数列は単調に増加しかつ 3 を超えないことが示せる。上に有界な単調増加数列は収束するという実数の性質により極限が存在する。この極限を e と定める。e は無理数で e=2.71828⋯e=2.71828\cdots である。

e=lim⁡n→∞(1+1n)n=lim⁡h→0(1+h)1he=\lim_{n\to\infty}\left(1+\frac{1}{n}\right)^n=\lim_{h\to 0}(1+h)^{\frac{1}{h}}

右の形は h=1nh=\frac{1}{n} とおきかえて n を実数に広げたものである。h → −0 の場合も同じ値 e に収束する。第10章で対数関数を微分するときはこの右の形を使う。e を底とする対数 log⁡e  x\log_e\;x を自然対数と呼び数学Ⅲでは底を省いて log⁡  x\log\;x と書く。

例題 12

(1) lim⁡n→∞(1+2n)n\lim_{n\to\infty}\left(1+\frac{2}{n}\right)^n ・ (2) lim⁡n→∞(1−1n)n\lim_{n\to\infty}\left(1-\frac{1}{n}\right)^n を求めよ。

解き方
(1) 2n=h\frac{2}{n}=h とおくと n → ∞ で h → +0 ・ n=2hn=\frac{2}{h}
{(1+h)1h}2→e2\left\{(1+h)^{\frac{1}{h}}\right\}^2\to e^2
答え e2e^2
(2) −1n=h-\frac{1}{n}=h とおくと h → −0 ・ n=−1hn=-\frac{1}{h}
{(1+h)1h}−1→e−1\left\{(1+h)^{\frac{1}{h}}\right\}^{-1}\to e^{-1}
答え 1e\frac{1}{e}

典型的な誤りは「1+1n→11+\frac{1}{n}\to 1 なので 1n=11^n=1」とすることである。底が 1 に近づき指数が ∞ に発散する 1∞1^\infty 型も不定形である。

関数の連続性と中間値の定理

関数 f(x)f(x) が x＝a で連続であるとは次の3条件がそろうことである。

連続の条件 f(a)f(a) が定義されている。
lim⁡x→af(x)\lim_{x\to a}f(x) が存在する。
両者が等しい。lim⁡x→af(x)=f(a)\lim_{x\to a}f(x)=f(a)

区間のすべての点で連続な関数をその区間で連続な関数と呼ぶ。多項式・分数関数・三角関数・指数関数・対数関数は定義域で連続である。連続な関数の和・差・積・商（分母≠0）も連続である。グラフで言えば連続とは途切れずにつながっていることを表す。

不連続の例はガウス記号 [x][x]（x を超えない最大の整数）である。x＝1 では [1]=1[1]=1 で右側極限は 1 ・左側極限は 0 なので極限が存在せず不連続である。

中間値の定理

学習指導要領解説は関数の連続性を扱うと定めるが中間値の定理の名称は挙げていない。この章では補足として扱う。関数 f(x)f(x) が閉区間 [a,b][a,b] で連続で f(a)≠f(b)f(a)\neq f(b) とする。f(a)f(a) と f(b)f(b) の間の任意の値 k について f(c)=kf(c)=k を満たす c が a<c<ba<c<b に少なくとも1つ存在する。これを中間値の定理と呼ぶ。とくに f(a)f(a) と f(b)f(b) が異符号なら方程式 f(x)=0f(x)=0 は a<x<ba<x<b に少なくとも1つの実数解をもつ。

例題 13

方程式 cos⁡  x=x\cos\;x=x は 0<x<π20<x<\frac{\pi}{2} に少なくとも1つの実数解をもつことを示せ。

解き方
g(x)=x−cos⁡  xg(x)=x-\cos\;x とおく。g は連続関数の差なので [0,π2]\left[0,\frac{\pi}{2}\right] で連続である。
g(0)=−1<0g(0)=-1<0 ・ g(π2)=π2>0g\left(\frac{\pi}{2}\right)=\frac{\pi}{2}>0
中間値の定理より g(c)=0g(c)=0 となる c が 0<c<π20<c<\frac{\pi}{2} に存在する。

典型的な誤りは2つある。中間値の定理は解の存在を示すが解の個数は示さない。解がただ1つであることを言うには第11章の増減を使う。また区間で連続であることを確かめずに定理を使うのも誤りである。右の図のように不連続なら値を飛び越えうる。

現実世界の極限 連続複利

e は利息の計算から見つかった数である。年利100％で1年預けると元本1は2になる。半年ごとに50％ずつ複利で付けると 1.52=2.251.5^2=2.25 になる。年 n 回に分けて複利で付けると (1+1n)n\left(1+\frac{1}{n}\right)^n になる。

利息を付ける回数1年後の元利合計
年1回2
半年ごと 年2回2.25
四半期ごと 年4回2.4414
毎月 年12回2.6130
毎日 年365回2.7146
限りなく細かくe＝2.71828…

回数を増やしても元利合計は限りなく増えるのではなく e で頭打ちになる。年利 r で連続的に複利を付けると t 年後の元利合計は erte^{rt} 倍になる。金融工学の割引計算はこの連続複利で書くことが多い。

現実世界

この問題を1683年に研究したのはヤコブ・ベルヌーイで極限が 2 と 3 の間にあることを示した。文字 e を使ったのはオイラーで1731年のゴールドバッハ宛の書簡に記録がある。

確認問題

問1 ・ 分数式の極限

lim⁡n→∞2n2−3n5n2+1\lim_{n\to\infty}\frac{2n^2-3n}{5n^2+1} の値として正しいものを1つ選べ。

  1. 0
  2. 25\frac{2}{5}
  3. −3-3
  4. ∞
解答と解説
正解は 2 である。分母と分子を n2n^2 で割ると 2−3n5+1n2→25\frac{2-\frac{3}{n}}{5+\frac{1}{n^2}}\to\frac{2}{5}。
問2 ・ ∞−∞ の不定形

lim⁡n→∞(n2+4n−n)\lim_{n\to\infty}\left(\sqrt{n^2+4n}-n\right) の値を求めよ。

解答と解説
答えは 2 である。有理化して 4nn2+4n+n=41+4n+1→42=2\frac{4n}{\sqrt{n^2+4n}+n}=\frac{4}{\sqrt{1+\frac{4}{n}}+1}\to\frac{4}{2}=2。
問3 ・ rⁿ の極限

lim⁡n→∞2n+1+3n3n+1−2n\lim_{n\to\infty}\frac{2^{n+1}+3^n}{3^{n+1}-2^n} の値として正しいものを1つ選べ。

  1. 13\frac{1}{3}
  2. 23\frac{2}{3}
  3. 1
  4. 3
解答と解説
正解は 1 である。分母と分子を 3n3^n で割ると 2(23)n+13−(23)n→13\frac{2\left(\frac{2}{3}\right)^n+1}{3-\left(\frac{2}{3}\right)^n}\to\frac{1}{3}。
問4 ・ 無限等比級数の収束条件

無限級数 x+x(1−x)+x(1−x)2+⋯x+x(1-x)+x(1-x)^2+\cdots が収束する x の範囲として正しいものを1つ選べ。

  1. 0<x<20<x<2
  2. 0≤x<20\le x<2
  3. 0≤x≤20\le x\le 2
  4. −1<x<1-1<x<1
解答と解説
正解は 2 である。初項 x ・公比 1−x1-x である。x＝0 なら全項 0 で収束する。x≠0 なら −1<1−x<1-1<1-x<1 から 0<x<20<x<2。合わせて 0≤x<20\le x<2。1 は x＝0 の場合を落としている。
問5 ・ 循環小数

循環小数 0.36˙=0.3666⋯0.3\dot{6}=0.3666\cdots を既約分数で表せ。

解答と解説
答えは 1130\frac{11}{30} である。0.3+(0.06+0.006+⋯ )=310+0.061−0.1=310+115=11300.3+(0.06+0.006+\cdots)=\frac{3}{10}+\frac{0.06}{1-0.1}=\frac{3}{10}+\frac{1}{15}=\frac{11}{30}。
問6 ・ 三角関数の極限

lim⁡x→0sin⁡  5xsin⁡  2x\lim_{x\to 0}\frac{\sin\;5x}{\sin\;2x} の値を求めよ。

解答と解説
答えは 52\frac{5}{2} である。sin⁡  5x5x⋅2xsin⁡  2x⋅52→1⋅1⋅52\frac{\sin\;5x}{5x}\cdot\frac{2x}{\sin\;2x}\cdot\frac{5}{2}\to 1\cdot 1\cdot\frac{5}{2}。
問7 ・ 極限値から係数を決める

lim⁡x→1x2+ax+bx−1=5\lim_{x\to 1}\frac{x^2+ax+b}{x-1}=5 となる定数 a ・ b の組として正しいものを1つ選べ。

  1. a＝3 ・ b＝−4
  2. a＝4 ・ b＝−5
  3. a＝−3 ・ b＝2
  4. a＝5 ・ b＝−6
解答と解説
正解は 1 である。分子 → 0 から b=−1−ab=-1-a。分子は (x−1)(x+1+a)(x-1)(x+1+a) で極限は 2+a=52+a=5 から a＝3 ・ b＝−4。検算 x2+3x−4x−1=x+4→5\frac{x^2+3x-4}{x-1}=x+4\to 5。
問8 ・ 連続性と中間値の定理

次の記述のうち正しいものを1つ選べ。

  1. f(1)<0f(1)<0 ・ f(2)>0f(2)>0 ならどんな関数でも 1<x<21<x<2 に f(x)=0f(x)=0 の解がある
  2. [1,2][1,2] で連続で f(1)<0f(1)<0 ・ f(2)>0f(2)>0 なら 1<x<21<x<2 に f(x)=0f(x)=0 の解がちょうど1つある
  3. [1,2][1,2] で連続で f(1)<0f(1)<0 ・ f(2)>0f(2)>0 なら 1<x<21<x<2 に f(x)=0f(x)=0 の解が少なくとも1つある
  4. lim⁡x→af(x)\lim_{x\to a}f(x) が存在すれば f は x＝a で連続である
解答と解説
正解は 3 である。1 は連続の仮定がない。2 は解の個数までは言えない。4 は極限値と f(a)f(a) が等しいことまで要る。たとえば f(a)f(a) だけ別の値に定めた関数は極限が存在しても不連続である。

この章の要点

要点 ∞/∞ は最高次で割り ∞−∞ は有理化する。∞ は数ではない。
lim⁡  rn\lim\;r^n は r＞1 で ∞ ・ r＝1 で 1 ・ |r|＜1 で 0 ・ r≦−1 で振動。
無限等比級数は a＝0 または |r|＜1 で収束し和は a1−r\frac{a}{1-r}。
極限が存在するのは右側極限と左側極限が一致するとき。
lim⁡x→0sin⁡  xx=1\lim_{x\to 0}\frac{\sin\;x}{x}=1 は面積の比較とはさみうちで導く。x はラジアン。
e=lim⁡(1+1n)n=lim⁡h→0(1+h)1h=2.718⋯e=\lim\left(1+\frac{1}{n}\right)^n=\lim_{h\to 0}(1+h)^{\frac{1}{h}}=2.718\cdots。
連続関数が異符号の値をとれば間に解がある。中間値の定理は存在だけを示す。

残っている問い

  • 高校では「限りなく近づく」という言葉で極限を定義する。大学ではこれを ε-δ 論法で厳密に定める。高校の定義は直感的な説明である。
  • (1+1n)n\left(1+\frac{1}{n}\right)^n が収束することの証明は「上に有界な単調数列は収束する」という実数の連続性に依存する。高校ではこの性質を証明せずに用いる。
  • sin x / x の証明で扇形の面積 ½x を使う。扇形の面積は弧の長さから導かれ弧の長さの定義には極限が含まれるので循環論法だという指摘がある。厳密には大学で三角関数を級数で定義し直す。
  • ベルヌーイの研究年は1683年とする資料が多いが刊行を1685年とする資料もあり確定できなかった。
  • 数学Ⅲの解説は関数の値の極限に関連して関数の連続性を扱うと定める。中間値の定理の名称は解説に見当たらない。教科書で本文と発展のどちらに置くかは確認できなかった。
