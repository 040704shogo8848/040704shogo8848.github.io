どの分野も公式に数値を代入する前に 何を数えて何で割るかを1行で書く。確率は分数のまま約分して最後に小数に直す。

1. 四分位数は中央値で前半と後半に分けてから求める
平均値は合計を個数で割った値である。中央値は小さい順に並べた中央の値で 個数が偶数なら中央の2つの平均をとる。四分位数は共通テストの方式で求める。個数が奇数なら中央値を除いて前半と後半に分け 前半の中央値を第1四分位数 後半の中央値を第3四分位数とする。分散は偏差の2乗の平均で 標準偏差は分散の正の平方根である。
データ 2, 3, 5, 6, 8, 9, 12　個数 7
→ 中央値は4番目の 6
→ 6 を除いた前半 2, 3, 5 の中央値 3 が第1四分位数
→ 後半 8, 9, 12 の中央値 9 が第3四分位数
→ 四分位範囲 = 9 − 3 = 6
データ 2, 4, 6, 8, 10
→ 平均値 6　偏差 −4, −2, 0, 2, 4
→ 偏差の2乗の和 = 16 + 4 + 0 + 4 + 16 = 40
→ 分散 = 40/5 = 8　標準偏差 = √8 ≒ 2.83
第2章 代表値と散らばりを開く
2. 相関係数は偏差の積の和を2乗和の平方根で割る
相関係数 r は共分散を x と y の標準偏差の積で割った値である。共分散も標準偏差も個数 n で割って求めるので n は分子と分母で約分される。偏差の積の和 ÷ √(x の偏差の2乗の和 × y の偏差の2乗の和) で計算すると割り算は1回で済む。r は −1 以上 1 以下になる。
x 1, 2, 3, 4, 5　y 2, 4, 5, 4, 5
→ 平均値 x 3　y 4
→ x の偏差 −2, −1, 0, 1, 2　y の偏差 −2, 0, 1, 0, 1
→ 偏差の積の和 = 4 + 0 + 0 + 0 + 2 = 6
→ 2乗の和 x 10　y 6
→ r = 6 ÷ √(10 × 6) = 6 ÷ √60 ≒ 0.775
第3章 相関係数を開く
3. 並べるなら P で 選ぶだけなら C
異なる n 個から r 個を並べるnPr = n × (n−1) × … を r 個
異なる n 個から r 個を選ぶnCr = nPr ÷ r!
n 人が円形に並ぶ(n−1)!　1人を固定する
同じものを含む n 個を並べるn! ÷ (p! q! r!)
n 種類から重複を許して r 個を並べるnr
男子 5 人と女子 4 人から男子 2 人と女子 2 人を選ぶ
→ 男子の選び方 5C2 = 10　女子の選び方 4C2 = 6
→ 積の法則で 10 × 6 = 60 通り
第4章 順列を開く　第5章 組合せを開く
4. 少なくとも の確率は余事象から計算する
1回の確率が p の試行を n 回くり返して ちょうど r 回起こる確率は nCr pr (1 − p)n−r である。少なくとも1回 の確率は 1 から 1回も起こらない確率を引く。独立な2つの事象が両方起こる確率は確率の積になる。
さいころを 4 回投げて 1 の目がちょうど 2 回出る確率
→ 4C2 × (1/6)2 × (5/6)2 = 6 × 1/36 × 25/36
→ = 150/1296 = 25/216
さいころを 3 回投げて少なくとも1回 6 の目が出る確率
→ 1 − (5/6)3 = 1 − 125/216 = 91/216
第6章 確率を開く
5. 条件付き確率は人数に直して数える
PA(B) = P(A ∩ B) ÷ P(A) である。検査の問題は 10000 人の集団を仮定して人数で数えると分母と分子の取り違えを防げる。期待値は 値 × その値をとる確率 の和である。
感染率 1%　感染者が陽性になる確率 90%　非感染者が陽性になる確率 5%
→ 10000 人のうち感染者 100 人で陽性は 90 人
→ 非感染者 9900 人で陽性は 495 人
→ 陽性の人が感染者である確率 = 90 ÷ (90 + 495) = 90/585 = 2/13 ≒ 0.154
第7章 条件付き確率と期待値を開く
6. 二項分布は np と np(1 − p) で済む
X が二項分布 B(n, p) に従うとき E(X) = np で V(X) = np(1 − p) である。Y = aX + b に対して E(Y) = aE(X) + b　V(Y) = a2V(X)　σ(Y) = |a|σ(X) が成り立つ。b は散らばりを変えない。
X は B(72, 1/3) に従う　Y = 3X − 5
→ E(X) = 72 × 1/3 = 24　V(X) = 72 × 1/3 × 2/3 = 16
→ E(Y) = 3 × 24 − 5 = 67
→ V(Y) = 32 × 16 = 144　σ(Y) = 12
第8章 確率変数と二項分布を開く
7. 正規分布は Z = (X − m)/σ で標準化して表を引く
X が N(m, σ2) に従うとき Z = (X − m)/σ は N(0, 1) に従う。表の p(z) は 0 ≤ Z ≤ z の確率である。Z ≥ 0 の確率は 0.5 で 分布は 0 について対称なので P(Z ≤ −z) = P(Z ≥ z) になる。
X は N(50, 102) に従う　P(X ≥ 65)
→ Z = (65 − 50)/10 = 1.50
→ P(Z ≥ 1.50) = 0.5 − p(1.50) = 0.5 − 0.4332 = 0.0668
第9章 正規分布を開く
8. 95% 信頼区間は 標本の値 ± 1.96 × 標準偏差
母平均 m の信頼度 95% の信頼区間は X − 1.96σ/√n ≤ m ≤ X + 1.96σ/√n である。母比率は標本比率 R を用いて R ± 1.96√(R(1 − R)/n) で求める。1.96 は p(z) = 0.4750 となる z の値である。
大きさ 100 の標本の平均値 52.0　母標準偏差 10
→ 1.96 × 10/√100 = 1.96 × 1 = 1.96
→ 52.0 − 1.96 = 50.04　52.0 + 1.96 = 53.96
→ 50.04 ≤ m ≤ 53.96
