どの分野も成分を書き出してから計算する。x 成分と y 成分を別々の式に分ければ符号の誤りは途中で見つけられる。大きさと角は最後に根号と三角比の表で値に直す。

1. ベクトルの成分は x と y を別々に計算する
和と実数倍は成分ごとに計算する。大きさは三平方の定理で |a| = √(a12 + a22) である。平行の条件は a = tb となる実数 t があることである。
a = (2, −1)　b = (1, 3) のとき |2a − b|
→ 2a − b = (4 − 1, −2 − 3) = (3, −5)
→ 32 + (−5)2 = 34
→ √34
第1章 平面ベクトルを開く
2. 内積は成分の積の和と |a||b|cos θ の2通りで書ける
a·b = a1b1 + a2b2 = |a||b|cos θ である。2つの式を等しくおけば cos θ が求まる。cos θ = 0 なら垂直である。角 θ は 0° ≦ θ ≦ 180° の範囲で答える。
a = (1, 2)　b = (−1, 3) のなす角
→ a·b = 1×(−1) + 2×3 = 5
→ |a| = √5　|b| = √10
→ cos θ = 5 / (√5 × √10) = 5 / (5√2) = 1/√2
→ θ = 45°
第2章 内積を開く
3. 内分点は相手側の比を掛ける
AB を m : n に内分する点は (na + mb) / (m + n) である。A に掛かる数は B 側の比 n である。外分は n を −n に置き換える。三角形の面積は2辺のベクトル (x1, y1) と (x2, y2) から S = |x1y2 − x2y1| / 2 で求める。
A(1, 2)　B(7, −4) を 1 : 2 に内分する点 P
→ x = (2×1 + 1×7) / 3 = 3
→ y = (2×2 + 1×(−4)) / 3 = 0
→ P(3, 0)
第3章 ベクトルと図形を開く
4. 空間ベクトルは z 成分が1つ増えるだけ
内積は a1b1 + a2b2 + a3b3 で大きさは √(a12 + a22 + a32) である。なす角の求め方は平面と同じである。
a = (1, 1, 0)　b = (0, 1, 1) のなす角
→ a·b = 0 + 1 + 0 = 1
→ |a| = |b| = √2
→ cos θ = 1 / (√2 × √2) = 1/2
→ θ = 60°
第4章 空間ベクトルを開く
5. 複素数は極形式に直して角を足す
z = a + bi の絶対値は |z| = √(a2 + b2) である。極形式 z = r(cos θ + i sin θ) に直すと ド・モアブルの定理 zn = rn(cos nθ + i sin nθ) が使える。偏角は 0° ≦ θ < 360° で答える。
(1 + √3 i)5
→ 1 + √3 i = 2(cos 60° + i sin 60°)
→ 25(cos 300° + i sin 300°) = 32 × (1/2 − √3/2 i)
→ 16 − 16√3 i
第5章 複素数平面を開く
6. 行列の積は行と列の積の和範囲外
AB の (i, j) 成分は A の第 i 行と B の第 j 列を順に掛けて足した値である。2×2 行列 A = (a b ; c d) の逆行列は ad − bc ≠ 0 のとき A−1 = (d −b ; −c a) / (ad − bc) である。
A = 1234　B = 01−12 の AB の (2, 1) 成分
→ 第2行 (3, 4) と第1列 (0, −1)
→ 3×0 + 4×(−1) = −4
第6章 行列を開く
7. 行列式は 2×2 なら ad − bc で 3×3 ならサラスの方法範囲外
3×3 の行列式は右下がりの3本の積の和から右上がりの3本の積の和を引く。行列式が 0 の行列は逆行列をもたない。
120013201
→ 右下がり 1×1×1 + 2×3×2 + 0×0×0 = 13
→ 右上がり 0×1×2 + 2×0×1 + 1×3×0 = 0
→ 13 − 0 = 13
第7章 線形変換を開く
8. 固有値は det(A − λE) = 0 の解範囲外
2×2 行列では λ2 − (a + d)λ + (ad − bc) = 0 を解く。固有値の和は a + d で積は ad − bc に等しい。固有ベクトルは (A − λE)x = 0 を満たす 0 でないベクトルである。
A = 4123
→ λ2 − 7λ + 10 = 0
→ (λ − 2)(λ − 5) = 0
→ λ = 2, 5
