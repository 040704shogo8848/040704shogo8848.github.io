数列と数学的帰納法

数列は自然数 n を入力として値を返す関数である。等差は足し算の繰り返しで等比は掛け算の繰り返しである。和の公式も漸化式の解法も同じ数列を2通りに並べて差をとる操作から導ける。

第1章の1次関数は x が1増えるたびに y が一定量だけ増える関数であった。第2章の指数関数は x が1増えるたびに y が一定の倍率で増える関数であった。この章ではこの2つを自然数 n=1,2,3,…n=1,2,3,\dots だけで考える。それが等差数列と等比数列である。続いて和を Σ 記号で表し和の公式を導く。最後に前の項から次の項を決める漸化式と自然数すべてについての命題を証明する数学的帰納法を扱う。

共通テスト「数学Ⅱ・数学B・数学C」では数列・統計的な推測・ベクトル・平面上の曲線と複素数平面の4項目から3項目を選んで解答する。この章は一般項・和・漸化式の順に積み上げる。第9章で扱う数列の極限はこの章で求めた一般項を基に考える。

数列と等差数列

数を1列に並べたものを数列と呼ぶ。並んだ各数を項と呼び最初から順に第1項・第2項・第3項と数える。第1項を初項と呼ぶ。第 n 項を n の式で表したものを一般項と呼び ana_n と書く。項の個数が有限なら最後の項を末項と呼び項の個数を項数と呼ぶ。

一般項が分かれば任意の項を計算できる。数列は自然数 n を入力として値 ana_n を返す関数である。関数 f(x)f(x) の x を自然数に限ったものと考えてよい。

等差数列の一般項

各項に一定の数 d を足すと次の項になる数列を等差数列と呼ぶ。d を公差と呼ぶ。初項 a から第 n 項までに d を足す回数は n 回ではなく n−1n-1 回である。第1項から第2項へ1回・第3項へ2回と数えるとこの回数が確かめられる。したがって一般項は次の式になる。

an=a+(n−1)da_n=a+(n-1)d

3つの数 a・b・c がこの順に等差数列になる条件は b−a=c−bb-a=c-b である。整理すると 2b=a+c2b=a+c となる。b を等差中項と呼ぶ。

例題 1

第3項が 11 で第10項が 32 の等差数列の一般項を求めよ。

解き方
初項を a・公差を d とする。
第3項から a+2d=11a+2d=11 ・ 第10項から a+9d=32a+9d=32
辺々引くと 7d=217d=21 で d=3d=3 ・ 代入して a=5a=5
答え an=5+(n−1)⋅3=3n+2a_n=5+(n-1)\cdot 3=3n+2
検算 a3=11a_3=11 ・ a10=32a_{10}=32 で一致する。

等差数列の和

1 から 5 までの和を考える。同じ和を逆順に並べて上下に足すと各列は 1＋5＝2＋4＝3＋3＝6 でそろう。6 が5列あるので合計は 30 で求める和はその半分の 15 である。

一般の等差数列でも同じ操作が成り立つ。初項 a から末項 l までの和 SnS_n を正順と逆順に書いて足すと各組の和はどれも a+la+l になる。組は n 個あるので 2Sn=n(a+l)2S_n=n(a+l) である。

Sn=n(a+l)2=n{2a+(n−1)d}2S_n=\frac{n(a+l)}{2}=\frac{n\{2a+(n-1)d\}}{2}

右の式は l=a+(n−1)dl=a+(n-1)d を代入したものである。末項が分かれば左の式・公差が分かれば右の式を使う。

例題 2

2桁の自然数のうち 3 で割ると 1 余る数の和を求めよ。

解き方
該当する数は 10・13・16・…・97 で初項 10 ・公差 3 の等差数列である。
項数は 10+3(n−1)=9710+3(n-1)=97 から n=30n=30
和は 30(10+97)2=15×107=1605\frac{30(10+97)}{2}=15\times 107=1605
答え 1605

和の最大値

公差が負の等差数列では項が正から負へ変わる。正の項をすべて足し終えた時点で和が最大になる。和の式を n の2次関数とみて最大値を求めてもよいが n は自然数に限られるので項の符号を調べるほうが確実である。

例題 3

初項 50 ・公差 −3 の等差数列の初項から第 n 項までの和 SnS_n の最大値を求めよ。

解き方
一般項は an=50−3(n−1)=53−3na_n=50-3(n-1)=53-3n
an>0a_n>0 を解くと n<17.66⋯n<17.66\cdots で a17=2a_{17}=2 ・ a18=−1a_{18}=-1
第17項までは正で第18項から負なので S17S_{17} が最大
S17=17(50+2)2=442S_{17}=\frac{17(50+2)}{2}=442
答え n＝17 のとき最大値 442

典型的な誤りは項数の数え違いである。10 から 97 までを (97−10)÷3=29(97-10)\div 3=29 項と数えるのは誤りで両端を含めると 30 項である。植木算と同じく間の個数に1を足す。

会計で言えば

定額法の減価償却は等差数列である

毎期同じ額を引くので帳簿価額は公差が負の等差数列になる。定率法は毎期同じ割合を掛けるので等比数列になる。

等比数列とその和

各項に一定の数 r を掛けると次の項になる数列を等比数列と呼ぶ。r を公比と呼ぶ。初項 a から第 n 項までに r を掛ける回数は n−1n-1 回なので一般項は次の式になる。

an=arn−1a_n=ar^{n-1}

0 でない3つの数 a・b・c がこの順に等比数列になる条件は ba=cb\frac{b}{a}=\frac{c}{b} で整理すると b2=acb^2=ac である。b を等比中項と呼ぶ。

等比数列の和の公式の導出

和 Sn=a+ar+ar2+⋯+arn−1S_n=a+ar+ar^2+\dots+ar^{n-1} の両辺に r を掛けると rSn=ar+ar2+⋯+arnrS_n=ar+ar^2+\dots+ar^{n} となる。2つの式は右辺の大部分が一致する。上から下を引くと arar から arn−1ar^{n-1} までが消えて両端だけが残る。

Sn−rSn=a−arn⟹(1−r)Sn=a(1−rn)S_n-rS_n=a-ar^n \quad\Longrightarrow\quad (1-r)S_n=a(1-r^n)

r≠1r\neq 1 なら両辺を 1−r1-r で割れる。r=1r=1 なら全項が a なので和は nana である。

Sn=a(1−rn)1−r=a(rn−1)r−1(r≠1),Sn=na(r=1)S_n=\frac{a(1-r^n)}{1-r}=\frac{a(r^n-1)}{r-1}\quad (r\neq 1) ,\qquad S_n=na\quad (r=1)

2つの形は分母と分子の両方に −1 を掛けたもので値は等しい。r>1r>1 なら右の形を使うと符号の誤りが減る。

例題 4

初項 3 ・公比 2 の等比数列の初項から第 8 項までの和を求めよ。また和が初めて 1000 を超えるのは第何項までの和か。

解き方
S8=3(28−1)2−1=3×255=765S_8=\frac{3(2^8-1)}{2-1}=3\times 255=765
Sn=3(2n−1)>1000S_n=3(2^n-1)>1000 を解く。2n−1>333.3⋯2^n-1>333.3\cdots なので 2n>334.3⋯2^n>334.3\cdots
28=2562^8=256 ・ 29=5122^9=512 より最小の n は 9
答え 765 ・ 第9項まで

等差×等比の和

∑k=1nk⋅2k−1\sum_{k=1}^{n}k\cdot 2^{k-1} のように等差数列と等比数列の積の和も同じ操作で求まる。和を S とし公比の 2 を掛けた 2S を1項ずらして並べて引くと等比数列の和が残る。

例題 5

S=1⋅1+2⋅2+3⋅22+⋯+n⋅2n−1S=1\cdot 1+2\cdot 2+3\cdot 2^2+\dots+n\cdot 2^{n-1} を求めよ。

解き方
2S=1⋅2+2⋅22+⋯+(n−1)2n−1+n⋅2n2S=1\cdot 2+2\cdot 2^2+\dots+(n-1)2^{n-1}+n\cdot 2^n
S−2S=1+2+22+⋯+2n−1−n⋅2nS-2S=1+2+2^2+\dots+2^{n-1}-n\cdot 2^n

答え S=(n−1)2n+1S=(n-1)2^n+1
検算 n＝3 で 1+4+12=171+4+12=17 ・ 式は 2⋅8+1=172\cdot 8+1=17

引き算の右辺で最後の項 n⋅2nn\cdot 2^n の符号を誤りやすい。2S の側にだけある項は引かれて負になる。

典型的な誤りは2つある。1つは一般項の指数を n とする誤りで an=arn−1a_n=ar^{n-1} の n−1n-1 を確認する。もう1つは公比が文字のときに r=1r=1 の場合分けを忘れる誤りである。

Σ記号と和の公式

数列の和 a1+a2+⋯+ana_1+a_2+\dots+a_n を次のように書く。Σ はギリシャ文字のシグマで和を表す。下の k=1k=1 から上の n まで k を1ずつ変えて aka_k を足す意味である。

∑k=1nak=a1+a2+⋯+an\sum_{k=1}^{n}a_k=a_1+a_2+\dots+a_n

Σ には次の性質がある。足す順序の入れ替えと分配法則により和と定数倍は Σ の外に出せる。

∑k=1n(pak+qbk)=p∑k=1nak+q∑k=1nbk\sum_{k=1}^{n}(pa_k+qb_k)=p\sum_{k=1}^{n}a_k+q\sum_{k=1}^{n}b_k

一方で積は外に出せない。∑akbk\sum a_kb_k は (∑ak)(∑bk)\left(\sum a_k\right)\left(\sum b_k\right) と一般に一致しない。n＝2 で a1b1+a2b2a_1b_1+a_2b_2 と (a1+a2)(b1+b2)(a_1+a_2)(b_1+b_2) を比べると後者には a1b2+a2b1a_1b_2+a_2b_1 が余分に含まれる。

階差数列と和から一般項を求める方法

数列 {an}\{a_n\} の隣り合う項の差 bn=an+1−anb_n=a_{n+1}-a_n を並べた数列を階差数列と呼ぶ。一般項が直接分からなくても階差に規則があれば一般項を求められる。

a2=a1+b1a_2=a_1+b_1 ・ a3=a1+b1+b2a_3=a_1+b_1+b_2 と続くので第 n 項は初項に階差を n−1n-1 個足した値になる。

an=a1+∑k=1n−1bk(n≥2)a_n=a_1+\sum_{k=1}^{n-1}b_k\qquad (n\ge 2)

この式は n≥2n\ge 2 でしか使えない。n＝1 では足す個数が0個になり Σ の上端が0になるからである。得た式が n＝1 でも成り立つかを最後に確かめる。

和 Sn から一般項を求める

初項から第 n 項までの和 SnS_n が分かっているとき SnS_n と Sn−1S_{n-1} の差は第 n 項だけである。

a1=S1,an=Sn−Sn−1(n≥2)a_1=S_1,\qquad a_n=S_n-S_{n-1}\quad (n\ge 2)

ここでも n≥2n\ge 2 の制限がある。S0S_0 は定義されていないからである。

漸化式

初項と「前の項から次の項を決める規則」で数列を定める式を漸化式と呼ぶ。漸化式が与えられれば項を1つずつ順に計算できる。試験では一般項を求めることが問われる。基本の型は次の4つである。

型漸化式一般項の求め方
等差型an+1=an+da_{n+1}=a_n+d公差 d の等差数列
等比型an+1=rana_{n+1}=ra_n公比 r の等比数列
階差型an+1=an+f(n)a_{n+1}=a_n+f(n)階差が f(n)f(n) なので第4節の式
1次型an+1=pan+qa_{n+1}=pa_n+qα=pα+q\alpha=p\alpha+q の解 α を引いて等比型にする

an+1＝pan＋q 型の解き方と理由

p≠1 とする。数 α が α=pα+q\alpha=p\alpha+q を満たすとする。漸化式からこの式を辺々引くと q が消える。

an+1−α=p(an−α)a_{n+1}-\alpha=p(a_n-\alpha)

この式は数列 {an−α}\{a_n-\alpha\} が公比 p の等比数列であることを示す。したがって an−α=(a1−α)pn−1a_n-\alpha=(a_1-\alpha)p^{n-1} で一般項が求まる。α は数列の項ではない。式を等比型に変えるために用いる補助の数である。α=pα+q\alpha=p\alpha+q から α=q1−p\alpha=\frac{q}{1-p} である。

例題 10

a1=1a_1=1 ・ an+1=3an+2a_{n+1}=3a_n+2 で定まる数列の一般項を求めよ。

解き方
α=3α+2\alpha=3\alpha+2 から α=−1\alpha=-1
an+1+1=3(an+1)a_{n+1}+1=3(a_n+1) で {an+1}\{a_n+1\} は初項2 ・公比3の等比数列
答え an=2⋅3n−1−1a_n=2\cdot 3^{n-1}-1
検算 a2=3⋅1+2=5a_2=3\cdot 1+2=5 ・ 式は 2⋅3−1=52\cdot 3-1=5
例題 11

a1=1a_1=1 ・ an+1=an+2na_{n+1}=a_n+2^n で定まる数列の一般項を求めよ。

解き方
階差数列が bn=2nb_n=2^n の階差型である
n≥2n\ge 2 のとき an=1+∑k=1n−12k=1+2(2n−1−1)2−1=2n−1a_n=1+\sum_{k=1}^{n-1}2^k=1+\frac{2(2^{n-1}-1)}{2-1}=2^n-1
n＝1 のとき 21−1=12^1-1=1 で初項と一致する
答え an=2n−1a_n=2^n-1

階差型では Σ の上端が n−1n-1 になる。等比数列の和の公式に入れるときの項数も n−1n-1 である。

典型的な誤りは an−α=(a1−α)pna_n-\alpha=(a_1-\alpha)p^{n} と指数を n にする誤りである。初項が a1−αa_1-\alpha なので指数は n−1n-1 になる。n＝1 を代入して a1a_1 に戻るかで確かめられる。

数学的帰納法

自然数 n についての命題 P(n)P(n) がすべての自然数で成り立つことを示す方法の1つが数学的帰納法である。次の2つを示す。

Ⅰ 出発点
  • n＝1 のとき P(1)P(1) が成り立つことを示す
Ⅱ 引き継ぎ
  • n＝k のとき成り立つと仮定する
  • その仮定を使って n＝k＋1 のときも成り立つことを示す

この2つで十分な理由は次のとおりである。Ⅰから P(1)P(1) が成り立つ。Ⅱで k＝1 とすると P(2)P(2) が成り立つ。続いて k＝2 とすると P(3)P(3) が成り立つ。この連鎖はどの自然数にも有限回で到達する。Ⅱで示すのは P(k)P(k) そのものではなく「P(k)P(k) ならば P(k+1)P(k+1)」という含意である。

例題 12

すべての自然数 n について ∑k=1nk2=16n(n+1)(2n+1)\sum_{k=1}^{n}k^2=\frac{1}{6}n(n+1)(2n+1) が成り立つことを数学的帰納法で証明せよ。

解き方
Ⅰ n＝1 のとき 左辺は 1 ・ 右辺は 16⋅1⋅2⋅3=1\frac{1}{6}\cdot 1\cdot 2\cdot 3=1 で成り立つ。
Ⅱ n＝k で成り立つと仮定する。n＝k＋1 の左辺は仮定を使って
16k(k+1)(2k+1)+(k+1)2=16(k+1){k(2k+1)+6(k+1)}\frac{1}{6}k(k+1)(2k+1)+(k+1)^2=\frac{1}{6}(k+1)\{k(2k+1)+6(k+1)\}
=16(k+1)(2k2+7k+6)=16(k+1)(k+2)(2k+3)=\frac{1}{6}(k+1)(2k^2+7k+6)=\frac{1}{6}(k+1)(k+2)(2k+3)
これは右辺の n に k＋1 を代入した式 16(k+1){(k+1)+1}{2(k+1)+1}\frac{1}{6}(k+1)\{(k+1)+1\}\{2(k+1)+1\} と一致する。
Ⅰ・Ⅱよりすべての自然数 n で成り立つ。
例題 13

n が4以上の自然数のとき 2n>3n2^n>3n を証明せよ。

解き方
Ⅰ n＝4 のとき 24=16>122^4=16>12 で成り立つ。
Ⅱ k≧4 で 2k>3k2^k>3k と仮定する。2k+1=2⋅2k>6k2^{k+1}=2\cdot 2^k>6k
6k−3(k+1)=3k−3>06k-3(k+1)=3k-3>0 なので 6k>3(k+1)6k>3(k+1)
よって 2k+1>3(k+1)2^{k+1}>3(k+1) で n＝k＋1 でも成り立つ。
Ⅰ・Ⅱより4以上のすべての自然数で成り立つ。

数学的帰納法は漸化式と組み合わせて使うことが多い。漸化式で a1a_1 から a4a_4 程度まで計算して一般項を推測する。推測した式がすべての n で正しいことを帰納法で証明する。Ⅱでは漸化式 ak+1=⋯a_{k+1}=\cdots に仮定の aka_k の式を代入して ak+1a_{k+1} の式を導く。推測だけでは証明にならないので帰納法の段階が必要になる。

出発点は n＝1 に限らない。例題13のように命題が成り立つ最小の n から始める。n＝3 では 8>98>9 が成り立たないので出発点を誤ると証明にならない。

典型的な誤りは3つある。Ⅰを省くこと・Ⅱで示すべき n＝k＋1 の式を最初から仮定に使うこと・Ⅱの式変形で仮定を一度も使わないことである。仮定を使わずに n＝k＋1 が示せたならそもそも帰納法は不要である。

現実世界の数列 複利と積立

金融の計算は等比数列とその和で書ける。元本 P を年利 r の複利で n 年預けると残高は P(1+r)nP(1+r)^n である。これは公比 1+r1+r の等比数列の項である。

毎年末に A 円ずつ積み立てる場合を考える。1年目末の A 円は残り n−1n-1 年の利息がついて A(1+r)n−1A(1+r)^{n-1} になる。最後の A 円は利息がつかない。n 年目末の合計は公比 1+r1+r の等比数列の和である。

A+A(1+r)+⋯+A(1+r)n−1=A{(1+r)n−1}rA+A(1+r)+\dots+A(1+r)^{n-1}=\frac{A\{(1+r)^n-1\}}{r}
例題 14

毎年末に10万円を年利3％の複利で10年間積み立てる。10年目末の残高を求めよ。1.0310=1.34391.03^{10}=1.3439 とする。

解き方
10×(1.3439−1)0.03=3.4390.03=114.63⋯\frac{10\times(1.3439-1)}{0.03}=\frac{3.439}{0.03}=114.63\cdots
答え 約114.6万円 ・ 積立額100万円に対して利息は約14.6万円

住宅ローンの元利均等返済も同じ式で決まる。借入額 L を n 回で返す毎回の返済額 x は「借入額を n 回後まで複利で増やした値」と「返済額を積み立てた値」が等しいという条件 L(1+r)n=x{(1+r)n−1}rL(1+r)^n=\frac{x\{(1+r)^n-1\}}{r} から求まる。

例題 15

300万円を年利2％で借り毎年末に同じ額 x 万円を返して5回で完済する。x を求めよ。1.025=1.10411.02^5=1.1041 とする。

解き方
借入額を5年後まで増やした値は 300×1.1041=331.23300\times 1.1041=331.23
返済額を5年後まで積み立てた値は x(1.1041−1)0.02=5.205x\frac{x(1.1041-1)}{0.02}=5.205x
両者が等しいので x=331.235.205=63.6⋯x=\frac{331.23}{5.205}=63.6\cdots
答え 約63.6万円 ・ 返済総額は約318万円で利息は約18万円
現実世界

「72の法則」は残高が2倍になる年数を 72÷年利（％）で概算する方法である。(1+r)n=2(1+r)^n=2 の両辺の自然対数をとると n=log⁡  2log⁡(1+r)n=\frac{\log\;2}{\log(1+r)} で r が小さいとき約 0.693r\frac{0.693}{r} になる。年利6％なら12年である。

  4. 68

初項 3 ・公差 4 の等差数列の初項から第20項までの和を求めよ。

問7 ・ 和から一般項

Sn=n2+3n+1S_n=n^2+3n+1 で与えられる数列について正しい記述を1つ選べ。

  1. すべての n で an=2n+2a_n=2n+2 である
  2. a1=5a_1=5 で n≥2n\ge 2 のとき an=2n+2a_n=2n+2 である
  3. a1=4a_1=4 で n≥2n\ge 2 のとき an=2n+2a_n=2n+2 である
  4. すべての n で an=2n+4a_n=2n+4 である

問8 ・ 数学的帰納法の構造

命題 P(n)P(n) がすべての自然数で成り立つことを数学的帰納法で示すとき Ⅱ で示すべき内容として正しいものを1つ選べ。

  1. P(k)P(k) が成り立つこと
  2. P(k+1)P(k+1) が成り立つと仮定すれば P(k)P(k) が成り立つこと
  3. P(k)P(k) が成り立つと仮定すれば P(k+1)P(k+1) が成り立つこと
  4. P(k)P(k) と P(k+1)P(k+1) がともに成り立つこと
解答と解説
正解は 3 である。Ⅱは含意「P(k)P(k) ならば P(k+1)P(k+1)」を示す段階である。1 と 4 は示すべき結論を前提にしている。2 は向きが逆で n＝1 から先へ連鎖しない。

この章の要点

要点 等差 an=a+(n−1)da_n=a+(n-1)d ・ 和 Sn=n(a+l)2S_n=\frac{n(a+l)}{2}。逆順に並べて足して導く。
等比 an=arn−1a_n=ar^{n-1} ・ 和 Sn=a(1−rn)1−rS_n=\frac{a(1-r^n)}{1-r}（r≠1）。Sn−rSnS_n-rS_n で導く。r＝1 は na。
∑k=12n(n+1)\sum k=\frac{1}{2}n(n+1) ・ ∑k2=16n(n+1)(2n+1)\sum k^2=\frac{1}{6}n(n+1)(2n+1) ・ ∑k3={12n(n+1)}2\sum k^3=\left\{\frac{1}{2}n(n+1)\right\}^2。
階差 an=a1+∑k=1n−1bka_n=a_1+\sum_{k=1}^{n-1}b_k と和 an=Sn−Sn−1a_n=S_n-S_{n-1} はどちらも n≥2n\ge 2 で n＝1 を別に確かめる。
an+1=pan+qa_{n+1}=pa_n+q は α=pα+q\alpha=p\alpha+q の α を引いて {an−α}\{a_n-\alpha\} を等比数列にする。
数学的帰納法は出発点と「k ならば k＋1」の2段で全自然数を示す。
