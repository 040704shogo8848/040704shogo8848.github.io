化学基礎 計算ドリル

化学基礎の計算問題は g・mol・L の単位を掛けて割る操作の組み合わせで解ける。このドリルは物質量・濃度・反応の量的関係・pH・中和滴定を毎回異なる数値で出題する。酸化数と化学式は暗記の確認として出題する。誤答には単位を追った解き方を表示する。記録はこの端末のブラウザに保存する。

問題の解き方の型method

どの分野も単位を式に書き込んで計算する。g を g/mol で割ると g が約分されて mol が残る。答えの単位が問われた単位と一致すれば式の組み方は正しい。

1. 物質量は mol を中心に置く
質量・粒子数・気体の体積は互いに直接換算しない。必ず一度 mol に直してから目的の量に換算する。
質量 g÷ モル質量 g/mol→ mol
粒子数 個÷ 6.0×1023 /mol→ mol
気体の体積 L÷ 22.4 L/mol→ mol　標準状態のみ
水 H2O 9.0 g の分子の数
→ モル質量 = 1×2 + 16 = 18 g/mol
→ 9.0 g ÷ 18 g/mol = 0.50 mol
→ 0.50 mol × 6.0×1023 /mol = 3.0×1023 個
第9章 物質量を開く
2. 濃度は溶液 1 L あたりの mol
モル濃度の分母は溶液の体積である。溶媒の体積ではない。希釈では水を加えても溶質の物質量は変わらないので C1V1 = C2V2 が成り立つ。質量パーセント濃度からの換算は溶液 1 L を仮定し 質量 → 溶質の質量 → 溶質の物質量 の順に求める。
98% 硫酸 密度 1.84 g/cm3
→ 溶液 1 L = 1000 cm3 の質量 = 1000 × 1.84 = 1840 g
→ 溶質 = 1840 × 0.98 = 1803.2 g
→ 1803.2 g ÷ 98 g/mol = 18.4 mol
→ 1 L あたりなので 18.4 mol/L
第10章 濃度を開く
3. 反応式の係数の比は物質量の比
係数の比は質量の比ではない。手順は3段階で固定する。与えられた量を mol に直す → 係数の比を掛ける → 問われた単位に戻す。
C3H8 + 5O2 → 3CO2 + 4H2O　プロパン 4.4 g から生じる CO2
→ 4.4 g ÷ 44 g/mol = 0.10 mol
→ CO2 は 0.10 × 3/1 = 0.30 mol
→ 0.30 mol × 44 g/mol = 13.2 g
第11章 反応の量的関係を開く
4. pH は [H+] の指数の符号を変えた値
強酸は全部電離するので [H+] = 価数 × モル濃度 である。強塩基は [OH−] = 価数 × モル濃度 を求めてから [H+][OH−] = 1.0×10−14 (mol/L)2 で [H+] に直す。10倍に薄めると pH は 7 に向かって 1 だけ変わる。酸をいくら薄めても pH は 7 を超えない。
5.0×10−3 mol/L の H2SO4
→ [H+] = 2 × 5.0×10−3 = 1.0×10−2 mol/L
→ pH = 2
1.0×10−3 mol/L の NaOH
→ [OH−] = 1.0×10−3
→ [H+] = 1.0×10−14 ÷ 1.0×10−3 = 1.0×10−11
→ pH = 11
第12章 酸と塩基を開く
5. 中和は H+ の mol と OH− の mol を等しくおく
酸の価数 a × 濃度 C × 体積 V = 塩基の価数 b × 濃度 C′ × 体積 V′ である。両辺の体積を mL のまま書けば 1/1000 は両辺で約分される。酢酸やアンモニアのような弱酸・弱塩基でも中和に要する量は価数と物質量だけで決まる。
0.10 mol/L の H2SO4 10.0 mL を 0.20 mol/L の NaOH で滴定
→ 2 × 0.10 × 10.0 = 1 × 0.20 × V′
→ V′ = 10.0 mL
第13章 中和を開く
6. 酸化数は合計から逆算する
  • 単体の原子の酸化数は 0
  • 単原子イオンの酸化数はイオンの電荷に等しい
  • 化合物中の H は +1 で O は −2
  • 化合物の酸化数の合計は 0 で多原子イオンの合計はイオンの電荷に等しい
  • アルカリ金属は +1 でアルカリ土類金属は +2
  • 例外は H2O2 の O が −1 で NaH の H が −1
KMnO4 の Mn
→ (+1) + x + (−2)×4 = 0
→ x = +7
第14章 酸化と還元を開く
7. 組成式は正負の電荷の合計を 0 にする
陽イオンの価数と陰イオンの価数を入れ替えて個数にし 最小の整数比に直す。多原子イオンが2個以上なら括弧でくくる。名称は陰イオンを先に読み 物イオン またはイオン を外して陽イオンの名称をつなげる。
Al3+ と SO42−
→ Al を 2個 SO4 を 3個 にすると (+3)×2 + (−2)×3 = 0
→ Al2(SO4)3　硫酸アルミニウム
