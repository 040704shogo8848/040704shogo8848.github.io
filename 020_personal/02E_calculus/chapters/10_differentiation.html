第5章では導関数を極限で定義し多項式を微分した。第9章では lim⁡x→0sin⁡  xx=1\lim_{x\to 0}\frac{\sin\;x}{x}=1 と e の定義を導いた。この章ではこの2つの道具を使い三角関数・指数関数・対数関数とそれらを組み合わせた関数の導関数を求める。

中心になるのは計算の規則である。積と商の微分・合成関数の微分・逆関数の微分の3つがあれば複雑な関数も基本の関数の導関数に分解して計算できる。第11章の接線・増減・凹凸はこの章の計算を前提にする。

微分可能性と連続性

関数 f(x)f(x) の x＝a での微分係数は次の極限である。この極限が有限の値として存在するとき f(x)f(x) は x＝a で微分可能であると言う。

f′(a)=lim⁡h→0f(a+h)−f(a)hf'(a)=\lim_{h\to 0}\frac{f(a+h)-f(a)}{h}

分数 f(a+h)−f(a)h\frac{f(a+h)-f(a)}{h} は x が a から a＋h まで変化するときの平均変化率でグラフ上の2点を結ぶ直線の傾きである。h を 0 に近づけると2点目が1点目に近づき直線は接線に近づく。微分係数は接線の傾きであり瞬間の変化率である。

区間のすべての点で微分可能なとき各点に f′(x)f'(x) を対応させる関数を導関数と呼ぶ。導関数は f′(x)f'(x) ・ y′y' ・ dydx\frac{dy}{dx} ・ ddxf(x)\frac{d}{dx}f(x) と書く。導関数を求めることを微分すると言う。

微分係数の定義を使う極限

定義の式の h は他の式に置き換えてよい。h → 0 となる量であれば何でもよい。この形の極限は導関数の公式を使わずに定義から求める。

例題 1

f(x) が x＝a で微分可能なとき lim⁡h→0f(a+2h)−f(a−h)h\lim_{h\to 0}\frac{f(a+2h)-f(a-h)}{h} を f′(a)f'(a) で表せ。

解き方
分子に f(a)f(a) を引いて足し2つに分ける。
f(a+2h)−f(a)2h⋅2+f(a−h)−f(a)−h⋅1\frac{f(a+2h)-f(a)}{2h}\cdot 2+\frac{f(a-h)-f(a)}{-h}\cdot 1
2h → 0 ・ −h → 0 なので各分数は f′(a)f'(a) に近づく
答え 3f′(a)3f'(a)

微分可能なら連続である

f(x)f(x) が x＝a で微分可能なら x＝a で連続である。理由は次の変形にある。

f(a+h)−f(a)=f(a+h)−f(a)h⋅h ⟶ f′(a)⋅0=0(h→0)f(a+h)-f(a)=\frac{f(a+h)-f(a)}{h}\cdot h\ \longrightarrow\ f'(a)\cdot 0=0\quad (h\to 0)

したがって lim⁡h→0f(a+h)=f(a)\lim_{h\to 0}f(a+h)=f(a) となり連続の条件を満たす。逆は成り立たない。連続でも微分可能でない関数がある。

右から近づく極限 lim⁡h→+0f(a+h)−f(a)h\lim_{h\to+0}\frac{f(a+h)-f(a)}{h} を右側微分係数・左から近づく極限を左側微分係数と呼ぶ。微分可能であるとは右側微分係数と左側微分係数が存在して一致することである。場合分けで定義された関数の境目ではこの2つを別々に計算する。

f(x)=∣x∣f(x)=|x| の x＝0 での右側極限は lim⁡h→+0∣h∣h=1\lim_{h\to+0}\frac{|h|}{h}=1 で左側極限は −1 である。一致しないので微分係数は存在しない。グラフの角になる点では微分できない。

例題 2

f(x)=x2f(x)=x^2（x≦1）・ f(x)=ax+bf(x)=ax+b（x＞1）が x＝1 で微分可能となる定数 a ・ b を求めよ。

解き方
微分可能なら連続なので x＝1 で左右の値が一致する。1=a+b1=a+b
左からの傾きは x2x^2 の導関数 2x に x＝1 を入れて 2 ・右からの傾きは a
一致の条件から a=2a=2 で b=−1b=-1
答え a=2a=2 ・ b=−1b=-1。直線 y＝2x−1 は y＝x² の点 (1, 1) での接線である。

典型的な誤りは傾きの一致だけを条件にして連続の条件 1=a+b1=a+b を落とすことである。値が跳ぶ点では傾きが一致しても微分可能でない。

経済で言えば

累進課税の税額は連続だが区切りの所得で微分できない

超過累進では税額は所得とともに途切れずに増える。限界税率が区切りで跳ぶのでグラフに角ができる。

積と商の微分

2つの関数の和と定数倍の導関数は第5章で扱った。積と商は次の公式になる。

{f(x)g(x)}′=f′(x)g(x)+f(x)g′(x)\{f(x)g(x)\}'=f'(x)g(x)+f(x)g'(x)
{f(x)g(x)}′=f′(x)g(x)−f(x)g′(x){g(x)}2,{1g(x)}′=−g′(x){g(x)}2\left\{\frac{f(x)}{g(x)}\right\}'=\frac{f'(x)g(x)-f(x)g'(x)}{\{g(x)\}^2},\qquad \left\{\frac{1}{g(x)}\right\}'=-\frac{g'(x)}{\{g(x)\}^2}

積の公式の導出を示す。分子に f(x)g(x+h)f(x)g(x+h) を引いて足す。

f(x+h)g(x+h)−f(x)g(x)h=f(x+h)−f(x)h g(x+h)+f(x) g(x+h)−g(x)h\frac{f(x+h)g(x+h)-f(x)g(x)}{h}=\frac{f(x+h)-f(x)}{h}\,g(x+h)+f(x)\,\frac{g(x+h)-g(x)}{h}

h → 0 で右辺は f′(x)g(x)+f(x)g′(x)f'(x)g(x)+f(x)g'(x) に近づく。g(x+h)→g(x)g(x+h)\to g(x) となるのは g が微分可能で連続だからである。商の公式は 1g\frac{1}{g} の導関数を同様に求め積の公式と組み合わせて得られる。

例題 3

(1) y=(x2+1)(3x−2)y=(x^2+1)(3x-2) ・ (2) y=xx2+1y=\frac{x}{x^2+1} を微分せよ。

解き方
(1) y′=2x(3x−2)+(x2+1)⋅3=9x2−4x+3y'=2x(3x-2)+(x^2+1)\cdot 3=9x^2-4x+3
検算 展開した 3x3−2x2+3x−23x^3-2x^2+3x-2 を微分しても同じ式になる。
(2) y′=1⋅(x2+1)−x⋅2x(x2+1)2=1−x2(x2+1)2y'=\frac{1\cdot(x^2+1)-x\cdot 2x}{(x^2+1)^2}=\frac{1-x^2}{(x^2+1)^2}

商の公式から負の整数乗の導関数も得られる。(1xn)′=−nxn−1x2n=−nx−n−1\left(\frac{1}{x^n}\right)'=-\frac{nx^{n-1}}{x^{2n}}=-nx^{-n-1} である。(xn)′=nxn−1(x^n)'=nx^{n-1} は n が負の整数でも成り立つ。

典型的な誤りは {f(x)g(x)}′=f′(x)g′(x)\{f(x)g(x)\}'=f'(x)g'(x) とすることである。x⋅x=x2x\cdot x=x^2 で確かめると左辺は 2x で右辺は 1 になり一致しない。商の公式では分子の引く順序を逆にする誤りが多い。分子は「分子の微分×分母」から始める。

会計で言えば

積の微分は売上の増減分析である

売上＝単価×数量の微小な変化は「単価の変化×数量」と「単価×数量の変化」の和になる。差異分析で両方の変化の積を無視した分解にあたる。

合成関数と逆関数の微分

y=f(u)y=f(u) と u=g(x)u=g(x) を組み合わせた y=f(g(x))y=f(g(x)) を合成関数と呼ぶ。合成関数の導関数は次の式で求める。

dydx=dydu⋅dudxすなわち{f(g(x))}′=f′(g(x)) g′(x)\frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx}\qquad\text{すなわち}\qquad \{f(g(x))\}'=f'(g(x))\,g'(x)

理由は変化量の比にある。x が Δx 変化すると u が Δu 変化し y が Δy 変化する。Δu≠0 なら ΔyΔx=ΔyΔu⋅ΔuΔx\frac{\Delta y}{\Delta x}=\frac{\Delta y}{\Delta u}\cdot\frac{\Delta u}{\Delta x} が成り立つ。Δx → 0 のとき Δu → 0 なので各比はそれぞれの導関数に近づく。

例題 4

(1) y=(2x+1)5y=(2x+1)^5 ・ (2) y=x2+1y=\sqrt{x^2+1} を微分せよ。

解き方
(1) u=2x+1u=2x+1 とおくと y=u5y=u^5。dydu=5u4\frac{dy}{du}=5u^4 ・ dudx=2\frac{du}{dx}=2
答え y′=10(2x+1)4y'=10(2x+1)^4
(2) u=x2+1u=x^2+1 とおくと y=u12y=u^{\frac{1}{2}}。dydu=12u−12\frac{dy}{du}=\frac{1}{2}u^{-\frac{1}{2}} ・ dudx=2x\frac{du}{dx}=2x
答え y′=xx2+1y'=\frac{x}{\sqrt{x^2+1}}

(2) では u12u^{\frac{1}{2}} の微分に有理数乗の公式を使った。この公式は次の逆関数の微分から導く。

逆関数の微分

y=f(x)y=f(x) の逆関数を考える。x を y の関数とみると次の関係が成り立つ。

dxdy=1dydx\frac{dx}{dy}=\frac{1}{\frac{dy}{dx}}

逆関数のグラフはもとのグラフを直線 y＝x に関して折り返したものである。折り返すと縦の変化と横の変化が入れ替わるので傾きは逆数になる。

この関係から有理数乗の公式を導く。y=x1ny=x^{\frac{1}{n}}（x＞0）なら x=ynx=y^n で dxdy=nyn−1\frac{dx}{dy}=ny^{n-1} である。したがって dydx=1nyn−1=1nx−n−1n=1nx1n−1\frac{dy}{dx}=\frac{1}{ny^{n-1}}=\frac{1}{n}x^{-\frac{n-1}{n}}=\frac{1}{n}x^{\frac{1}{n}-1} となる。xmn=(x1n)mx^{\frac{m}{n}}=\left(x^{\frac{1}{n}}\right)^m に合成関数の微分を使えば任意の有理数 r で次の公式が成り立つ。第5節で実数 r に広げる。

(xr)′=rxr−1(x^r)'=rx^{r-1}

1次式を中に含む関数はよく使うので形で暗記する。{f(ax+b)}′=af′(ax+b)\{f(ax+b)\}'=af'(ax+b) である。たとえば {(3x−1)4}′=12(3x−1)3\{(3x-1)^4\}'=12(3x-1)^3 ・ {2x+1}′=12x+1\{\sqrt{2x+1}\}'=\frac{1}{\sqrt{2x+1}} となる。2つ目は 12(2x+1)−12⋅2\frac{1}{2}(2x+1)^{-\frac{1}{2}}\cdot 2 を整理したものである。

典型的な誤りは外側だけを微分して内側の導関数を掛け忘れることである。{(2x+1)5}′\{(2x+1)^5\}' を 5(2x+1)45(2x+1)^4 とするのがこの誤りで2倍が抜けている。

三角関数の導関数

三角関数の導関数は次のとおりである。x は弧度法である。

(sin⁡  x)′=cos⁡  x,(cos⁡  x)′=−sin⁡  x,(tan⁡  x)′=1cos⁡2  x(\sin\;x)'=\cos\;x,\qquad (\cos\;x)'=-\sin\;x,\qquad (\tan\;x)'=\frac{1}{\cos^2\;x}

(sin⁡  x)′(\sin\;x)' の導出を示す。差を積に直す公式 sin⁡  A−sin⁡  B=2  cos⁡A+B2  sin⁡A−B2\sin\;A-\sin\;B=2\;\cos\frac{A+B}{2}\;\sin\frac{A-B}{2} を使う。

sin⁡(x+h)−sin⁡  xh=cos⁡(x+h2)⋅sin⁡h2h2\frac{\sin(x+h)-\sin\;x}{h}=\cos\left(x+\frac{h}{2}\right)\cdot\frac{\sin\frac{h}{2}}{\frac{h}{2}}

h → 0 で cos⁡(x+h2)→  cos⁡  x\cos\left(x+\frac{h}{2}\right)\to\;\cos\;x で第9章の極限から sin⁡h2h2→1\frac{\sin\frac{h}{2}}{\frac{h}{2}}\to 1 である。よって (sin⁡  x)′=cos⁡  x(\sin\;x)'=\cos\;x となる。(cos⁡  x)′(\cos\;x)' も cos⁡  A−cos⁡  B=−2  sin⁡A+B2  sin⁡A−B2\cos\;A-\cos\;B=-2\;\sin\frac{A+B}{2}\;\sin\frac{A-B}{2} から同様に求まる。式で書くと cos⁡(x+h)−cos⁡  xh=−sin⁡(x+h2)⋅sin⁡h2h2→−sin⁡  x\frac{\cos(x+h)-\cos\;x}{h}=-\sin\left(x+\frac{h}{2}\right)\cdot\frac{\sin\frac{h}{2}}{\frac{h}{2}}\to-\sin\;x である。cos⁡  x=sin⁡(x+π2)\cos\;x=\sin\left(x+\frac{\pi}{2}\right) に合成関数の微分を使っても cos⁡(x+π2)=−sin⁡  x\cos\left(x+\frac{\pi}{2}\right)=-\sin\;x が得られる。(tan⁡  x)′(\tan\;x)' は tan⁡  x=sin⁡  xcos⁡  x\tan\;x=\frac{\sin\;x}{\cos\;x} に商の公式を使い cos⁡2  x+sin⁡2  xcos⁡2  x=1cos⁡2  x\frac{\cos^2\;x+\sin^2\;x}{\cos^2\;x}=\frac{1}{\cos^2\;x} となる。

弧度法を使う理由はここにある。x を度で測る関数 sin⁡  x∘\sin\;x^\circ を微分すると π180  cos⁡  x∘\frac{\pi}{180}\;\cos\;x^\circ となり係数 π180\frac{\pi}{180} が残る。弧度法なら係数が1になり公式が最も簡単になる。合成関数の形では {sin⁡(ax+b)}′=a  cos⁡(ax+b)\{\sin(ax+b)\}'=a\;\cos(ax+b) ・ {tan⁡(ax+b)}′=acos⁡2(ax+b)\{\tan(ax+b)\}'=\frac{a}{\cos^2(ax+b)} である。

例題 5

指数関数と対数関数の導関数

対数関数

先に対数関数を微分する。x＞0 とし対数の性質で差をまとめる。

log⁡(x+h)−log⁡  xh=1h  log⁡(1+hx)=1x  log⁡(1+hx)xh\frac{\log(x+h)-\log\;x}{h}=\frac{1}{h}\;\log\left(1+\frac{h}{x}\right)=\frac{1}{x}\;\log\left(1+\frac{h}{x}\right)^{\frac{x}{h}}

t=hxt=\frac{h}{x} とおくと h → 0 で t → 0 となり (1+t)1t→e(1+t)^{\frac{1}{t}}\to e である。これは第9章の e の定義である。よって極限は 1x  log⁡  e=1x\frac{1}{x}\;\log\;e=\frac{1}{x} になる。底を e にしたので log⁡  e=1\log\;e=1 となり式が最も簡単になる。

(log⁡  x)′=1x,(log⁡∣x∣)′=1x,(log⁡a  x)′=1x  log⁡  a(\log\;x)'=\frac{1}{x},\qquad (\log|x|)'=\frac{1}{x},\qquad (\log_a\;x)'=\frac{1}{x\;\log\;a}

log⁡∣x∣\log|x| は x＜0 でも定義され導関数は同じく 1x\frac{1}{x} である。x＜0 で log⁡(−x)\log(-x) を合成関数として微分すると −1−x=1x\frac{-1}{-x}=\frac{1}{x} となるからである。log⁡a  x=log⁡  xlog⁡  a\log_a\;x=\frac{\log\;x}{\log\;a} と底の変換をすれば3つ目の式が得られる。

指数関数と e の意味

y=exy=e^x は x=log⁡  yx=\log\;y の逆関数である。dxdy=1y\frac{dx}{dy}=\frac{1}{y} なので逆関数の微分から dydx=y=ex\frac{dy}{dx}=y=e^x となる。

(ex)′=ex,(ax)′=ax  log⁡  a(e^x)'=e^x,\qquad (a^x)'=a^x\;\log\;a

ax=ex  log⁡  aa^x=e^{x\;\log\;a} と書き直して合成関数の微分を使うと2つ目の式になる。x＝0 での傾きは log⁡  a\log\;a で a＝2 なら約0.693 ・ a＝3 なら約1.099 である。点 (0, 1) での傾きがちょうど1になる底が e である。式で書くと lim⁡h→0eh−1h=1\lim_{h\to 0}\frac{e^h-1}{h}=1 である。

極限 lim⁡h→0eh−1h=1\lim_{h\to 0}\frac{e^h-1}{h}=1 は対数の極限から直接示せる。eh−1=te^h-1=t とおくと h=log⁡(1+t)h=\log(1+t) で h → 0 のとき t → 0 である。eh−1h=tlog⁡(1+t)=1log⁡(1+t)1t→1log⁡  e=1\frac{e^h-1}{h}=\frac{t}{\log(1+t)}=\frac{1}{\log(1+t)^{\frac{1}{t}}}\to\frac{1}{\log\;e}=1 となる。この極限を使えば ex+h−exh=ex⋅eh−1h→ex\frac{e^{x+h}-e^x}{h}=e^x\cdot\frac{e^h-1}{h}\to e^x で導関数を定義から求めることもできる。

対数微分法

両辺の対数をとってから微分する方法を対数微分法と呼ぶ。積・商・累乗が重なる関数や指数に x を含む関数で使う。{log⁡  y}′=y′y\{\log\;y\}'=\frac{y'}{y} を利用する。

例題 7

y=xxy=x^x（x＞0）を微分せよ。

解き方
両辺は正なので自然対数をとる。log⁡  y=x  log⁡  x\log\;y=x\;\log\;x

例題 8

解き方

答え y′=−(x+1)2(x2+4x−3)(x2+1)3y'=-\frac{(x+1)^2(x^2+4x-3)}{(x^2+1)^3}

商の公式で直接計算すると分子の展開が長くなる。積と商と累乗が重なるときは対数微分法のほうが計算量が少ない。y が負になりうる関数では絶対値をとってから対数をとる。

同じ方法で実数乗の公式を示せる。y=xry=x^r（x＞0 ・ r は実数）なら log⁡  y=r  log⁡  x\log\;y=r\;\log\;x で y′y=rx\frac{y'}{y}=\frac{r}{x} となり y′=rxr−1y'=rx^{r-1} である。

典型的な誤りは xxx^x を x⋅xx−1x\cdot x^{x-1} とすることである。(xr)′=rxr−1(x^r)'=rx^{r-1} は指数が定数のときの公式で指数が x を含む場合には使えない。(ax)′=ax(a^x)'=a^x とするのも誤りで log⁡  a\log\;a が掛かる。

陰関数と媒介変数表示の微分

学習指導要領解説の数学Ⅲの微分法はこの節の2つの方法を名指ししていない。媒介変数表示そのものは数学Cの平面上の曲線で学ぶ。数学Ⅲの積分法の解説は媒介変数で表された曲線の面積と曲線の長さを挙げており導関数の計算はその前提になる。

方程式で表された曲線

円 x2+y2=25x^2+y^2=25 のように x と y の方程式で曲線が与えられることがある。y を x の関数とみて両辺を x で微分する。y2y^2 は合成関数なので ddxy2=2ydydx\frac{d}{dx}y^2=2y\frac{dy}{dx} である。

2x+2ydydx=0⟹dydx=−xy(y≠0)2x+2y\frac{dy}{dx}=0\quad\Longrightarrow\quad \frac{dy}{dx}=-\frac{x}{y}\quad (y\neq 0)

点 (3, 4) での接線の傾きは −34-\frac{3}{4} である。この点の半径の傾きは 43\frac{4}{3} で積は −1 になる。円の接線が半径に垂直であることと一致する。

媒介変数表示

曲線が x=f(t)x=f(t) ・ y=g(t)y=g(t) と媒介変数 t で表されているとき導関数は次の式で求める。合成関数と逆関数の微分を組み合わせたものである。

dydx=dydtdxdt(dxdt≠0)\frac{dy}{dx}=\frac{\frac{dy}{dt}}{\frac{dx}{dt}}\qquad \left(\frac{dx}{dt}\neq 0\right)

この式の理由は次のとおりである。x が t の関数で dxdt≠0\frac{dx}{dt}\neq 0 なら t を x の関数とみることができ逆関数の微分から dtdx=1/dxdt\frac{dt}{dx}=1\Big/\frac{dx}{dt} となる。y を t を経由した x の合成関数とみると dydx=dydt⋅dtdx\frac{dy}{dx}=\frac{dy}{dt}\cdot\frac{dt}{dx} である。2つを組み合わせると上の式になる。dxdt=0\frac{dx}{dt}=0 となる t ではこの式が使えない。サイクロイドの尖った点がその例である。

図の点 P では dxdt=−2  sin⁡π4=−2\frac{dx}{dt}=-2\;\sin\frac{\pi}{4}=-\sqrt{2} ・ dydt=cos⁡π4=22\frac{dy}{dt}=\cos\frac{\pi}{4}=\frac{\sqrt{2}}{2} で傾きは −12-\frac{1}{2} である。点 (2,22)\left(\sqrt{2},\frac{\sqrt{2}}{2}\right) を通るので接線は y=−12x+2y=-\frac{1}{2}x+\sqrt{2} になる。楕円を x24+y2=1\frac{x^2}{4}+y^2=1 と方程式で表して陰関数として微分しても dydx=−x4y\frac{dy}{dx}=-\frac{x}{4y} で同じ値 −12-\frac{1}{2} が得られる。

例題 11

y′=ex  sin⁡  x+ex  cos⁡  x=ex(sin⁡  x+cos⁡  x)y'=e^x\;\sin\;x+e^x\;\cos\;x=e^x(\sin\;x+\cos\;x)

現実世界の微分 価格弾力性

経済学の価格弾力性は価格が1％変化したとき需要量が何％変化するかを表す。変化率の比なので対数の微分で書ける。

ε=−dQ/QdP/P=−d(log⁡  Q)d(log⁡  P)\varepsilon=-\frac{dQ/Q}{dP/P}=-\frac{d(\log\;Q)}{d(\log\;P)}

需要関数が Q=AP−2Q=AP^{-2} なら log⁡  Q=log⁡  A−2  log⁡  P\log\;Q=\log\;A-2\;\log\;P で弾力性はどの価格でも 2 である。価格を1％上げると需要量は約2％減る。対数をとると積が和に変わり累乗が係数に変わる。対数微分法と同じ操作である。

経済学で「限界」と呼ぶ量は導関数である。価格 P が販売量 Q の関数 P(Q)P(Q) のとき収入は R=PQR=PQ で限界収入は積の微分から次の式になる。

dRdQ=P+QdPdQ=P(1−1ε)\frac{dR}{dQ}=P+Q\frac{dP}{dQ}=P\left(1-\frac{1}{\varepsilon}\right)

弾力性 ε が1より大きければ限界収入は正で販売量を増やすと収入が増える。ε が1より小さければ値下げして販売量を増やすと収入は減る。独占企業の価格設定の理論はこの式から始まる。

現実世界

微分を dx ・ dy で表す記法はライプニッツが1684年の論文で発表した。ニュートンは時間による変化を点で表す記法を使った。分数のように約分できる形の記法が合成関数と逆関数の微分の計算を簡単にした。

問2 ・ 合成関数の微分

f(x)=(2x−1)4f(x)=(2x-1)^4 のとき f′(1)f'(1) の値を求めよ。

問3 ・ 商の微分

f(x)=xx+1f(x)=\frac{x}{x+1} のとき f′(1)f'(1) の値を求めよ。

y=e−x2y=e^{-x^2} の導関数として正しいものを1つ選べ。

問8 ・ 微分可能性

次の記述のうち正しいものを1つ選べ。

  1. x＝a で連続な関数は x＝a で微分可能である
  2. x＝a で微分可能な関数は x＝a で連続である
  3. y=∣x∣y=|x| は x＝0 で微分可能で微分係数は 0 である
  4. y=∣x∣y=|x| は x＝0 で連続でない
解答と解説
正解は 2 である。1 は逆が成り立たない例として y=∣x∣y=|x| がある。y=∣x∣y=|x| は x＝0 で連続だが左右の傾きが −1 と 1 で一致せず微分可能でない。

この章の要点

要点 微分可能なら連続。逆は不成立で y＝|x| が反例。
(fg)′=f′g+fg′(fg)'=f'g+fg' ・ (fg)′=f′g−fg′g2\left(\frac{f}{g}\right)'=\frac{f'g-fg'}{g^2}。
合成関数 dydx=dydu⋅dudx\frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx} ・ 逆関数 dxdy=1/dydx\frac{dx}{dy}=1\Big/\frac{dy}{dx} ・ (xr)′=rxr−1(x^r)'=rx^{r-1}。
(sin⁡  x)′=cos⁡  x(\sin\;x)'=\cos\;x ・ (cos⁡  x)′=−sin⁡  x(\cos\;x)'=-\sin\;x ・ (tan⁡  x)′=1cos⁡2  x(\tan\;x)'=\frac{1}{\cos^2\;x}。
(log⁡  x)′=1x(\log\;x)'=\frac{1}{x} ・ (ex)′=ex(e^x)'=e^x ・ (ax)′=ax  log⁡  a(a^x)'=a^x\;\log\;a。e は (0, 1) での傾きが1になる底。
指数に x を含む関数は対数微分法。陰関数は y を x の関数とみて微分。媒介変数は dy/dtdx/dt\frac{dy/dt}{dx/dt}。

残っている問い

  • 合成関数の微分の理由は Δu≠0 を仮定した説明である。Δu＝0 となる x が 0 の近くに無数にある関数では別の証明が要る。厳密な証明は大学の解析学で扱う。
  • (sin⁡  x)′(\sin\;x)' の導出は第9章の lim⁡sin⁡  xx=1\lim\frac{\sin\;x}{x}=1 に依存し その証明の扇形の面積には循環論法の指摘がある。
  • 陰関数の微分は y が x の微分可能な関数として表せることを前提にしている。その保証は陰関数定理で大学の範囲である。
  • 数学Ⅲの解説の微分法は積・商・合成関数・三角関数・指数関数・対数関数の導関数を挙げる。逆関数の導関数と対数微分法は「取り扱うことが考えられる」とする。陰関数と媒介変数表示の微分は解説の微分法に記述がない。教科書での扱いは確認できなかった。
