正規分布

値が連続的に変わる確率変数では確率を曲線の下の面積で表す。代表が左右対称の釣り鐘形をした正規分布 N(m, σ²) である。どの正規分布も Z＝(X−m)/σ で標準正規分布に直せるので1枚の正規分布表で確率を求められる。n が大きい二項分布も正規分布で近似できる。

第8章で扱った確率変数は 0・1・2 のように飛び飛びの値をとった。身長や重量や待ち時間は連続した値をとる。このような確率変数では「ちょうど170.000…cm になる確率」を考えても意味がない。この章では確率を面積で表す方法を導入し最も重要な連続型の分布である正規分布を扱う。

共通テストの数学Ⅱ・B・Cでは巻末に正規分布表が付く。問題の多くは「標準化して正規分布表を引く」という同じ手順で解ける。第10章の推定と第11章の検定もこの手順を使う。表の引き方を確実にすることがこの章の目標である。

連続型確率変数と確率密度関数

第1章のヒストグラムで階級の幅を細かくしていく場面を考える。縦軸を「相対度数÷階級の幅」にとると各柱の面積がその階級の相対度数になり全部の面積の合計は1になる。データの個数を増やしながら幅を0に近づけると柱の上端は1本の曲線に近づく。

連続した値をとる確率変数を連続型確率変数と呼ぶ。連続型確率変数 X に対して次の性質をもつ関数 f(x) を X の確率密度関数と呼ぶ。曲線 y＝f(x) を X の分布曲線と呼ぶ。

  • 常に f(x)≥0f(x)\ge 0 である
  • 曲線と x 軸の間の面積の合計は1である
  • a≤X≤ba\le X\le b となる確率は x＝a から x＝b までの曲線の下の面積に等しい
P(a≤X≤b)=∫abf(x) dxP(a\le X\le b)=\int_a^b f(x)\,dx

積分は数学Ⅱで扱う面積の計算である。この章の計算では積分の記号は確率が面積であることを示す記号として読めば足りる。正規分布の面積は表から求める。

面積で考えると幅0の区間の面積は0である。連続型では P(X＝a)＝0 なので P(a≤X≤b) と P(a<X<b) は等しい。不等号に等号が付くかどうかを気にする必要がない点が離散型と異なる。

例題 1

確率変数 X の確率密度関数が 0≤x≤2 で f(x)＝x/2 でありそれ以外で0である。P(0.5≤X≤1) を求めよ。

解き方
手順1 0 から t までの面積は底辺 t・高さ t/2 の三角形なので t2/4t^2/4 である。
手順2 P(0.5≤X≤1)=124−0.524=14−116=316P(0.5\le X\le 1)=\frac{1^2}{4}-\frac{0.5^2}{4}=\frac14-\frac1{16}=\frac{3}{16}。答え 3/16

連続型確率変数の期待値と分散も第8章の Σ を積分に置き換えて定義する。E(X)=∫xf(x) dxE(X)=\int x f(x)\,dx で V(X)=∫(x−m)2f(x) dxV(X)=\int (x-m)^2 f(x)\,dx である。aX＋b の公式と独立な確率変数の和の公式は連続型でもそのまま成り立つ。学習指導要領解説は確率密度関数を用いた平均と分散を理数数学Ⅱで発展させる内容として例示している。数学Bでは正規分布表を引く計算が中心である。

典型的な誤りは f(a) の値を P(X＝a) と読む誤りである。確率は面積であり f(a) は高さである。f(x) の値は1を超えることもある。

正規分布 N(m, σ²)

m を実数とし σ を正の数とする。次の関数を確率密度関数とする分布を正規分布と呼び N(m,σ2)N(m,\sigma^2) で表す。e は約 2.718 の定数で π は円周率である。

f(x)=12π σ e−(x−m)22σ2f(x)=\frac{1}{\sqrt{2\pi}\,\sigma}\,e^{-\frac{(x-m)^2}{2\sigma^2}}

式を暗記する必要はない。共通テストで問われるのは次の性質である。

  • 正規分布 N(m,σ2)N(m,\sigma^2) に従う X の期待値は m で標準偏差は σ である。分散は σ² である
  • 分布曲線は直線 x＝m について対称で x＝m で最大になる
  • x 軸を漸近線とし m から離れるほど0に近づく
  • σ が大きいほど山は低く横に広がる。σ が小さいほど高く細くなる。面積はいつも1である

正規分布という名前は多くの測定値がこの形に近い分布をとることに由来する。測定誤差・同じ年齢の人の身長・大量生産された製品の寸法などである。理由の1つは第10章で扱う中心極限定理である。小さな独立の要因が多数加わって決まる量は正規分布に近い分布に従う。

典型的な誤りは N(m,σ2)N(m,\sigma^2) の2番目の数を標準偏差と読む誤りである。N(50, 100) なら分散が100で標準偏差は10である。問題文が N(50, 10²) と書くか N(50, 100) と書くかを確かめる。

現実世界

偏差値は N(50, 10²) に合わせた目盛りである

偏差値は「50＋10×(得点−平均)÷標準偏差」で計算する。得点の分布が正規分布に近ければ偏差値60以上は約16%で70以上は約2.3%である。

標準化

m と σ の組は無数にあるので正規分布ごとに面積の表を用意することはできない。そこで第8章の aX＋b の公式を使って1つの分布に直す。X が N(m,σ2)N(m,\sigma^2) に従うとき次の Z を考える。

Z=X−mσZ=\frac{X-m}{\sigma}

Z は 1σX−mσ\frac1\sigma X-\frac m\sigma の形なので aX＋b の公式から期待値と分散が求まる。

E(Z)=1σE(X)−mσ=0,V(Z)=1σ2V(X)=1E(Z)=\frac{1}{\sigma}E(X)-\frac{m}{\sigma}=0 ,\qquad V(Z)=\frac{1}{\sigma^2}V(X)=1

正規分布に従う確率変数を1次式で変換したものもまた正規分布に従う。したがって Z は N(0, 1) に従う。N(0, 1) を標準正規分布と呼びこの変換を標準化と呼ぶ。Z の値は X が平均から標準偏差何個分離れているかを表す。単位は消え符号は平均より上か下かを示す。

例題 2

X が N(50, 10²) に従う。X＝65 と X＝35 はそれぞれ Z のいくつに当たるか。

解き方
手順1 Z=(65−50)/10=1.5Z=(65-50)/10=1.5
手順2 Z=(35−50)/10=−1.5Z=(35-50)/10=-1.5。答え 1.5 と −1.5 で平均から標準偏差1.5個分上と下である
投資で言えば

標準化はシャープレシオと同じ割り算である

シャープレシオは超過リターンを標準偏差で割りリスク1単位あたりの成果をみる。Z も平均からの差を σ で割り散らばり1単位あたりの位置をみる。

野球で言えば

投高打低の年の打率 .300 は打高投低の年の .330 に勝ることがある

リーグ平均と標準偏差で標準化すると時代の異なる打者を同じ目盛りで比べられる。

例題 3

ある試験の得点 X が N(50, 10²) に従う。P(X≥65) と P(40≤X≤62) を求めよ。

解き方
手順1 標準化する。X＝65 は Z＝1.5 で X＝40 は Z＝−1 で X＝62 は Z＝1.2 である。
手順2 P(X≥65)＝P(Z≥1.5)＝0.5−0.4332＝0.0668
手順3 P(40≤X≤62)＝P(−1≤Z≤1.2)＝p(1)＋p(1.2)＝0.3413＋0.3849＝0.7262。答え 0.0668 と 0.7262
例題 4

例題3の試験で上位2.5%に入る得点の境目を求めよ。

解き方
手順1 P(Z≥z)＝0.025 となる z を求める。0.5−p(z)＝0.025 から p(z)＝0.4750 である。
手順2 表で 0.4750 を検索すると 1.9 の行と 0.06 の列にあり z＝1.96 である。
手順3 X＝50＋1.96×10＝69.6。答え 約69.6点

例題4のように確率から z を求める逆引きは推定と検定の準備になる。とくに p(1.96)＝0.4750 と p(2.58)＝0.4951 は第10章と第11章で何度も使う。

典型的な誤りは3つある。1つ目は p(a) をそのまま P(Z≥a) とする誤りである。2つ目は負の z で表を引こうとする誤りで対称性を使って正の値に直す。3つ目は標準化で σ² で割る誤りである。割るのは標準偏差 σ である。

68-95-99.7 の目安

正規分布表から平均の前後に標準偏差の1倍・2倍・3倍の幅をとったときに入る割合が求まる。

P(∣Z∣≤1)=2×0.3413=0.6826P(∣Z∣≤2)=2×0.4772=0.9544P(∣Z∣≤3)=2×0.49865=0.9973\begin{aligned} P(|Z|\le 1)&=2\times 0.3413=0.6826\\ P(|Z|\le 2)&=2\times 0.4772=0.9544\\ P(|Z|\le 3)&=2\times 0.49865=0.9973 \end{aligned}

N(m, σ²) に戻すと m±σ に約68%・m±2σ に約95%・m±3σ に約99.7% が入る。平均から3σ以上離れた値は1000回に3回程度しか生じない。この目安で計算結果の桁の誤りを素早く確かめられる。

95% の範囲を正確に求めるときは 2σ ではなく 1.96σ を使う。2×p(1.96)＝0.95 だからである。目安の95.4%と区別する。

例題 5

ある部品の長さが N(20.0, 0.1²) に従う。長さが 19.8 以上 20.2 以下の部品を合格とするとき不合格品の割合を求めよ。

解き方
手順1 19.8 と 20.2 は m±2σ に当たる。
手順2 合格の割合は P(|Z|≤2)＝0.9544 である。
手順3 不合格は 1−0.9544＝0.0456。答え 約4.6%

二項分布の正規分布による近似

第8章の図3では n＝10 の二項分布の棒の形が山形であった。n を大きくすると棒の並びは正規分布の曲線に近づく。この事実は次のようにまとめられる。

X が二項分布 B(n, p) に従うとき n が十分大きければ X は近似的に正規分布 N(np, np(1−p)) に従う。したがって次の Z は近似的に N(0, 1) に従う。

Z=X−npnp(1−p)Z=\frac{X-np}{\sqrt{np(1-p)}}

近似先の正規分布の平均と分散は二項分布の期待値と分散そのものである。形だけを正規分布に置き換え中心と散らばりは元の分布から受け継ぐ。

例題 6

1枚の硬貨を400回投げる。表が220回以上出る確率を正規分布で近似して求めよ。

解き方
手順1 表の回数 X は B(400, 1/2) に従う。期待値は 200 で分散は 400×1/2×1/2＝100 である。標準偏差は10である。
手順2 X は近似的に N(200, 10²) に従う。X＝220 は Z＝(220−200)/10＝2 である。
手順3 P(X≥220)≒P(Z≥2)＝0.5−0.4772＝0.0228。答え 約0.0228

典型的な誤りは分散 np(1−p) を標準偏差として割る誤りである。例題6で100で割ると Z＝0.2 になり答えが大きくずれる。標準化の分母はいつも標準偏差である。

恋愛で言えば

100回のデートで成功する回数は二項分布でありその形は正規分布に近い

1回ごとの成否は0か1でも回数が増えると成功回数の分布は滑らかな山になる。中心は np で幅は √(np(1−p)) である。

現実世界の正規分布

二項分布を正規分布で近似する公式は18世紀にド・モアブルが硬貨投げの計算から得た。1738年の『偶然の理論』第2版に収められた。19世紀にはガウスが天体観測の誤差の分析に正規分布を用いた。このためガウス分布とも呼ばれる。

現実世界

工場の品質管理では製品の寸法の平均から上下に3σの位置に管理限界線を引く方式が広く使われる。正規分布なら管理限界を超える製品は約0.3%なので超えた場合は工程の異常を疑う。一方で株価の日次変化率は正規分布より裾が厚い。正規分布を仮定すると大きな下落の確率を過小に見積もる。

確認問題

問1 ・ 確率密度関数

確率変数 X の確率密度関数が 0≤x≤3 で f(x)＝ax でありそれ以外で0である。P(1≤X≤2) を分数で答えよ。

解答と解説
正解は 1/3 である。全体の面積 a×3×3÷2＝9a/2＝1 より a＝2/9 である。0 から t までの面積は a t²/2＝t²/9 である。P(1≤X≤2)＝4/9−1/9＝3/9＝1/3
問2 ・ 片側の確率

X が N(60, 8²) に従うとき P(X≥72) として正しいものを1つ選べ。

  1. 0.0668
  2. 0.4332
  3. 0.9332
  4. 0.1587
解答と解説
正解は 1 である。Z＝(72−60)/8＝1.5 で P(Z≥1.5)＝0.5−0.4332＝0.0668 である。2 は表の値をそのまま答えた誤りで 3 は 0.5 に足した誤りである。
問3 ・ 両側にまたがる確率

ある集団の身長 X cm が N(170, 6²) に従う。P(158≤X≤176) を小数第4位まで答えよ。

解答と解説
正解は 0.8185 である。158 は Z＝−2 で 176 は Z＝1 である。p(2)＋p(1)＝0.4772＋0.3413＝0.8185
問4 ・ 逆引き

ある試験の得点が N(500, 100²) に従う。上位5%に入る得点の境目に最も近いものを1つ選べ。

  1. 598
  2. 664
  3. 696
  4. 758
解答と解説
正解は 2 である。P(Z≥z)＝0.05 から p(z)＝0.45 である。表で p(1.64)＝0.4495 と p(1.65)＝0.4505 の間なので z≒1.645 である。500＋1.645×100≒664 である。3 は上位2.5%の境目 z＝1.96 を使った値で 4 は上位0.5%の境目 z＝2.58 の値である。
問5 ・ 二項分布の近似

1個のさいころを450回投げて1または2の目が出る回数を X とする。P(X≤138) を正規分布で近似した値として正しいものを1つ選べ。

  1. 0.1151
  2. 0.3849
  3. 0.8849
  4. 0.2302
解答と解説
正解は 1 である。X は B(450, 1/3) に従い期待値 150・分散 450×1/3×2/3＝100・標準偏差10である。Z＝(138−150)/10＝−1.2 で P(Z≤−1.2)＝0.5−0.3849＝0.1151 である。4 は両側の確率で2倍した誤りである。
問6 ・ 正規分布の性質

X が N(m, σ²) に従い確率密度関数を f(x) とする。誤りを含むものを1つ選べ。

  1. 曲線 y＝f(x) は直線 x＝m について対称である
  2. σ を大きくすると曲線の山は低くなる
  3. P(X＝m)＝f(m) である
  4. 曲線と x 軸の間の面積は1である
解答と解説
正解は 3 である。連続型確率変数では1点をとる確率は0である。f(m) は曲線の高さで確率ではない。
問7 ・ 標準化による比較

試験 A は平均60点・標準偏差8点で試験 B は平均65点・標準偏差12点である。どちらも得点は正規分布に従うとする。A で72点の人と B で80点の人の相対的な位置について正しいものを1つ選べ。

  1. B の80点のほうが上位である
  2. A の72点のほうが上位である
  3. 同じ位置である
  4. 標準偏差が異なるので比べられない
解答と解説
正解は 2 である。A の Z は (72−60)/8＝1.5 で B の Z は (80−65)/12＝1.25 である。Z が大きい A のほうが上位である。
問8 ・ 目安の割合

正規分布 N(m, σ²) に従う値のうち m−2σ 以上 m＋2σ 以下の範囲の外にある割合を小数第4位まで答えよ。

解答と解説
正解は 0.0456 である。範囲内は 2×0.4772＝0.9544 なので外は 1−0.9544＝0.0456 である。

この章の要点

要点 連続型確率変数では確率は確率密度関数の下の面積で P(X＝a)＝0 である。
正規分布 N(m, σ²) は x＝m について対称で期待値 m・標準偏差 σ である。
標準化 Z＝(X−m)/σ で N(0, 1) に直してから正規分布表を引く。
表の値は p(z₀)＝P(0≤Z≤z₀)。裾は 0.5−p(a) で両側は 2p(a)。
m±σ・m±2σ・m±3σ に約68%・95%・99.7%。95%の正確な境目は 1.96σ。
B(n, p) は n が大きいとき N(np, np(1−p)) で近似できる。

残っている問い

  • 二項分布を正規分布で近似するとき大学の統計学では X＝k を k−0.5 から k＋0.5 までの区間と見る連続修正を行う。高校の教科書と共通テストでは通常この修正を行わない。
  • 「n が十分大きい」の基準は高校の範囲では明示されない。np と n(1−p) がともに5以上または10以上といった目安が大学の教科書で示される。
  • 共通テストの巻末の正規分布表の体裁は大学入試センターが公表する問題冊子で確認する。本文の表の形式は教科書と過去の試験に共通する形式として記した。年度ごとの体裁は出典で確定していない。
  • ド・モアブルの近似は1733年にラテン語の小論として配布されたとする記述がある。本文では書籍への収録年1738年を記した。
