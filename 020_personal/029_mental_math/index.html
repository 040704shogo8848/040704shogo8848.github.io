桁が増えても潰れない計算法technique

桁が上がると詰まるのは、途中で覚えておく数が増えるからで、計算そのものが難しくなるわけではない。下の8つはどれも、途中で覚える数を1つか2つに抑えるための型。

1. 上の位から足す
筆算は下の位から繰り上がる。暗算では逆に、上の位から足して答えを育てる。最初に出る数が答えの概形になるので、途中で間違えても桁は狂わない。
487 + 396
→ 400+300 = 700
→ 700+80+90 = 870
→ 870+7+6 = 883
2. キリのいい数に寄せて、あとで戻す
8や9で終わる数は、10や100に切り上げてから差を引く。引き算では引く数を切り上げて、切り上げた分を足し戻す。
8241 − 3987
→ 3987を4000とみなす: 8241−4000 = 4241
→ 13だけ引きすぎたので戻す: 4241+13 = 4254
3. 掛け算は片方を分解する
2桁×2桁以上は、片方を位ごとに分けて2回の掛け算にする。分ける側は小さいほう、または0が多くなるほうを選ぶ。
47 × 68
→ 47×70 = 3290
→ 47×2 = 94 を引く
→ 3290−94 = 3196
4. 平均の2乗から差の2乗を引く
2つの数の真ん中がキリのいい数になるとき、掛け算は2乗の引き算1回で済む。(m+k)(m−k) = m² − k²。47×53 のように和が偶数で中央が10の倍数になる組で効く。
47 × 53 （真ん中は50、差は3）
→ 50² − 3² = 2500 − 9 = 2491
83 × 77 （真ん中は80、差は3）
→ 6400 − 9 = 6391
5. 25・50・125は割り算に直す
×25 は ×100÷4、×50 は ×100÷2、×125 は ×1000÷8。÷25 は ×4÷100。桁の大きい数ほど得をする。
3648 × 25
→ 364800 ÷ 4 = 91200
7200 ÷ 25
→ 7200×4 = 28800 → ÷100 = 288
6. 11倍は間に和を挟む
2桁×11は、両端の数字をそのまま置いて、間に2つの和を入れる。和が10以上なら左へ繰り上げる。
53 × 11 （5と3の間に8）
→ 583
78 × 11 （7+8=15なので繰り上げ）
→ 7|15|8 → 858
7. 百分率は1%を作ってから掛ける
いきなり％を掛けず、まず100で割る。桁が大きいほどこの順番が効く。％と元の数は入れ替えてもよい（8%の25 = 25%の8）。
4,800,000 の 7%
→ 1% = 48,000
→ ×7 = 336,000
25 の 8% （入れ替え）
→ 8 の 25% = 2
8. 九去法で検算する
各桁の数字を全部足し、9で割った余りを取る。この余りは足し算・掛け算でそのまま引き継がれるので、答えの余りが合わなければ計算違いが確定する。余りが合っていても正解とは限らないが、桁違いと数字の入れ替えはほぼ捕まえられる。
47 × 68 = 3196 で検算する
→ 47: 4+7=11 → 2　68: 6+8=14 → 5
→ 2×5 = 10 → 1
→ 3196: 3+1+9+6=19 → 1　一致
