確率変数と二項分布

試行の結果に数値を対応させたものが確率変数である。確率変数の中心を期待値で測り散らばりを分散と標準偏差で測る。同じ試行を n 回くり返したときの成功回数は二項分布 B(n, p) に従い期待値は np で分散は np(1−p) である。

第6章と第7章では1つの事象の確率と1回の試行の期待値を計算した。この章からは数学Bの「統計的な推測」に入る。試行の結果を数値で表した量を確率変数と呼び確率変数がとる値と確率の対応を1つの表やグラフにまとめる。第1章と第2章でデータに対して計算した平均と分散を今度は確率分布に対して計算する。

共通テストの数学Ⅱ・B・Cで「統計的な推測」は選択問題の1つである。この範囲から確率分布の期待値と分散・aX+b の変換・二項分布の期待値と分散が毎年の計算の出発点になる。第9章の正規分布と第10章の推定と第11章の検定はすべてこの章の公式の上に立つ。最初の節では数列の単元で学ぶ Σ 記号を必要な分だけ扱う。

Σ記号の読み方

確率分布の期待値は「値×確率」を全部足した和である。項の数が多いと書き切れないので和を記号 Σ で表す。Σ はギリシャ文字のシグマの大文字で英語の sum の頭文字 S に当たる。

∑k=1nak=a1+a2+a3+⋯+an\sum_{k=1}^{n} a_k = a_1 + a_2 + a_3 + \cdots + a_n

下の k=1k=1 は「k を1から始める」を表し上の nn は「n で終える」を表す。k に 1・2・3・… と順に代入した項をすべて足す。k は足し終えると残らない文字なので i や j に替えても値は同じである。

Σ には次の3つの性質がある。どれも足し算の順序を入れ替えてよいことと分配法則から直接に導かれる。

∑k=1n(ak+bk)=∑k=1nak+∑k=1nbk,∑k=1nc ak=c∑k=1nak,∑k=1nc=nc\sum_{k=1}^{n}(a_k+b_k)=\sum_{k=1}^{n}a_k+\sum_{k=1}^{n}b_k ,\qquad \sum_{k=1}^{n}c\,a_k=c\sum_{k=1}^{n}a_k ,\qquad \sum_{k=1}^{n}c=nc

計算で使う和の公式は次の2つである。1つ目は1から n までの和を逆順に並べた和と足すと n+1n+1 が n 個並ぶことから得られる。2つ目の導出は数列の単元で扱う。

∑k=1nk=n(n+1)2,∑k=1nk2=n(n+1)(2n+1)6\sum_{k=1}^{n}k=\frac{n(n+1)}{2} ,\qquad \sum_{k=1}^{n}k^2=\frac{n(n+1)(2n+1)}{6}
例題 1

∑k=15(2k+1)\displaystyle\sum_{k=1}^{5}(2k+1) を求めよ。

解き方
手順1 性質で分ける。2∑k+∑12\sum k+\sum 1 になる。
手順2 ∑k=15k=5⋅62=15\sum_{k=1}^{5}k=\frac{5\cdot 6}{2}=15 で ∑k=151=5\sum_{k=1}^{5}1=5 である。
手順3 2×15+5=352\times 15+5=35。検算として 3+5+7+9+11=35 で一致する。答え 35

典型的な誤りは ∑k=151\sum_{k=1}^{5}1 を1とする誤りである。1を5回足すので5である。定数の和は「定数×項の数」になる。

確率変数と確率分布

試行の結果によって値が定まり各値をとる確率が定まる変数を確率変数と呼ぶ。確率変数は大文字の X や Y で表す。X がとる値を x1,x2,…,xnx_1, x_2, \ldots, x_n としそれぞれの値をとる確率を p1,p2,…,pnp_1, p_2, \ldots, p_n とする。この値と確率の対応を X の確率分布または単に分布と呼ぶ。X が値 a をとる確率を P(X=a)P(X=a) と書く。

確率分布には次の2つの条件がある。各確率は0以上1以下であり確率の合計は1である。X がとる値は互いに排反な事象を表し全部合わせると全事象になるからである。

pk≥0,∑k=1npk=p1+p2+⋯+pn=1p_k \ge 0 ,\qquad \sum_{k=1}^{n}p_k=p_1+p_2+\cdots+p_n=1

硬貨を3枚投げて表の枚数を X とする。X のとる値は 0・1・2・3 である。表が r 枚の出方は 3Cr{}_3\mathrm{C}_r 通りで全体は 23=82^3=8 通りなので確率分布は次の表になる。

例題 2

赤玉3個と白玉2個が入った袋から同時に2個取り出す。取り出した赤玉の個数を X とするとき X の確率分布を求めよ。

解き方
手順1 取り出し方の総数は 5C2=10{}_5\mathrm{C}_2=10 通りである。
手順2 X＝0 は白2個で 2C2=1{}_2\mathrm{C}_2=1 通り。X＝1 は赤1個と白1個で 3×2=63\times 2=6 通り。X＝2 は赤2個で 3C2=3{}_3\mathrm{C}_2=3 通り。
手順3 確率は順に 1/10・6/10・3/10 である。合計が1になることを確かめる。答え P(X＝0)＝1/10・P(X＝1)＝3/5・P(X＝2)＝3/10

典型的な誤りは確率の合計を確かめずに次の計算へ進む誤りである。合計が1にならない分布は数え漏れか重複がある。共通テストでは分布表の空欄を「合計が1」の条件から求める設問が多い。

期待値と分散と標準偏差

期待値

確率変数 X の期待値または平均を次の式で定義し E(X)E(X) または m で表す。

E(X)=∑k=1nxkpk=x1p1+x2p2+⋯+xnpnE(X)=\sum_{k=1}^{n}x_k p_k=x_1p_1+x_2p_2+\cdots+x_np_n

この式の根拠は第1章の度数分布表の平均である。度数分布表の平均は「階級値×相対度数」の和であった。試行を多数回くり返すと各値の相対度数は確率に近づく。相対度数を確率で置き換えたものが期待値である。図1の釣り合いの位置は 0⋅18+1⋅38+2⋅38+3⋅18=128=1.50\cdot\frac18+1\cdot\frac38+2\cdot\frac38+3\cdot\frac18=\frac{12}{8}=1.5 で求まる。

分散と標準偏差

期待値が同じでも値の散らばり方は分布ごとに異なる。図2の A と B はどちらも期待値が3である。B のほうが3から遠い値をとる。この散らばりを測るために期待値 m からの偏差 X−mX-m の2乗の期待値を考える。これを分散と呼び V(X)V(X) で表す。分散の正の平方根を標準偏差と呼び σ(X)\sigma(X) で表す。

V(X)=∑k=1n(xk−m)2pk,σ(X)=V(X)V(X)=\sum_{k=1}^{n}(x_k-m)^2p_k ,\qquad \sigma(X)=\sqrt{V(X)}

偏差をそのまま平均すると正と負が打ち消し合って必ず0になる。2乗すると符号が消えるので散らばりの大きさが残る。ただし2乗すると単位も2乗になる。X が円なら分散の単位は円の2乗である。平方根をとって元の単位に戻したものが標準偏差である。

分散の計算には次の公式を使うことが多い。

V(X)=E(X2)−{E(X)}2V(X)=E(X^2)-\{E(X)\}^2

導き方は定義の2乗を展開して Σ の性質を使うだけである。∑(xk−m)2pk=∑xk2pk−2m∑xkpk+m2∑pk\sum(x_k-m)^2p_k=\sum x_k^2p_k-2m\sum x_kp_k+m^2\sum p_k と分ける。第2項の ∑xkpk\sum x_kp_k は m で第3項の ∑pk\sum p_k は1なので E(X2)−2m2+m2=E(X2)−m2E(X^2)-2m^2+m^2=E(X^2)-m^2 になる。第2章でデータの分散を「2乗の平均−平均の2乗」で求めた公式と同じ形である。

例題2の X について期待値と分散と標準偏差を求めよ。

解き方
手順1 E(X)=0⋅110+1⋅610+2⋅310=1210=1.2E(X)=0\cdot\frac{1}{10}+1\cdot\frac{6}{10}+2\cdot\frac{3}{10}=\frac{12}{10}=1.2

典型的な誤りは2つある。1つ目は E(X2)E(X^2) を {E(X)}2\{E(X)\}^2 と同じものとして分散を0にする誤りである。E(X2)E(X^2) は値を先に2乗してから確率を掛けて足す。2つ目は分散と標準偏差の取り違えである。設問がどちらを問うかを最後に確かめる。

投資で言えば

期待値はリターンで標準偏差はリスクである

運用の世界では収益率の期待値をリターンと呼び標準偏差をリスクと呼ぶ。図2の A と B はリターンが同じでリスクが2倍異なる2つの商品である。

aX＋b の期待値と分散

確率変数 X に定数 a を掛けて定数 b を足した Y=aX+bY=aX+b も確率変数である。X が xkx_k をとるとき Y は axk+bax_k+b をとりその確率は pkp_k のままである。このとき次の公式が成り立つ。

E(aX+b)=aE(X)+b,V(aX+b)=a2V(X),σ(aX+b)=∣a∣ σ(X)E(aX+b)=aE(X)+b ,\qquad V(aX+b)=a^2V(X) ,\qquad \sigma(aX+b)=|a|\,\sigma(X)

期待値の式は Σ の性質から得られる。∑(axk+b)pk=a∑xkpk+b∑pk=aE(X)+b\sum(ax_k+b)p_k=a\sum x_kp_k+b\sum p_k=aE(X)+b である。

分散の式は偏差を見ると根拠がわかる。Y の期待値は am+bam+b なので Y の偏差は (axk+b)−(am+b)=a(xk−m)(ax_k+b)-(am+b)=a(x_k-m) である。b は全員を同じだけ平行移動させるだけで偏差を変えない。a は偏差を a 倍にするので2乗した分散は a² 倍になる。標準偏差は平方根をとるので ∣a∣|a| 倍になる。a が負でも散らばりは負にならないので絶対値が付く。

会計で言えば

固定の受取額 b はリスクを増やさない

販売数量 X に単価 a を掛け固定収入 b を足しても収入の振れ幅は |a| 倍にしかならない。b は全期間に同額が加わるだけなので標準偏差に影響しない。

確率変数の和と積

和の期待値

2つの確率変数 X と Y について X＝a かつ Y＝b となる確率の対応をまとめたものを X と Y の同時分布と呼ぶ。同時分布から次の性質が成り立つ。

E(X+Y)=E(X)+E(Y),E(aX+bY)=aE(X)+bE(Y)E(X+Y)=E(X)+E(Y) ,\qquad E(aX+bY)=aE(X)+bE(Y)

これは X と Y がどのような関係にあっても成り立つ。同時分布の表で xi+yjx_i+y_j に確率を掛けて全部足すと x の部分と y の部分に分かれ x の部分は E(X) に y の部分は E(Y) になるからである。3つ以上の和でも同様である。

独立な確率変数

X のとる任意の値 a と Y のとる任意の値 b について次の式が成り立つとき X と Y は独立であるという。

P(X=a, Y=b)=P(X=a) P(Y=b)P(X=a,\ Y=b)=P(X=a)\,P(Y=b)

第6章の独立な試行の結果から定まる確率変数は独立である。たとえば2個のさいころの目 X と Y は独立である。X と Y が独立なら次の2つが成り立つ。

E(XY)=E(X)E(Y),V(X+Y)=V(X)+V(Y)E(XY)=E(X)E(Y) ,\qquad V(X+Y)=V(X)+V(Y)

積の式は独立の定義から同時確率が P(X=a)P(Y=b)P(X=a)P(Y=b) に分かれ和が ∑aP(X=a)×∑bP(Y=b)\sum aP(X=a)\times\sum bP(Y=b) に分かれることから得られる。分散の式は展開すると根拠がわかる。

V(X+Y)=V(X)+V(Y)+2{E(XY)−E(X)E(Y)}V(X+Y)=V(X)+V(Y)+2\{E(XY)-E(X)E(Y)\}

独立なら波かっこの中が0になるので分散がそのまま足し算になる。独立でないと波かっこの中は一般に0ではない。片方が大きいときにもう片方も大きくなりやすい組では和の散らばりが V(X)＋V(Y) より大きくなる。波かっこの中の E(XY)−E(X)E(Y) は大学の統計学で共分散と呼ばれ、第3章のデータの共分散と同じ構造である。

投資で言えば

分散投資の効果は V(X＋Y)＝V(X)＋V(Y) から生じる

分散が V の独立な2資産に半分ずつ投資すると分散は (V＋V)÷4＝V/2 になる。期待値は変わらずリスクだけが下がる。

二項分布

1回の試行で事象 A が起こる確率を p とする。この試行を n 回くり返す反復試行で A が起こる回数を X とする。第6章の反復試行の確率から X の確率分布は次の式で表される。ここで q=1−pq=1-p である。

P(X=r)=nCr prq n−r(r=0,1,2,…,n)P(X=r)={}_n\mathrm{C}_r\,p^r q^{\,n-r}\qquad (r=0,1,2,\ldots,n)

この確率分布を二項分布と呼び B(n,p)B(n,p) で表す。B は binomial の頭文字である。確率の合計が1になることは二項定理 (p+q)n=∑nCrprqn−r(p+q)^n=\sum{}_n\mathrm{C}_r p^r q^{n-r} で p+q=1p+q=1 とおけば確かめられる。第5章の二項定理の各項がそのまま確率になっている。

二項分布の期待値と分散は次の式で表される。

E(X)=np,V(X)=npq=np(1−p),σ(X)=npqE(X)=np ,\qquad V(X)=npq=np(1-p) ,\qquad \sigma(X)=\sqrt{npq}

導き方は X を n 個の確率変数の和に分けるのが最も短い。k 回目に A が起これば1で起こらなければ0をとる確率変数を XkX_k とする。X=X1+X2+⋯+XnX=X_1+X_2+\cdots+X_n である。

  • E(Xk)=1⋅p+0⋅q=pE(X_k)=1\cdot p+0\cdot q=p である。和の期待値は和なので E(X)=npE(X)=np
  • E(Xk2)=12⋅p+02⋅q=pE(X_k^2)=1^2\cdot p+0^2\cdot q=p なので V(Xk)=p−p2=pqV(X_k)=p-p^2=pq である
  • 各回の試行は独立なので分散も足し算になり V(X)=npqV(X)=npq
例題 7

解き方
手順1 3の倍数の目は3と6で確率は 1/3 である。X は B(4, 1/3) に従う。
手順2 P(X=2)=4C2(13)2(23)2=6×19×49=2481=827P(X=2)={}_4\mathrm{C}_2\left(\frac13\right)^2\left(\frac23\right)^2=6\times\frac19\times\frac49=\frac{24}{81}=\frac{8}{27}
手順3 E(X)=4×13=43E(X)=4\times\frac13=\frac43・V(X)=4×13×23=89V(X)=4\times\frac13\times\frac23=\frac89。答え 8/27・4/3・8/9
例題 8

二項分布 B(n, p) に従う X の期待値が 12 で分散が 9 である。n と p を求めよ。

解き方
手順1 np＝12 と np(1−p)＝9 を連立する。
手順2 2式目を1式目で割ると 1−p＝9/12＝3/4 で p＝1/4 である。
手順3 n＝12÷(1/4)＝48。答え n＝48・p＝1/4

典型的な誤りは二項分布でない場面に np を使う誤りである。二項分布の条件は「同じ確率の独立な試行を決まった回数くり返す」ことである。例題2のように袋から玉を戻さずに取り出す場合は各回の確率が変わるので二項分布ではない。

野球で言えば

打率3割の打者の4打数は B(4, 0.3) である

各打席が独立なら安打数の期待値は 1.2本である。4打数無安打の確率は 0.7⁴＝0.2401 で約4試合に1試合ある。

実際の打席は相手投手や球場で確率が変わるので独立で同じ確率という仮定は近似である。

現実世界の確率変数

二項分布の考え方は品質管理と保険と臨床試験の計算の出発点である。不良品率 p の工程から n 個を検査したときの不良品の個数は B(n, p) で表される。不良品率2%の工程から50個を抜き取ると不良品の個数 X は B(50, 0.02) に従い期待値は1個である。1個も含まれない確率は 0.9850≒0.364 で2個以上含まれる確率は約0.264 である。期待値が1個でも3回に1回以上は不良品を1個も検出できない。抜き取る個数を決めるときはこの確率を計算して検査の見逃しを評価する。保険会社は1件あたりの支払額を確率変数とみて期待値に経費を加えて保険料を定める。加入者が多いほど1人あたりの支払額の平均の散らばりが小さくなる。この性質は第10章の大数の法則で扱う。

現実世界

反復試行の成功回数を体系的に扱った最初の書物の1つはヤコブ・ベルヌーイの『推測術』である。ベルヌーイの没後の1713年に刊行され試行回数を増やすと相対度数が確率に近づく定理を含む。1回の試行で成功か失敗の2通りをとる試行は現在でもベルヌーイ試行と呼ばれる。

問4 ・ aX＋b の変換

E(X)＝5・σ(X)＝2 の確率変数 X に対し Y＝−3X＋4 とする。Y の期待値と標準偏差の組として正しいものを1つ選べ。

  1. 期待値 −11・標準偏差 6
  2. 期待値 −11・標準偏差 −6
  3. 期待値 −11・標準偏差 36
  4. 期待値 −15・標準偏差 6

問5 ・ 独立な確率変数の分散

独立な確率変数 X と Y が V(X)＝4・V(Y)＝9 を満たす。2X−Y の標準偏差として正しいものを1つ選べ。

  1. √7
  2. 1
  3. √17
  4. 5
解答と解説
正解は 4 である。V(2X−Y)＝2²×4＋(−1)²×9＝16＋9＝25 で標準偏差は5である。1 は 4×4−9 の誤り。3 は 2×4＋9 で係数を2乗し忘れた値である。
問6 ・ 二項分布の n と p

二項分布 B(n, p) に従う X の期待値が 20 で標準偏差が 4 である。n を答えよ。

解答と解説
正解は 100 である。分散は 4²＝16 である。np＝20 と np(1−p)＝16 から 1−p＝0.8 で p＝0.2 である。n＝20÷0.2＝100
問7 ・ 常に成り立つ式

任意の確率変数 X と Y について常に成り立つものを1つ選べ。

  1. E(XY)＝E(X)E(Y)
  2. E(X＋Y)＝E(X)＋E(Y)
  3. V(X＋Y)＝V(X)＋V(Y)
  4. V(X−Y)＝V(X)−V(Y)
解答と解説
正解は 2 である。和の期待値の式は独立かどうかに関係なく成り立つ。1 と 3 は X と Y が独立のときに成り立つ。4 は独立でも成り立たず正しくは V(X)＋V(Y) である。

この章の要点

要点 確率分布は値と確率の対応で確率の合計は1である。
期待値 E(X)＝Σ xkpk は分布の釣り合いの位置である。
分散 V(X)＝E(X²)−{E(X)}² で標準偏差はその正の平方根である。
E(aX＋b)＝aE(X)＋b・V(aX＋b)＝a²V(X)・σ(aX＋b)＝|a|σ(X)。
和の期待値は常に和である。積の期待値と和の分散が分かれるのは独立なときだけである。
二項分布 B(n, p) は E＝np・V＝np(1−p) で n 個のベルヌーイ試行の和として導ける。
